# 阶段132采集前设计：规模、位长与合法组合

本设计在该批数据采集前保存；遵循既有7进程block、每任务预热1次/热测5次、固定seed打乱热任务次序。首批计时资料保持不改。

1. 小池容量：n=2圆盘、全单位方盒、t=1，k=3/4/5/6/7/8个有理共线目标。所有返回NOT_EXCLUDED。k8留出；以k7锚定2^k至2^k*k^3操作工作预测，不用k8拟合。
2. 位长：固定3个靠近原点的非共线目标，分母2^b+1和2^b+3，b=8/32/128/512/2048。n=2、全方盒、t=1。只改变输入位长及由此产生的几何数值；不能称几何完全不变。2048留出，先按512点的常数至二次位复杂度工程区间预测，再检查实际。
3. 组合语料：已有盒约束胜MEC、MEC胜均值能量、零权消除杂点三个反例，加一个闭半径正控制。三个方法统一给非负权重，逐输入同父域独立重放；保存3x4判定矩阵和域指纹，直接取排除集合并/交，不乘边际概率。运行三个两方法组合的六个顺序，以及三方法完整安全重放；每种顺序在EXCLUDED才短路。
4. 缓存：只测本地可信执行得到的叶结果，用完整payload和源/实际依赖快照哈希作键。改半径或改前提快照必须miss。外部提交的结果仍需composer完整重放，不用缓存命中替代外部证书验证。分别记录首次填充、命中、完整composer重放。
5. 计数/弧组合：在当前U下404标签集核对弧帽和透镜增量排除，预测为0；该断言是有限标签域事实，不是其他半径的支配证明。

缓存和顺序收益只对该公开的四例语料。它是互补性展示，不估任意随机全图的成功率。固定四例很小，不报告显著性或总体效应。所有时间仅为遥测，所有几何判定仍由精确接口完成。
