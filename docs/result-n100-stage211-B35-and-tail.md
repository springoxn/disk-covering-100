## B36障碍

[B36固定松弛点障碍](../verify/out/n100-tail-support-obstruction-206.json)实际退出0。对旧capped-pair常数，取

`x=y=9921033/12500000`，

得到松弛区间

`3754996055077/500000000000000 <= pair <= 3754996055079/500000000000000`。

其下端超过旧截距1501/200000约`0.00000499211`，并且超过B36总面积预算允许的最大截距。故不能仅通过增加箱预算、提高旧截距或复用B≥37的19/2500截距修复B36；后者使B36预算为负。该障碍不是覆盖配置或反例，只说明当前固定pair relaxation不足。

下一步必须同步改变B36的斜率、罚系数、三角支持，或加入更紧的相邻透镜/共同端点约束，并对整个有理域重新覆盖。除非该新证书通过，不能接受0.11324。
