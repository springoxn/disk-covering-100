# n=100 阶段38：真实核心的四轴插入弧预算剪枝

## 接入现行半径的几何前端

固定 U=1154469548855829/10^16，取有理 c>0 且 c²<=1-U²，M=U/c。半径不超过U的盘在单位圆的服务半弧phi满足phi<=M（短弧性质及sin(phi)>=phi*cos(phi)）。因此一条边界弧长至多2M。证书精确验证12M<pi/2，所以覆盖任意一个四分之一圆至少需要7条边界弧。

删除四个轴点后，若两个相邻轴之间有g个核心边界顶点，则恢复轴点后该四分之一圆有g+1条弧，因此g>=6。四轴落同一核心边、或落过近边，无法满足此必要条件。多个轴同边不是在枚举入口擅自删去，而是在穷举后由当前U的严格弧预算排除。

这是轴点插入阶段的必要筛选，适用于采用单一简单外边界的通用位置核心；不自动证明对应坐标赋值存在。
