## 正确使用的必要条件

对任一内面f和固定轴a_i，令d_i为该面至轴所属面的内面对偶最短距离。面圆心c_f必须满足

`|c_f-a_i| <= (2*d_i+1)*U`。

记R_i²=(2*d_i+1)²U²。对任意正权重w_i和锚点子集I，设W=sum w_i、mu=sum w_i*a_i/W，有恒等式

`sum w_i*|c_f-a_i|² = W*|c_f-mu|² + sum w_i*|a_i-mu|²`。

因此若右边加权方差严格大于sum w_i R_i²，则该圆心不可能存在，进而可排除轴方案。

本轮对每个方案的全部100个内面，检查4个三轴子集及1个四轴子集。权重固定为w_i=1/R_i²，精确算术使用Fraction。重复图距离向量缓存，不改变检查域。
