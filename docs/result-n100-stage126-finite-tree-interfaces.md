# 阶段126：有限弧学习与闭实区间树证明接口

[有限域接口](../verify/n100_finite_proof_interfaces.py)、[分支树接口](../verify/n100_split_tree_proof_interfaces.py)及[验证入口](../verify/n100_finite_tree_proof_interface_contracts.py)已实现。加强后的测试实际退出0，[当前v2证书](../verify/out/n100-finite-tree-proof-interface-contracts-v2.json)为本轮权威证据；初版证书保留为历史，不替代v2。

## 有限必要模型

输入绑定地图、帧、连续父域、半径域，给出循环变量、整数标签位掩码、相邻关系表和同象限次序标志。运行状态DP累计各nogood的满足位；独立核对将“避开每个冲突合取”展开成重叠子域并集，在扩展次序状态上分别运行bit/set两种循环DP。

同象限状态记录标签前缀最大值M，要求M<=下一标签+1，允许闭端点相接；锚点必须位于象限切换后。相邻关系和扩展次序状态都仅为必要有限松弛，模型与连续几何的桥接仍继承，不把有限可满足当作覆盖。

关系键只接受非负整数或规范整数文本，禁止浮点键隐式int截断及00/0别名覆盖。验证预算分别限制子域展开数量和理论状态规模；超预算返回UNDECIDED，不排除。

## Nogood来源与迁移

learn_nogood由连续父请求和每个标签的实区间tile重建限制子盒，保留父约束；空tile交或实际连续原语重放排除才允许学习。不能直接导入一个未经重放的excluded:true标签。

学习记录绑定完整父请求指纹、完整tile实现指纹和限制分支证明。重注入逐项重新构造并核对。换父盒、换tile、换帧或半径语义不隐式迁移。即使迁入更小父盒在逻辑上可能有效，也需要显式蕴含适配；本接口采用严格相同父域策略。

本轮学习例是受控连续必要系统，不冒充旧nogood驱动的全部连续冲突已经移植。历史高阶nogood库仍需逐条转换其tile/父域和约束来源。

## 完整空间树

树节点先重放连续必要收缩，再在收缩后的闭盒上分裂。精确子域为[lo,cut]与[cut,hi]，共享中点允许；从cut+1开始会漏掉真实实区间，被拒绝。

验证器重建每个子请求，核对完整传播记录，检查子索引唯一、无环、无漏子树和无不可达额外节点。每片叶都必须重新验证：所有叶排除才返回根EXCLUDED；只要存在未决叶即返回UNDECIDED。当前只处理连续盒约束树；中心盒Hall/容量混合树仍需显式不同域适配，不能隐式混用。

## 实证

- 奇数不等循环排除，偶数循环全部标签保留。
- 三标签0/1/2的27种固定分支逐一与直接前缀次序判断比较，覆盖真实的严格逆序冲突及闭端点保留。
- 一个真实重放的连续父域nogood限制支持为[2,3,3]；可行分支不允许学习。
- 两个历史闭相邻弧次序模型完整支持逐项匹配，标签数1866和2312。该重放保留原来的相邻关系模型；没有额外宣称历史模型已包含全部非相邻次序约束。
- 一个未决深度0根与一个7节点完整树分别返回UNDECIDED、EXCLUDED；后者4片排除叶，无未决叶。树使用受控范数必要系统，不是全n100空间树。
- 12项负控制通过，包括改父域/坐标tile/证明、无冲突却要求学习、锚点不复位、浮点及非规范关系键、缺子树/复用节点/伪造排除/不可达节点/整数格点式实区间缺口。

## 成本模型接口

循环状态最多O(d*2^g)个每层，d为标签规模、g为冲突数，另乘锚点数及相邻转移数；当前独立子域并集oracle有prod(冲突长度)个分支。不能把“DP”笼统当作多项式于g。

完整树有N节点，当前安全核验逐节点重跑连续传播，总成本约sum_node(S_node*C_node)次区间原语，加盒复制、序列化与索引验证。当前实现保存完整节点传播数据，空间成本不能只按叶数估计。

组合顺序可以先做便宜关系支持再尝试连续冲突学习；学习仅删除已证冲突合取。多个否定子域重叠时做精确并集，不相加标签数或概率。共享父域tile和表的缓存必须绑定快照哈希。
