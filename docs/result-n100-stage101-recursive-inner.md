# 阶段101：递归内圆整数包络将非圆周服务盘下限提高至56

## 本轮结论和实际执行

主脚本及独立脚本均退出0。主脚本首次运行因反正弦的粗上界不足而退出1；备份保存了失败版本，改为有理正项级数尾界后通过。未放宽目标常数或判定容差。

在U=1154469548855829/10^16，任意至多100盘覆盖至少有56个圆盘不与单位圆周相交。因此若有效盘数为m，圆周服务数k满足k<=m-56，特别k<=44。

将该必要条件接入旧计数域，三元组1328->530，删除798；家族87->65，删除22。固定核心的576排除、4200保留统计没有更新，本轮没有对所有几何根重跑。

## 1. 递归覆盖的严格归约

把所有圆盘半径统一放大至U。若一个圆盘与单位圆周相交，其中心c满足|c|>=1-U。任意盘内点x满足|x|>=|c|-U>=1-2U，所以这些盘都不进入开内圆|x|<s=1-2U。

原覆盖中不服务圆周的q个圆盘必须覆盖该开内圆。它们的有限并是闭集，因而也覆盖开内圆的闭包。将长度除以s，得到q个半径t=U/s的盘覆盖单位闭盘。这个子问题可独立投影盘外中心并去重，使中心数N<=q；不改变原问题的分类计数。

## 2. 通用整数边数包络

复用既有Voronoi解析证明的通用部分，而非复用n100特定数值：裁剪胞的圆周归属弧数B，弧角g<=2asin(t)。按弧端点作内接多边形P，名义整数边数满足sum e_i<=6N-6-B。

一般位置、多弧、投影后重合、空胞及高阶交汇的处理继承既有证明。其通用推导见proofs/n100-strengthened-lowerbound-combined.md第1—4节和proofs/n100-sharp-envelope-lowerbound.md第1节。本轮已读取这些段落，N只用作任意有限中心数，100并不参与通用计数恒等式。

设f6=3sqrt(3)/2，f5=5sqrt(10+2sqrt(5))/8。通过整数5、6的割线对全部整数边数面积上界成立，故

area(P)<=t²[(f6-f5)*sum e_i+N*(6f5-5f6)]。

## 3. 至多55盘的统一矛盾

精确有理算术证明asin(t)<T=151/1000，20T<pi，故B>=21。因此sum e_i<=6N-27，若N<=55，则

area(P)<=t²[(N-27)f6+27f5]<=t²[28f6+27f5]。

另一方面，sin(g)/g在此角域递减，弧角总和2pi，所以

area(P)>=pi*sinc(asin(t))>pi*sinc(T)。

对sinc(T)=sin(2T)/(2T)，取6项交错级数的负末项截断H，得到严格下界；对根式用正有理向上外包，得到G_up>=28f6+27f5。证书中精确认证

`pi_lo*H - t²*G_up > 0`。

上下界矛盾，故q<=55不可能，q>=56。归一化半径t固定为U/s；更小原半径通过先放大至U得到同样必要条件。

## 4. 独立核验

主实现用16项反正弦正项级数及几何尾界。独立实现改用asin(t)=atan(t/sqrt(1-t²))，整数二分构造平方根下界，以17项atan交错上界核对T。

独立实现还直接平方验证f6和f5嵌套根式的保存端点、重算sinc交错级数及严格面积亏损、独立Machin级数括住pi、逐项重新计算全部530保留及798删除三元组，以及65保留和22删除家族。三种篡改（虚增非服务下限、伪造亏损、缩小角上界）全部被拒绝。

算术证书并不形式化Voronoi几何、面积次可加和闭包覆盖引理。这些解析依赖已在此明列，属于既有证明框架的应用；独立脚本没有假装另行形式化它们。
