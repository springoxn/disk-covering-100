## 1. 结论摘要（一句话 + 三张表）

设 `r_D(100)` 为覆盖单位闭圆盘所需 100 个等半径闭圆盘的最小半径。

1. **精确目标舍入判别（本文档最重要的交付）**：历史 10 位小数
   `0.1109141386 = 554570693/5000000000` 是**四舍五入偏大**。连续 Jensen 链的真根是
   ```
   r* = 0.110914138592409428292745323501279224408257699399065905...（发现层）
   r* − 554570693/5000000000 = −7.5905717072546765×10⁻¹²  < 0
   ```
   **因此只要还走「连续 Jensen + 精确 A_min」这条链，能证的常数是 r* ≈ 0.1109141385924，
   而不是 0.1109141386。** 后者若被当作该链的下界，就是**高估 7.59×10⁻¹²**。
   对应地，5% 判据阈值 `20L/19` 若用历史值会门开得稍大：
   `20r*/19 ≈ 0.11675172...` < `554570693/4750000000 ≈ 0.11675172...`（差 7.99×10⁻¹²）。

2. **离散包络路线（推荐）能证到的是历史值本身，且有余量。** 把连续 Jensen 换成
   整数格上的**离散凹包络**（把 G 上界从 253.2941 压到 252.0924），同时把精确
   `A_min(r,b)` 换成更粗但只用一行的 **chord-chord cap 下界** `π sin G_arc/G_arc`，
   净效果是**变强**：残差 `Ψ` 在 target 处为正，且 `Ψ` 严格单调递减（**免费**），
   于是**单点有理求值**就够，不需要分段、不需要根隔离、不需要 Chebyshev、
   也彻底消掉了审计义务 **O10**（400 步浮点不动点）。
   这条路线实际证到 `ρ ≈ 0.1111200842 > 0.1109141386`（高出 2.06×10⁻⁴）。

3. **两条路线的定位**：
   - **路线 A**（连续 Jensen + 精确 A_min + 根隔离）：**仅作发现/诊断参照**，
     其常数 r* 低于历史值；**不为其造 rootcert**。
   - **路线 B**（离散包络 + 粗 cap + 单点求值）：**推荐**，已落成条件算术证书。

## 2. 对象与符号

`N = 100`，`f(M) = (M/2) sin(2π/M)`（在 `[3,∞)` 上凹且增），
`G(b) = N f(6 − (6+b)/N)`（连续 Jensen 聚合）。

覆盖构型取 Voronoi 胞 `V_i ⊆ B(c_i,r)`，`b` 为带非退化弧的边界胞数，
`P` 为边界顶点构成的内接多边形，`e_i` 为 `V_i ∩ P` 的顶点数
（边界胞 `e_i = m_i + 1`，内部胞 `e_i = m_i`；**b 按弧数计**，见 GEOM-2）。

- **路线 A 的对象**（分段形式，`k = b−1` 固定）
  ```
  Φ(b,r) = ½[ (b−1) sin(2 asin r) − sin(2(b−1) asin r) ] − r² G(b)
  ```
  在 b 段 `r ∈ [sin(π/b), sin(π/(b−1)))` 上恒有 `k = ⌊π/asin r⌋ = b−1`，
  且 `Φ(b,r) = areaP_min(r,b) − r² G(b)` 与 `tools/cell_bound.py:369-388` 一致。

- **路线 B 的对象**（单点形式）
  ```
  G_disc = 65 f(6) + 35 f(5)
  Ψ(r)   = π (1 − (2/3) asin(r)²) − r² G_up
  ```

### 2.1 CAS 等式（简单单调性，符号可查）

**(E1) `Φ` 的导数。** 令 `t = asin r`，`A(t) = ½[(b−1) sin 2t − sin(2(b−1)t)]`，则
```
dΦ/dr = A'(t)·(dt/dr) − 2rG(b)
      = (b−1)[cos 2t − cos(2(b−1)t)] / cos t − 2rG(b)
      = 2(b−1) sin(b t) sin((b−2) t) / √(1−r²) − 2rG(b)
```
（用到 `cos X − cos Y = −2 sin((X+Y)/2) sin((X−Y)/2)`）。已由 sympy 在代换
`r = sin t` 下**符号验证**（`b = 29,30,31,32` 全部 `True`），并在 80 位精度下用
中心差分对**完整** `Φ'` 逐点核对，最大残差 `5.31×10⁻⁴¹`
（见 JSON `cas_checks.A_prime_identity_max_abs_residual`）。

**(E2) Chebyshev 形式**（若走路线 A 的整数/有理认证路线时需要）：
```
sin(k·asin r) = r · U_{k−1}(√(1−r²))      （U = 第二类 Chebyshev）
```
40 位精度核对残差 ≤ `1.74×10⁻⁷⁹`（80 位工作精度）。这把 `sin(k asin r)` 变成 `s = √(1−r²)` 的**整系数多项式**，
从而路线 A 的点判定可以退化为「`√(1−r²)` 的有理括号 + Horner 区间」，
不需要任何超越函数求值。

**(E3) 离散包络的代数恒等式**（路线 B 关键）：
```
565 a + 100 β = 65 f(6) + 35 f(5),     a = f(6) − f(5),  β = 6 f(5) − 5 f(6)
```
展开即 `565f6 − 565f5 + 600f5 − 500f6 = 65f6 + 35f5`。

> **⚠️ 两个必须写清楚的限定（已按 geometry 侧意见修正）**
>
> **(i) `β` 不是边界胞数 `b`。** 本文件一律用 `β` 记割线截距（`6f5 − 5f6`）；
> 边界胞数/弧数仍是 `b`（GEOM-1、GEOM-2、`b ≥ 29`）。两者不可混称。
>
> **(ii) 过 `(5,f(5))`、`(6,f(6))` 的割线不是凹函数 `f` 在实数上的支撑线。**
> `f` 在 `[3,∞)` 上凹，所以在区间 `(5,6)` 内部 `f` 的图像**严格位于该割线上方**
> （例如 `f(5.5) > 5.5` 处的割线值）。该界
> ```
> φ(e) ≤ a e + β
> ```
> **只对整数 `e` 成立**，理由逐类：
> `e = 5, 6` 取等；`e ≤ 4` 与 `e ≥ 7` 时凹函数的割线外推位于图像**上方**（成立）；
> `e ≤ 2` 时 `φ(e) = 0 ≤ 2a + β`（因 `a, β, 2a+β > 0`）。
> **`5` 与 `6` 之间不存在整数**，所以「中间取不到」这一步是有内容的、必须写明。
> 结论：**离散包络只能是 `Σ_i φ(e_i)` 的界（整数量），不是连续版本。**
>
> **(iii) 取值不能靠区间分拆。** 若分别用区间去界 `a` 和 `β`
> （`a_lo = f6_lo − f5_hi = 3/25`，`β_lo = 6f5_lo − 5f6_hi = 5/4`），
> 再代入 `100 f6_hi − 35 a_lo`，会得到 **255.8**（甚至用
> `100 f6_hi − 35(f6_hi−f5_lo) = 252.125`）——有效但远松，甚至使 margin 变负。
> `a, β, 2a+β > 0` 的作用**只是**论证整数割线合法，取值必须走上面的恒等式
> `565a + 100β = 65f6 + 35f5`。

**(E4) `Ψ` 的单调性（免费）**：
```
Ψ'(r) = −π (4/3) asin(r)/√(1−r²) − 2 r G_up  < 0   对一切 r > 0
```
两项都为负，无任何前提。这是路线 B 相对路线 A 的核心优势：
**只需一个有理点求值**，不需要「分段 + 每段单调 + 每段一个见证点」。

## 3. 精确目标舍入判别（交付项）

**输入的两个不同对象**（历史上常被混为一谈）：

| 名称 | 精确表示 | 十进制 | 来源 |
|---|---|---|---|
| 历史记录值 | `554570693/5000000000` | `0.1109141386` | `docs/audit-lowerbound-n100.md:5,29,125,261,287,335`；`docs/notes-lowerbound-n100.md:183` |
| 该链的真根 `r*`（发现层） | 无理数（非有理，见 §3.1 判别） | `0.110914138592409428292745323501279224408257699399065905…` | 本文档 §3.1 |
| 5% 判据阈值（历史值口径） | `554570693/4750000000` | `0.116751724…` | `docs/audit-lowerbound-n100.md:335` |
| 5% 判据阈值（真根口径） | `20r*/19` | 比上一行小 `7.99×10⁻¹²` | 本节 |

### 3.1 根的高精度定位（发现层，非隔离证明）

- **方法**：在 `b = 29` 段 `[sin(π/29), sin(π/28))` 上对 `Φ(29,·)` 做**显式二分**
  （`tools/discover_lowerbound_constant_n100.py` 的 `find_root`，`mpmath` 多精度）。
- **精度**：`dps ∈ {40, 60, 80, 120, 160}` 五次独立运行给出**前 50 位完全一致**的值
  ```
  r* = 0.1109141385924094282927453235012792244082576993990659052…   (dps = 160)
  ```
- **⚠️ 一条已修正的发现层陷阱**：`mpmath.findroot(..., solver="bisect", tol=1e-60)`
  返回 `0.11091413859240942829274532350127930705494209173035`，其**第 35 位起是错的**
  （该点 `Φ = −4.70×10⁻³³ ≠ 0`，偏差 `8.26×10⁻³⁵`）。
  本工具因此改成显式二分循环，迭代次数与结果都可复现。
  **这个修正不影响任何结论**：`r* − target` 在前 21 位不变。
- **唯一性（段内，发现层）**：`Φ(29, sin(π/29)) = +0.15613 > 0`，
  `Φ(29, sin(π/28)) = −0.06001 < 0`，且 §4.1 证明 `Φ` 在段上严格递减
  → 段内**至多一个**根。**这不是整数/有理意义下的根隔离证书**，
  路线 B 也不需要它。

### 3.2 舍入判别（判定）

```
r* − 554570693/5000000000 = −7.5905717072546765×10⁻¹² < 0
```

**判定：历史 10 位小数 `0.1109141386` 是 r* 的「四舍五入上取」，比真根大
`7.59×10⁻¹²`。** 因此：

1. 若把 `0.1109141386` 当作**连续 Jensen 链**的下界，是**高估**（该链只能到 r*）。
   正确写法是 `r_D(100) ≥ r* = 0.1109141385924…`，
   或用**向下取整**的有理数（本节 3.3 给出候选）。
2. 该链的 5% 判据阈值精确为 `20r*/19 ≈ 0.11675172…`，
   比历史口径 `554570693/4750000000` 小 `7.99×10⁻¹²`。
   在「构型要改进约 4.6%」这一结论上，两者无实质差别；但在**精确有理比较**中不可混用。
3. **路线 B 不受此影响**：它证到的 `ρ ≈ 0.11112008 > 0.1109141386`，
   即历史值在这条链上**原样成立**。

### 3.3 可用的有理下界候选（路线 A 口径）

`Φ(29,·)` 在 `[sin(π/29), r*]` 上递减，故 `Φ(29,L) > 0 ⟺ L < r*`。

| 候选 `L` | 十进制 | `r* − L` | `Φ(29,L)` | 可用？ |
|---|---|---|---|---|
| `110914138592/10¹²` | 0.110914138592 | +4.09×10⁻¹³ | +2.33×10⁻¹¹ | ✅ |
| `11091413859/10¹¹` | 0.11091413859 | +2.41×10⁻¹² | +1.37×10⁻¹⁰ | ✅ |
| `1109141385/10¹⁰` | 0.1109141385 | +9.24×10⁻¹¹ | +5.25×10⁻⁹ | ✅（10 位向下取整） |
| `554570693/5000000000` | 0.1109141386 | **−7.59×10⁻¹²** | 负 | ❌（路线 A 不可用，路线 B 可用） |

**建议表述**：路线 A 口径用 `L = 110914138592/10¹²`；
路线 B 口径直接用 `L = 554570693/5000000000`（即历史值）。

## 4. 路线 A：分段义务清单（发现/诊断用，不产 rootcert）

### 4.1 分段表（`[1/10, r*)` 的完整覆盖）与单调性余量

`b(r) = ⌈π/asin r⌉` 随 r 增大而**非增**（`asin` 增 ⟹ `π/asin` 减 ⟹ `ceil` 非增），
断点为 `r = sin(π/b)`：`b(r) = b ⟺ r ∈ [sin(π/b), sin(π/(b−1)))`。
在 `r ∈ [1/10, r*)` 上只有 4 段：

| 段 | `b` | `k = ⌊π/asin r⌋` | `r` 区间 | 段右端 | `Φ_b(右端)` | `max\|A'\|` | `min 2rG` | 余量 |
|---|---|---|---|---|---|---|---|---|
| 1 | 32 | 31 | `[1/10, sin(π/31)]` | `sin(π/31)=0.1011683…` | **+0.533905** | 0.638 | 50.537 | ×79.2 |
| 2 | 31 | 30 | `[sin(π/31), sin(π/30)]` | `sin(π/30)=0.1045285…` | **+0.355571** | 0.659 | 51.169 | ×77.6 |
| 3 | 30 | 29 | `[sin(π/30), sin(π/29)]` | `sin(π/29)=0.1081190…` | **+0.158501** | 0.682 | 52.911 | ×77.6 |
| 4 | 29 | 28 | `[sin(π/29), r*]` | `r*`（根） | 0（定义） | 0.644 | 54.772 | ×85.1 |

**单调性**：`|A'(r)| ≤ 2(b−1)/√(1−r²)·|sin(b·asin r) sin((b−2)asin r)| ≤ 0.69`
（数值上界，见 JSON 的 `max_abs_A_prime_lead_sampled`），而 `2rG ≥ 2·(1/10)·G(32) ≥ 50.5`，
故 `Φ'_b < 0`，余量约 **77–85 倍**。

### 4.2 义务清单 OB0–OB6（每条都可落成整数/有理判定）

每段 `Φ` 递减 ⟹ 只需段**右端**一点；而断点处 `H` 会因 `G(b)` 下降而**上跳**
（`G(b+1) < G(b)`，`A` 连续），所以「更紧的」永远是各段右端用**自己的** `b` 求值。

| # | 义务 | 类型 | 见证/做法 |
|---|---|---|---|
| OB0 | `r ∈ [1/10, L] ⟹ b(r) ∈ {29,30,31,32}` | 有理 | `π/32 < 1/10`（用 `π < 3.2`，Machin）；`L < sin(π/28)`（用 `28 asin L ≤ 28L/√(1−L²) < π`，即 `28·1.116×10⁻¹ < 3.1249 < π`） |
| OB1 | `Φ_b` 在 `[1/10,L]` 上严格递减，`b ∈ {29,30,31,32}` | 有理区间 | (E1) 的 `A'` 解析式 + `\|A'\| ≤ 2(b−1)/√(1−L²)·max\|sin ba\|·max\|sin((b−2)a)\|`，用 `s=√(1−r²)` 的 Chebyshev 多项式 Horner 区间（(E2)，无超越函数） |
| OB2 | `Φ_32(r₃₂) > 0` | 有理点 | `r₃₂ = 10117/100000 > sin(π/31)` |
| OB3 | `Φ_31(r₃₁) > 0` | 有理点 | `r₃₁ = 10453/100000 > sin(π/30)` |
| OB4 | `Φ_30(r₃₀) > 0` | 有理点 | `r₃₀ = 10812/100000 > sin(π/29)` |
| OB5 | `Φ_29(L) > 0` | 有理点 | `L = 110914138592/10¹² < r*`（本文档 3.3） |
| OB6 | `L < r*`（若坚持要「根」的表述） | 有理 | 由 OB5 + 段内单调性（OB1, b=29）即得 `L < r*`；**不需要**根的区间隔离 |

**为什么路线 A 需要 OB0（π 与 sin(π/b) 的括号）而路线 B 不需要**：
路线 B 只有 `b ≥ 29` 这一处用到「弧长/π」，而 `b ≥ 29` 只需
`28T < π_low`（`T` 是**有理**的 `asin` 上界），完全绕开了 `sin(π/b)`。

## 5. 路线 B：推荐方案（完整义务清单 B0–B7）

### 5.1 推导（每步标注类型）

设覆盖半径 `r ≤ L`。

| # | 步骤 | 类型 |
|---|---|---|
| B0 | `asin r ≤ asin L ≤ L/√(1−L²) < T = 14/125`；`28T = 3.136 < π_low` ⟹ `b ≥ 29` | 有理（**不开方**的平方比较） |
| B1 | 截断 Euler 记账：`Σ_i e_i ≤ 6N − 6 − b ≤ 600 − 6 − 29 = 565` | **几何前提 [GEOM-2]，未证** |
| B2 | 离散包络：`φ(e) := f(e)`（整数 `e ≥ 3`）、`φ(e) := 0`（整数 `e ≤ 2`）；整数割线 `φ(e) ≤ a e + β`；`a, β, 2a+β > 0`（**仅整数 `e` 合法**，见 (E3)(ii)；`β` 与边界胞数 `b` 无关） | 初等（`f` 在 `[3,∞)` 凹；`5,6` 间无整数） |
