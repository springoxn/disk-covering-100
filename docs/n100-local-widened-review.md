## 作用域措辞（重要）

固定规范/固定杆的陈述只是**中间范式**，不是最终输入域。链条的实际次序是：

1. **最终（最外层）输入域是无规范的中心邻域**：带标号的 100 个中心逐坐标落在精确根
   的 `1e-37` 盒内（未假设任何规范）；
2. 显式旋转把该无规范盒归一化进**固定仿射规范盒** `1e-36`（旋转角 `θ≤2(ε+ρ)`，
   坐标位移 `≤5ε+4ε²`）；
3. 在固定规范盒内 146 个孔由 Banach 连续延拓（半径 `η=1e-33`），逼出 406 条杆不等式，
   提升后落进**固定杆局部球** `1e-29`，再由增广 Lagrange 局部排除给出矛盾。

因此"固定规范"只适用于第 3 步。脚本第 29 行的措辞与回执 `scope.fixed_affine_gauge`
应读作中间范式；**最终结论覆盖的是无规范的根中心带标号邻域**。写成一句话：
先固定杆、后无规范（末端的输入域才是无规范邻域）。

## 标量链

回执中复用同一个判定函数检查 **21 条**条件，对母证书声明常数**零违反**：

* `2κ − K_Young ≥ 1`：`K_Young = 119939110720000 ≤ 2κ−1 = 199999999999999`（松弛 `80060889279999`）；
* `m ≤ min(μ/4Z², 1/2R²)`：`1e-9`，余量 1.0331×（由 `1/2R²` 卡住）；
* 局部半径：`2κJq·r ≤ m/4`、`κ(Jr+2r²) ≤ α_min`，`r = 1e-29`
  （同一代数下容许半径 `= m/(8κJq) = 1.8038e-28`，声明半径低 18.04×）；
* 分支：`128·K·ε ≤ η`（余量 1.1161×，这是分支侧最紧的一条）、`K(16ε+4η) ≤ 1/2`；
* 桥接：`gap > 64(η+ε)`、`margin > 32η+2η²`（余量 ~2.9e29 / ~5.5e30）；
* 提升：`23·max(ε,η,64(η+ε)) = 1.473472e-30 < 1e-29`（余量 6.7867×）；
* 规范/旋转：中心坐标 `≤2`、`|x_pivot| ≥ 9/10`、导数下界 `>1/2`、

## 发现（不改变结论）

* **F1（完整性）**：母回执的负控制只有"过大半径"两项，**缺少 wrong-R 控制**。
  本审计补上三项 wrong-R（去 √439、阈值下取整、旧宽松路线），均被拒绝。
* **F2（文档）**：母脚本的旋转步用 `θ=2ε` 而略去 `ρ=1e-58`。本审计按 `θ=2(ε+ρ)` 重跑，
  结论仍成立（`5.000005e-37 < 1e-36`），属表述精度问题，非算术错误。
* **F3（措辞）**：见上"作用域措辞"——"固定规范"是中间范式，最终输入域无规范。
