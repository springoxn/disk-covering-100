# 阶段127：地图编译与精确代数排除接口

[代数接口](../verify/n100_algebra_proof_interfaces.py)和[验证入口](../verify/n100_algebra_proof_interface_contracts.py)已实现。测试实际退出0，[当前证书](../verify/out/n100-algebra-proof-interface-contracts.json)记录六个小地图、实际n100候选及9项负控制。

## 地图到模型

compile_map先独立检查顶点/边端点及连通性，再调用已有通用编译器验证dart面、顶点链、边两侧所有者、外边界、四个有序轴标和Euler关系。平行边仍用独立边id，不能只保留端点对。输出绑定完整地图及模型指纹、变量布局与约束数。

这只编译一个声明的连通地图。它不证明所有n100可能地图均已出现，也不证明四轴编译细分的边数等于规范化边界细胞B。有效地图的几何必要性和更高层枚举完整性依旧是单独桥接前提。

本轮六个小地图模型与旧证书逐项一致；实际候选的全部编译多项式也逐项一致。实际候选没有同面两个固定轴标，双轴规则返回NOT_EXCLUDED。

## 通用负一证书

模型使用f_j=0、g_i>=0。证明格式为

-1 = sigma_0 + sum_i sigma_i*g_i + sum_j h_j*f_j，

其中每个sigma由带非负有理权的显式多项式平方和表示，h_j为任意有理多项式。核验器逐项展开稀疏单项式、合并所有系数，必须精确等于常数-1；仅浮点评估负值、随机点测试或PSD数值猜测都不接收。

域上限使用明确的平方半径T，加入T-t>=0。证书绑定原模型指纹，所有多项式变量下标和约束引用均检查。变量固定只能由原模型中非零一次单变量等式推出，不能根据候选数值直接代入圆心或t。

此格式覆盖显式因子SOS、Farkas非负常数乘子和等式理想乘子。尚不直接接收未经分解/核验的Gram矩阵，也不承担寻找SOS证书的优化问题。它是验证已有精确证书的接口。

## 实际双轴模式

同一面覆盖两点P,Q给出

t-|P-Q|^2/4 = (g_P+g_Q)/2 + |c-(P+Q)/2|^2。

固定轴坐标由编译模型中的实际轴等式核验。若L=|P-Q|^2/4>T，则与T-t>=0相加并除以正的L-T，生成严格的负一证书。端点T=L不排除；本轮六个小地图在T=1时均保留这一闭边界。

六个小模型在U^2处排除。相邻轴对仅要求T<1/2、相对轴对要求T<1；这属于结构子族排除，不能从六个样本推断所有剩余地图被排除。

## 独立与控制

主核验只用Fraction稀疏多项式。测试用当前安装的SymPy精确Rational独立展开六份证书，并对任意P,Q,c坐标的通式做符号零断言。另测试一个Farkas特例和一个等式理想特例。

9项拒绝控制：负SOS权、错误模型、普通半径冒充平方半径、浮点系数、无依据圆心固定、越界约束引用、错误平方偏移、断开地图、错误面所有者。自动生成入口也先检查上限为非负精确数据，避免没有触发模式时绕过类型约束。

## 组合及成本输入

代数叶只排除其绑定的完整多项式域；放入树时必须再绑定该节点的地图、变量布局及额外域约束。一个子域的代数无解不能排除父域。多个证书对同域可逻辑求交，不累加面积亏损。

若平方多项式有a项，朴素平方至多a^2个乘积；两个稀疏多项式乘法按项数积计价，合并系数还需计入有理数位长。验证成本由证书项数决定，寻找SOS/枚举地图的成本另计；不能用很短的验证时间推断搜索时间。SymPy交叉核验与主Fraction核验也应分别计时。
