## 已独立重放的指定方向

[逐杆证书](../verify/out/n100-rod-force-transfer.json)修正了二维锚点根箱速度误差预算，父会话执行[独立检查器](../runtime/n100-rod-force-transfer/independent_check.py)实际exit0。全部406条区间重建一致：196正、210负、未定0。仅说明所指定锚点角方向及其谐延拓无法直接给出一阶缩半径可行运动；不排除相同锚点速度配合其他自由节点速度。

## 新增：所有根处速度的一阶对偶

[精确检查器](../verify/n100_first_order_rod_dual.py)最终实际exit0；[机器证据](../verify/out/n100-first-order-rod-dual.json)包含493个驻定多项式系数检查、406正距离乘子根箱、权重和为1、438个旋转恒等式及2个破坏控制。

记每条活跃杆平方长度的一阶变化为l'_j，边界单位约束导数为u'_k，规范导数为g'。在已认证精确KKT根处，驻定恒等式给出

`Σ_j α_j l'_j + Σ_k ν_k u'_k + γ g' = 0`。

角方向满足单位圆切向条件u'_k=0；旋转规范可令g'=0。故`Σ α_j l'_j=0`。归一化`Σ α_j=1`、α_j>0。因此若所有杆满足一阶可行不等式`l'_j≤t'<0`，则`0=Σα_j l'_j≤t'<0`，矛盾。这排除了该根处所有具有严格负一阶t变化的逐杆可行运动，不限于已测试的一个方向。

规范不是“中心y=0”：源系统固定中心74的y为一个非零有理值。脚本初次把值误设为0而exit1，随后读取真实metadata并修正。局部规范消除只需中心74的x非零：减去角速度ω=velocity_y(74)/center_x(74)的无穷小整体旋转，使g'=0；杆长与单位圆切向性不变。非零x由根箱验证，未要求规范值为零。

## 下一步和严格边界

这是根处的一阶Farkas式接口，来自已接受KKT根；不是新增全局下界，也不是更强的局部SOSC。若t'=0但t''<0，一阶对偶不足以排除；原54维切空间SOSC提供局部二阶信息，但用于连续域证明树的LOCAL叶还需显式邻域半径和非线性余项预算。

下一执行单元应把根箱、约束Jacobian、正权重和SOSC下界组装成定量邻域排除定理，并验证其对所有满足逐杆不等式的附近点成立。之后还要覆盖候选图其余域和87族其他拓扑。不能从本轮证书升级为r_D(100)等于候选根。
