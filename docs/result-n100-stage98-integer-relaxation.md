# 阶段98：当前矩形聚合松弛的整数可行见证

## 实证

`python verify/n100_arc_lens_integer_relaxation.py`及`python verify/n100_arc_lens_integer_relaxation_independent.py`均退出0。

生产证书：verify/out/n100-arc-lens-integer-relaxation.json。独立证书：verify/out/n100-arc-lens-integer-relaxation-independent.json。

## 为什么测试整数见证

阶段97证明固定delta、固定径向及透镜外包下，最优仿射支持线仍不能排除k54。该证书是凸优化层面的结论，尚不能单凭它断言整数圆盘数的聚合模型也可行。本轮直接构造整数重数，避免混淆分数凸组合和整数可行性。

## 明确定义的松弛

沿用阶段96选中delta=7/250、半径U。每个服务圆周圆盘选择一个保守矩形[0,p_i]×[0,C_i]，坐标分别为半弧长和内部面积容量；尾端允许[0,M]×{0}。这些矩形只是必要条件外包，端点的弧长与面积不必能被同一个真实圆心同时达到。

聚合模型要求：所有服务圆盘半弧长之和至少pi；内部容量和加上非服务圆盘完整面积预算至少pi*s²。没有角位置、圆心坐标、圆盘交叠浪费或覆盖每个目标点的约束。

## 有理整数见证

- 34个圆盘选择第41个径向矩形的右上端(p41,C41)；
- 20个圆盘选择尾端(M,0)；
- 46个非服务圆盘，各计入完整面积预算。

全部重数为非负整数，总数100，服务数54。程序使用更严格端点验证：弧长总和大于pi_hi；容量中完整圆盘仅计pi_lo*r²，而目标面积使用pi_hi*s²，仍有严格正余量。精确余量保存在证书。

这些不等式使见证对pi括号内任意真实pi均满足聚合约束，但不代表实际面积预算可独立达到或真实圆周弧能无浪费铺满。

## 独立验证

独立脚本从阶段96数据重新读入源矩形，检查重数整数性、所有点位于所选矩形、半弧长和容量总和、保存余量及文件绑定。两个篡改控制（非整数格式重数、超出矩形容量）均被拒绝。未导入生产见证生成器。

本轮依赖阶段96已经核验的几何外包数据；没有重跑65536条积分外包。所证明的是这些固定保守数据的聚合松弛可行，不是实际几何构型可行，更不是最优覆盖存在性证明。

## 对后续路径的约束

当前固定矩形外包加总弧长、总面积和整数圆盘数的模型，有一个显式可行点。任何对这些完全相同约束的逻辑后果，都不能合法判空该模型。若要取得新排除，必须收紧外包、换用额外内部圆或其他容量信息，或加入圆心位置、角次序、交叠等空间相关性。

不将此局限推广为所有单圆盘或聚合方法的普遍不可能定理。只涉及当前delta、有限外包和明确列出的约束。
