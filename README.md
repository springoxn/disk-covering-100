## 问题

令 `D = {x in R^2 : |x| <= 1}`，则

```text
r_D(100) = inf { r : D ⊆ ⋃ B(c_i,r), i=1,...,100, c_i ∈ R² }.
```

中心不受限制，圆盘和目标均取闭集。构型优化只能给存在性上界；普适下界需要对所有中心配置的排除及完整的几何归约。
