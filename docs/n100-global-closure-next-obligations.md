## 2. 路线 A：有限见证 / 有理对偶的采样松弛（发现层，不是证明）

### 2.1 形式化与"什么才算认证"

```
M(r) = max { μ(D) : μ ≥ 0 测度, μ(B(c,r) ∩ D) ≤ 1  ∀ c ∈ D }        （分式覆盖数）
```

* **正确**：若 `n` 个半径 `r` 的闭盘覆盖 `D`（中心可先投影进 `D`），则
  `n ≥ Σ_i μ(B(c_i,r)∩D) ≥ μ(D)`（每项 ≤ 1 是关键），故 `M(r) > 100 ⟹ r_D(100) > r`。
* **正确**：旋转平均把可行测度化为径向且不损失（`D` 与约束集旋转不变）。
* **认证 `M(r)` 上界需要的**：一个**连续可行**的中心测度 `ν`（`ν(B(p,r)∩D) ≥ 1` 对**所有** `p ∈ D`）
  及其质量 `ν(D)`。"有限壳 + 有限采样约束"**不构成**原问题的连续上界：壳内均匀是测度类限制
  （使最小值偏大），采样约束是约束放松（使最小值偏小），两者方向相反、误差不可控；
  旋转平均**不**修复这个径向离散化。

### 2.2 变量与约束（可复现）

壳边界 `0=t_0<…<t_K=1`；变量 `m_k ≥ 0`（点壳质量，面积 `π(t_{k+1}²−t_k²)`）；
约束在每个中心半径采样 `s_g ∈ {壳边界} ∪ {壳中点}`（`2K+1` 个）：

```
Σ_k m_k · A[g,k] ≤ 1 ,  A[g,k] = [Λ(s_g,r,t_{k+1}) − Λ(s_g,r,t_k)] / π(t_{k+1}²−t_k²)
```

`Λ(S,r,T)` = 两圆透镜面积（闭式，已与独立数值积分对照，6 例最大偏差 `2.1e-7`）。
原侧用同一矩阵（透镜面积对两半径对称）在**同一采样网格**上检查覆盖。

## 3. 路线 B：边界胞亏损引理（分析草案 + 采样对手族）

### 3.1 引理 L1（长弦角亏损）

> 设凸胞 `Q` 有 `k ≥ 3` 条边、`Q ⊆ B(c,r)`（`0<r<1`），`m` 为 `Q` 的 MEC 中心；`Q` 的一条边是
> `∂D` 上的弦、弦长 `l = 2sin(g/2)`。若 **`l > r` 严格**，则该边在 `m` 处的扇角
> `θ₁ ≥ t₀(l,r) := 2asin(l/(2r))`，且 `area(Q) ≤ r²Φ(k, max(t₀, 2π/k))`，
> `Φ(k,t) = ½[sin t + (k−1)sin((2π−t)/(k−1))]`（`Φ(k,2π/k)=f(k)`，回到旧界）。

证明三步（草案，未形式化）：
1. `area(Q) = ½Σρ_jρ_{j+1}sinθ_j ≤ (r²/2)Σsinθ_j`（`ρ_j ≤ r`）；`m` 在 `Q` 内部时 `Σθ_j=2π`、`θ_j ≤ π`；
   `m` 落在边界（顶点 / 边）时需"向内平移 `ε`、半径 `r+ε`、取单侧极限"。
2. `cosθ₁ = (u²+w²−l²)/(2uw)`，`u,w ≤ r`。令 `t=l/r`：`∂F/∂u = (u²−w²+t²)/(2u²w) > 0`（`t ≥ 1`），
   故最大在 `u=w=1`，即 `θ₁ ≥ 2asin(l/(2r))`。**这一步要求 `l ≥ R`（当前半径）**；用内移极限时
   当前半径是 `r+ε`，故仅 `l > r` 严格时极限可用；`l = r` 的退化情形（弦端点与 MEC 中心重合、
   扇角无定义）**未覆盖**（数值上非退化下确界恰为 `π/3`）。
3. `sin` 凹 + `Σθ=2π` ⟹ `Σsinθ_j ≤ Φ(k, max(t₀,2π/k))`。闭式已与独立单纯形网格 / 随机极值对照
   （k=5 的 61³ 网格、k=6 的 2e4 随机点，松弛 ≤ 1.2e-3 = 网格分辨率）。

**父 agent 的二次主导式已独立复核为真**：`sinθ ≤ √3/2 + (θ−π/3)/2 − (θ−π/3)²/4` 在 `[0,π]` 成立，
等号仅在 `θ=π/3`（该式在此**相切**：`F(π/3)=F'(π/3)=0`；`F(0)=0.068271`、`F(π)=0.816600`、
`F'(0)=π/6−1/2>0`、`F'(π)=3/2−π/3>0`，`F''=sinθ−1/2` 在 `π/6,5π/6` 换号 ⟹ `F'` 先减后增再减、
只在 `π/3` 归零 ⟹ `F ≥ 0`）。本轮把它作为**独立校验项**记录（JSON `validations.sine_quadratic_majorant`）；
它不能替代第 2 步的 `l > r` 条件。

### 3.2 引理 L2（弧胞透镜上界，独立第二重心）

> `Q` 凸、含 `∂D` 上测度 `g` 的弧的弦、`Q ⊆ B(c,r) ∩ D` ⟹ `area(Q) ≤ Λ(g,r) := |B((d*,0),r) ∩ D|`，
> `d* = cos(g/2) − √(r²−sin²(g/2))`。

* 引理 A（外向单调）：`s ↦ A(s)=|B((s,0),r)∩D|` 不增；`dA/ds = −∫_{∂D∩B((s,0),r)} x₁ dσ ≤ 0`
  （该弧上 `x₁ ≥ (1+s²−r²)/(2s) > 0`，`r<1`）。数值：2001 点网格最大增量 `0.0`。
* 引理 B（最小可行中心距）：弦两端点到 `c` 都 ≤ `r` ⟹ `|c| ≥ d*`（凸性 + 对称轴）。
  数值：网格最小范数 − `d*` ∈ `[1.2e-5, 1.5e-4]`（正值，= 网格步长量级）。
* 推论：`Λ(g,r)` 对 `g` 单调不增（`dd*/dg ∝ [cos(g/2)/√(r²−sin²(g/2)) − 1] ≥ 0`）。

### 3.3 合成（塞回锐化包络）

```
area(Q_i) ≤ r² min{ f(k_i), Φ(k_i, t₀(γ_i,r)), λ(γ_i,r) } ,  λ = Λ/r²
area(P) = Σ area(Q_i) ≥ π h(asin r)          （包络下界，不变）
Σ k_i ≤ Σ e_i ≤ 594 − B , B ≥ 29 , 弧胞数 k_arc ≥ ⌈2π/2arccos(1−r²/2)⌉ = 29 (r=L)
RHS(B,r)/r² = [a(594−B) + 100β] − k_arc(r)·min_{k∈{5,6}} max(0, f(k) − max(Φ(k,t₀(2π/B)), λ(2π/B,r)))
矛盾判据（仅对该采样族）：π h(asin r) > r² max_{29≤B≤297} RHS(B,r)
```

退化胞说明：每条逐胞上界都非负（`deficit ≤ f(k) ⟹ f(k)−deficit ≥ min(f(k),Φ,λ) ≥ 0`），
所以零面积胞自动满足 `area = 0 ≤ 上界`，**无需**额外的"补 π 扇角 / padding"处理
（父 agent 提出的该构造本身正确，只是不必要）；只需 `deficit` 不超过 `f(k)` 这一点。
