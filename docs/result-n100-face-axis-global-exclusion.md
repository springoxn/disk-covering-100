# 面内双轴标记：精确平方和全域排除

[检查器](../verify/n100_face_axis_global_exclusion.py)实际执行退出0，[回执](../verify/out/n100-face-axis-global-exclusion.json)保存六个完整小模型域的排除证书及通用结构规则。

对同面两个固定轴点P,Q，定义gP=t−|c−P|²≥0，gQ=t−|c−Q|²≥0。精确恒等式为

 t−|P−Q|²/4=(gP+gQ)/2+|c−(P+Q)/2|²。

右侧为两个有效约束的非负有理倍数加两个平方。因此任何闭可行赋值都满足t≥|P−Q|²/4，允许重合圆心、零几何边及折叠。固定轴坐标在等式约束下精确代入；无需浮点优化或局部根。

实现按面遍历定位原模型两条距离约束，精确替换全部轴坐标，使用Fraction稀疏系数字典逐项验算上述恒等式。回执记录实际约束索引、1/2乘子、两个平方的中心坐标索引及偏移。错误常数控制被拒绝。此次没有第二套独立SOS验证器，因此独立全域证书复核仍待补。

结果：六个V4,E5,m2,B4地图均有一个面包含相反轴点，故全域t≥1。它们在t≤(1154469548855829/10^16)²均不可行，包含此前t=1可行赋值，二者一致。一般双轴同面结构至少给出t≥1/2，故对当前百盘上界下所有地图均可作为完备前置剪枝规则。四个轴标记必须分属不同的承载面（每标记可以关联多个面，但没有面同时含二轴）。这是必要条件，不是全部图计数。

百盘候选没有双轴同面，检查结果不触发；本轮未排除候选本身或其外邻域。小规模参数族全域排除不能解释为m≤99所有分支排除。未完成百盘合法地图族枚举、其他连续域排除及全局等号证明。
