# 阶段60：同顶点约束冗余审计与交替传播

## 对开头假设的修正

原计划增加同一核心顶点incident面圆心的两两距离<=2U。对562条面—顶点关联精确重建面集合后，同顶点无序面心对共有265对，与既有核心共边邻接对完全相同。另以alpha边两侧独立重建邻接集合，逐对相等。故该计划没有新增约束，不能宣称强化了数学模型。

## 实际实施的强化

阶段49圆周与共享顶点传播从阶段42邻接固定点出发，但之后不再交替执行圆心邻接承包器。本轮先将圆周/共享顶点传播到固定点（最多160轮），再每轮交替：

1. 一遍32边界顶点的圆周/象限承包器及562条面—顶点距离承包器；
2. 一遍265个圆心邻接对，两个方向分别使用距离<=2U承包器。

全部判定使用整数；盒仍表示实区间，不限制为整数格点。

两个测试方案的结果：

| placement | 额外总盒宽缩减（缩放单位） | 交替轮数 | 状态 |
|---|---:|---:|---|
| [30,6,14,22] | 0 | 1 | 非空固定点 |
| [20,27,2,9] | 746 | 3 | 非空固定点 |

缩减总量包括面心与核心顶点的所有坐标区间宽度，是相对于圆周/共享顶点基线固定点的额外缩减，不能与阶段58只含100面心的指标混淆。

主实现使用既有circle/contract，独立实现使用独立setup、circle和clip。邻接集合由独立边两侧方法重建。逐案比较完整最终盒、逐轮邻接变更计数和固定点状态，全部相等。基线由主实现计算，之后两实现从相同基线盒出发，因此本证书对新增交替步骤作独立重放；不单独认证此前所有基线推导。

没有新增严格排除；固定核心累计仍576排除、4200保留。真实候选保留。下一步若扩展本方法，应对4200域实际运行交替传播并记录严格空盒；本轮没有完成该全扫描。

仍仅为一个固定核心的必要松弛，machine_verified_geometry=false，global_optimality=false。全局最优性、完整核心枚举和极小多项式尚未完成。
