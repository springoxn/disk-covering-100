# 阶段72：离散闭弧次序与整象限单调支持

`python verify/n100_arc_monotone_cycle.py`退出0，证书`verify/out/n100-arc-monotone-cycle.json`。

输入仍为代表[14,21,28,3]的node27与真实候选[30,6,14,22]的两套阶段70有限关系，并未扫描其他叶或其他根。

## 相邻弧段次序

同象限内参数t随CCW次序不减。标签j的闭区间为[j/256,(j+1)/256]。相邻标签j,k允许某个不减参数选择，当且仅当j<=k+1。不能误用j<=k，因为j=k+1时仍可在公共端点相等。

全部65536对标签用Fraction端点比较独立核对；公共端点保留和严格倒序拒绝控制通过。核心边界用正向/逆phi两种遍历重建一致。每案32关系中28条同象限关系加入次序。

结果：node27额外拒绝41578个弧段对，候选拒绝47956对。弧相容后分别仍有1866、2312标签；精确闭环支持没有额外删除。每次删除日志按集合操作重放，位动态规划与集合动态规划一致。

## 相邻控制不能替代全序

标签序列5,4,3在每一步都满足j<=k+1，但不存在整体不减参数选择：首点至少5/256，末点至多4/256。脚本保留这一反例控制。

为消除该松弛，在每个象限从第一个顶点起维护此前标签下端最大值M。当前标签j必须满足M<=j+1，更新M=max(M,j)。M只可能等于j或j+1，因此可用两个状态2j+flag编码；跨象限重置M=j。整个闭环从象限切换处开始，以免象限组绕过锚点。扩展后的有限模型仍可用精确闭环动态规划处理。

两案位实现与独立集合/关系实现一致。结果仍为1866和2312个标签全部支持，未判空。各保存30条锚见证，逐条断言所有边关系、参数闭区间成员性及同象限参数单调性。见证的参数值为(j+flag)/256。

## 结论与边界

本轮加强的是离散必要关系。见证的参数选择满足次序，但尚未验证这些具体点与圆心之间的距离条件；pair关系只说明对应弧段外包通过必要检验。因而不能称作连续覆盖配置。

该有限关系模型即使加上整象限单调实现仍有解，不能靠反复运行相同关系排除两输入。下一步可固定见证弧段，测试内部连续几何传播，或加入共同圆心与内部顶点的更强相关约束。没有新增严格叶/根排除，固定核心仍576排除、4200保留。
