# 阶段97：自由截距支持线的精确原始—对偶证书

命令`python verify/n100_arc_lens_free_intercept.py`及`python verify/n100_arc_lens_free_intercept_independent.py`均退出0。

## 检验目标

阶段96对每个径向区间提供半弧长上界p_i及透镜面积上界C_i，另含尾端(p,C)=(M,0)。之前使用cap<=a(M-phi)，预设截距b=aM。本轮改为自由截距cap<=b-a*phi，a>=0，要求全部C_i+a*p_i<=b。

在这些固定保守外包及delta=7/250下，k54对应最小化54b-a*pi_lo。本轮用精确有理直线上包络得到最优线，不使用浮点。

## 结果

最优线接触第41个径向区间与tail尾端，b=aM仍成立。此时仍不能排除k54。相较阶段96目标值的严格微小改善仅来自不再将斜率向上舍入到分母10^12，不能归功于自由截距这一放宽。

计数域与原域交集仍1328个三元组，新增删除0。支持数据、凸包折点、所有不等式松弛量与精确目标保存在生产证书。

## 独立对偶验证

独立脚本不调用凸包算法，直接从原支持证书重建所有513个约束，核对最优线满足每个约束。

设两个接触点为(p0,C0)、(p1,C1)，计算精确lambda使lambda*p0+(1-lambda)*p1=pi_lo/54。检查lambda与1-lambda均非负，则任何可行线均满足

`54b-a*pi_lo >= 54[lambda*C0+(1-lambda)*C1]`。

保存的可行线恰好达到该下界，原始与对偶目标有理数完全相等，故确实为这份固定外包模型中的最优支持线。该证据比仅网格选最好斜率更强。

## 适用边界

这证明：在阶段96选中delta及512个径向外包、128条透镜积分外包的当前精度下，单纯放开仿射支持截距不能排除k54。它不证明更精细的外包、其他delta、非线性容量条件或真实几何问题也无法排除k54。两个对偶接触点是保守外包数据，不是可行圆盘覆盖构型。
