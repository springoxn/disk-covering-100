# Disk covering benchmark: n = 100

本仓库公开 n=100 等圆盘覆盖单位圆盘的研究材料、验证脚本、最终证书和路线记录。

## 当前可公开结论

在本发布包绑定的证书链中：

> **`r_D(100) > 0.113235` 已有六分支证书；`0.11324` 尚未闭合，B36 仍有严格残余。**

不要把未完成的 `0.113236`、`0.113237` 或 `0.11324` 候选写成已证明结果。

## 一键本地检查

需要 Python 3.10+，仅使用标准库：

```powershell
python reproduce.py
```

该入口检查最终 JSON 是否存在、状态是否为 PASS、候选半径是否为 `22647/200000`、六分支总账是否闭合，并打印证书摘要。它是发布包的端到端**证据一致性检查**；历史 pair 域重放脚本仍保留在 `verify/`，但其部分上游几何依赖没有在本仓库重复复制。

## 目录

- `verify/`：n=100 验证和独立复核脚本；公开所有已整理的 n=100 路线入口。
- `verify/out/`：与最终结论直接相关的精简证书链，不包含大型中间运行树。
- `tools/`：发现、参数扫描和路线工具；浮点结果仅作发现，最终证书使用有理/区间检查。
- `docs/`：阶段报告、失败路线、残余、预算审计和工程化复现记录。
- `runtime/`：公开状态与少量交接材料；不包含服务器凭据、第三方源码或大规模缓存。
- `ROUTE_INDEX.md` / `route_manifest.json`：当前所有 n=100 线路的脚本与报告索引。

## 最终证书链

- `verify/out/n100-candidate-complete-225.json`：六分支组合证书。
- `verify/out/n100-six-branch-ledger-226.json`：候选半径事实源。
- `verify/out/n100-tail-candidate-224.json`：B36/B>=36 完整 pair 域证书。
- `verify/out/n100-candidate-budget-222.json`：标量预算守恒证书。
- `verify/out/n100-radius-scan-219.json`：`0.1132301` 到 `0.11324` 的有理诊断扫描。
- `docs/result-n100-stage229-current-best.md`：当前严格最佳值和未决范围。

## 证据边界

B31–B35 及 B>=37 的排除证书可按半径单调性继承到更小的候选半径；B36 在 `0.113235` 下有独立完整重放。目标半径 `0.11324` 的旧 pair 松弛存在精确障碍点，因此本项目明确保留该残余而不夸大结论。

历史实验路线保留是为了可审计和便于改进；`PASS` 只表示对应证书范围内的机器检查通过，不表示所有路线都构成全局最优性证明。
