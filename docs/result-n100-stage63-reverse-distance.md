# 阶段63：等距反向平方收缩

入口：`python verify/n100_voronoi_reverse_distance.py`。正式重跑实际退出0。证书：`verify/out/n100-voronoi-reverse-distance.json`。

同顶点v关联的圆心a、b满足共同距离平方属于两个区间外包D(a,v)、D(b,v)的交集，并不超过ceil((UQ)^2)。对每一坐标w=a_k-v_k，从共同距离目标扣除另一坐标平方范围，得到w²的必要范围。平方反解必须保留正负两支，先各自与当前w区间相交，再取其并集的区间外包；用w和v反向收缩圆心a，也用w和a反向收缩v。没有把实未知量限制为整数格点。

平方根下界向下取整，上界向上取整。两实现分别使用isqrt与纯整数二分平方根，并分别调用主/独立圆周和距离承包器。两实现共享区间公式、控制流、输入设置；仅为替代算术实现比较，不能称为完全独立端到端证明。

483个有理点外包控制通过；严格拒绝、双分支取外包及单侧分支控制通过。33案（完整32项间隙类加真实候选）最终盒与状态在两实现间完全相等。

结果：33 fixed、0 excluded、0 capped、0额外盒宽缩减。首跑缺少Path导入，传播完成但证书未写出而退出1；修复后完整重跑退出0，正式证书才作依据。

本轮测试说明当前宽盒上，这个反向承包器也未带来收益。没有扫描4200全域，没有新增全局结论。固定核心仍576排除、4200保留。等距必要性仍依赖Voronoi核心的解析归约，machine_verified_geometry=false，global_optimality=false。
