# n=100 阶段1：严格基线恢复与证据审计 goal

## 范围与完成含义

承接 [交接报告](../handoff-n100-research-plan-2026-10-11.md)，只推进其中的阶段1。长期研究目标仍为 [正式题面](../docs/goal-n100.md) 的精确全局最优性；完成本 goal 不代表求出 r_D(100)。

规划前已读取三个历史事实源，确认覆盖和下界的强度标注存在冲突。本地路径检索没有返回名称含 n100 的正式 verify 文件；历史 freecover JSON 含 best.P 坐标字段，但数量、精确解释、覆盖性尚未重新验证。约 0.1223432713 与约 0.1109141386 均为待审计历史记录，不能直接充当严格有理端点。

## 持久化 objective

完成 n=100 阶段1：恢复并固定至少一份实际100中心精确输入与来源哈希；建立完整连续覆盖的整数/有理/有理区间认证及可重放证书，输出安全有理上界 U；逐条审计历史逐胞面积、圆弧 cap、Euler 记账、弧覆盖、通有化及退化分支，区分已证与未闭合义务，给出实际可支持的普适有理下界 L。若历史加强界未闭合，保留经证明的面积下界 1/10。提供统一复现入口、基线审计及状态交接，实际运行并记录退出码、环境、哈希和证书条目；最后拟定阶段2/4小规模试验建议，不执行新搜索或服务器重算。

自动续行上限12轮，是会话预算，不是计算规模或完成期限。额度耗尽且验收未完成时维持未完成状态。

## 执行顺序与分工

1. 主代理恢复输入：追溯自由点、极坐标、profile 结果，核实100个有限二维中心、排序、重合、缺失值与生成参数。恢复代数格点须固定整数索引；历史十进制也可作为有理数精确定义一个构型，再重新认证安全半径。不得把舍入坐标当成原代数构型。
2. 同阶段并行两个有界子任务：A 审计候选极值完整性并实现覆盖验证；B 审计下界义务和退化。主代理整合、运行；产物形成后再安排独立检查。子代理口头结论不能替代证书。
3. 覆盖侧证明有限候选归约，或使用完整域分割的有理区间证书。处理内部极值、边界分界、单中心边界极值、零中心、共线、共圆、重合、相切以及等号筛选。Delaunay、网格、浮点仅用于发现。分割不终止时记录原因，调整安全裕量或换精确方法，不放宽判定。
4. 下界侧建立解析义务—适用范围—证明—证书条目表。n25 的实例 Euler 证书不证明 n100 普适性。历史加强界仅在全部前提闭合后提升；否则标待证。保底面积论证写明 π≤100πr²，因此 r≥1/10，并保存精确算术条目。
5. 统一入口在干净输出目录重放，核对输入与代码哈希，失败非零退出并保留失败对象；未决盒不可省略。用独立检查器或另一方法复核，并披露共享依赖。
6. 写审计、修正状态、交接：明确 L、U、证据强度、未决义务和实际资源开销。阶段2/4仅形成预算及停止条件建议，执行另起下一阶段。

所有子代理显式使用 provider `deepseek-official`、model `deepseek/deepseek-v4.1-flash`、reasoning_effort `high`，即 CommandCode 的 DeepSeek-V4.1-Flash (CC)。本次已通过模型目录核实路由。

## 验收条件

- 至少一份100中心精确输入可重放，来源与转换可追溯，哈希固定。
- 安全有理 U 有完整连续覆盖充分性论证与证书，涵盖边界、退化，严格判定没有浮点。
- 普适有理 L 有明确解析证明与精确检查；历史未闭合加强界不称已证。允许保底下界完成阶段1，但报告明确降级原因。
- 统一入口实际退出0，记录环境、命令、哈希和证书条目；分割证书完整覆盖根域且记录终止叶，或有限候选归约完整性已证明。
- 检查器拒绝至少一个有针对性的损坏证书或输入不匹配，独立复核说明方法和共享依赖。
- 审计与状态不冲突；全局最优性、极小多项式、局部最优仍按真实证据标注；建议不写成已执行。

## 边界及异常处理

本地只执行本阶段必要的输入恢复和证书计算，先攻小单元。服务器只读检查可定位已有材料；需要连接或传输时加载相应技能。服务器数据重算仍须明确授权，本 goal 不含该授权；不得改服务器环境。

已有文件先读、时间戳备份再修改；UTF-8 使用 read/edit/write 或显式编码 Python。新增产物用 n100 专名，保持与小n及 n11/n12 产物独立。

缺失最佳输入先追溯脚本和已有结果，不用新优化代替审计。义务有反例或缺口则保存证据并修正结论。仍有可执行工作就继续，不把困难当完成；需要缺失材料或外部授权时记录具体条件，遵守 goal 工具续行规则。
