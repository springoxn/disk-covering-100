## 4. 关联图拟合

## 6. 精确层（可机器判定，全部在 Q 内）

冻结的十进制字面量本身就是精确有理数，所以最深活跃三角形的几何可以**精确判定**，不需要区间算术：

- 精确外心 `x*` 是有理点（分母 53 位十进制），`r²` 是有理数，分母 **108 位十进制**（356 bit）。
- 三个精确平方距离 `|x* - c_a|²` 两两之差 **精确等于 0**。
- 精确重心乘子之和**精确等于 1**，三者**精确严格为正**，且都 `> 1/4`。
- 精确恒等式 `Σ_a λ_a (c_a - x*) = 0` **精确成立**（两个分量都为 0）。
- 因此："`x*` 严格落在活跃三角形内部"这一单洞一阶驻点条件是**精确定理级**的事实，不是数值观察。

**这个精确层的边界（务必连同上一段一起引用）**：

- 它**证明**的是：这三个冻结十进制中心的外心精确有理、三距离精确相等、乘子精确为正且和为一、驻点恒等式精确成立。
- 它**不证明**：`x*` 是 `d(x)` 在单位闭盘上的全局最大（那是浮点 evaluator 的枚举论证，本文引用而不重证）、枚举完整、`r = |x*-c_a|` 是该构型的覆盖半径、该构型覆盖圆盘、或任何关于 `r_D(100)` 的事。
- 标签 `trivial_minpoly_of_this_decimal_triangle`（`t² - r²`）是**合法的精确陈述，但只是这个三角形的外接半径多项式**，不是覆盖半径的多项式；其分母 108 位十进制 ⇒ 无信息。**本文不做任何 minpoly 声明。**

## 7. 代数模式尝试：无可信候选

方法：PSLQ（mpmath，dps = 50）**提议**，精确有理算术**裁决**。因为输入是精确有理数，"是否精确成立"是可判定的；只要精确残差非零就是伪关系（本仓库相对判据的执行方式）。

输入精度窗口（17 位冻结有效数字，度数 d 的关系高度 H 需 `≈ d·log10 H` 位）：`d=1 → H ≤ 1e16`，`d=2 → H ≤ 1e8`，`d=3 → H ≤ 1e5`，`d=4 → H ≤ 1e4`。

| 目标 | 高度上限 | 结果 |
|---|---:|---|
| `deg1_in_rho` | 1e8 | 无提议 |
| `deg2_in_rho` | 1e8 | 无提议 |
| `deg3_in_rho` | 1e5 | 无提议 |
| `deg4_in_rho` | 1e4 | 无提议 |
| `deg1_in_x_y_rho` | 1e7 | 无提议 |
| `deg2_in_x_y` | 1e8 | 1 个提议，**精确残差非零 ⇒ 拒绝**（系数高度 `7.36e7`） |
| `deg2_in_x_y_rho` | 1e4 | 无提议 |

- 7 个目标里 **0 个**得到精确关系；6 个窗口 PSLQ 穷尽高度范围也没找到任何东西。
- 唯一那个非精确提议**不能被读成"接近结构"**：这里的目标是精确有理三角形的外心，其分母 108 位十进制，搜索的残差分辨率约 `1e-108`，所以 `|A| ≈ 7.8e-41` 不含信息。裁决依据是**精确不成立**，不是"残差够小"。
- 17 个量的最佳有理逼近扫描：没有一个是异常逼近（最小 `误差/(1/(2q²)) = 0.0083`，来自 68 次试验；68 次独立试验中最小比值本就该是 `O(1/68)` 量级），**0 个**是精确小有理数。
- 已考察并明确拒绝的"准巧合"：活跃三角形一角 `56.999642°`（距 `57°` 有 `3.6e-4°`，即 `6.3e-6` 相对误差，是冻结精度的 `1e10` 倍，且三取一撞上整数度概率 `O(1)`）；`rho/alpha` 不是简单有理数；`R = 18761/156250` 是 7 位上取整而非几何量。

**判词：本构型是泛型浮点点，没有可信的有理/代数关系候选。**

## 8. 唯一的实质结构：晶格继承已被摧毁

工程里唯一已知的代数构型是 lattice-97 种子（实坐标 `a*(u, √3 v)`，`a² = 3/67`，数据是高度 ≤ 7 的整数，位于四次域 `Q(√3, √67)`，覆盖半径 `alpha = 1/√67`，`rho` 与 `alpha` 之比 = 1）。

- 归一化（格点单位）下 `rho = 0.982818233`（< 1，即该 anchor 把晶格覆盖半径改进了 1.72%）。
- 最深洞在归一化坐标 `(u, v) = (0.422908, 1.805637)`；最近的格点 Voronoi 顶点是 `(1/2, 11/6)`（即 `u = 1/2, v = 11/6` 那族），距离 **0.0908 格点单位**（= 0.01921 实单位）。
- 中心相对 lattice-97 种子的位移：中位 **0.1014 格点单位**（实单位 min `0.000551`、中位 `0.021460`、max `0.043320`）；三个活跃中心位移 `0.010281 / 0.016267 / 0.024389`。
- 结论：形变是格点间距的 ~10%，即冻结精度的 `10^15` 倍。**`Q(√3, √67)` 的代数继承没有存活**，晶格域给不出这张候选的精确证书捷径。

## 9. 判词与建议下一步

**判词**：`algebraic_structure = none credible`；`generic_floating = true`；同时 `structural_structure = 一个严格内部的锐角 Voronoi 顶点，乘子精确为正，被 2.222e-4 的相对落差孤立`。

**为什么"孤立单洞"是下一步的关键**：极小化极大的 KKT 点通常要让**若干洞同时顶到上界**；这里只有 1 个临界点达到最大值，次深洞低 `2.222e-4`（相对），而搜索自己的记录（[`NOTES-run.md`](../runtime/n100-cooperative/NOTES-run.md)）写明 rounds C8..C12 **接受 0 次改进**（`trust_region_collapsed_no_improvement`）。也就是说：线性切平面模型卡住了，而非线性问题未必没有空间。

**建议：精确驻点延拓（exact stationarity continuation）**，四步、每步可独立验证：

1. **先在浮点层面重新平衡**：从冻结中心重启 sequential-LP 切平面，但 (a) 见证带放宽到 1e-3（收集全部近距离临界点，而不是只看 argmax），(b) 每个接受步之后重新放大信赖域，(c) LP 数据用精确有理数。目标：**≥ 3 个近并排的洞**。
2. **写出精确驻点方程组**：固定各洞活跃集 `A_h` 后，高精度（mpmath，≥ 200 位，牛顿法，冻结点作初值）解：`|x_h - c_a| = rho`（`a ∈ A_h`）、洞的定心方程、乘子方程 `Σ_h Σ_{a∈A_h} λ_ha (c_a - x_h) = 0`、边界洞的 `|x_h| = 1`。本文 §6 已在 Q 内验证了**单洞**情形。
3. **再做代数候选**：对**高精度根**（不是浮点）跑 LLL/PSLQ，用本仓库的相对判据；然后造 minpoly + 有理隔离区间并精确认证。模板：`tools/n11_kkt_hp.py`、`verify/krawczyk_n11.py`、`verify/minpoly_checks_n11.py`。**在此之前不得做任何 minpoly 声明。**
4. **必须回到精确证书**：任何改进构型仍须按父 agent 对 `R = 18761/156250` 的做法，用精确重放（`verify/coverage_n100.py` + 独立 checker）对显式有理 `R` 复核。

**禁止项**：不要把冻结十进制当代数数；不要从 17 位浮点宣布 minpoly；不要用镜像对称猜测去做平衡（实测镜像映射最大残差 `0.199`，没有可用对称约化）；不要用本文件里的任何数字去改 `verify/` 或状态层。
