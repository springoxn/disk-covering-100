# n=100 阶段36：真实地图的三价核心与四轴细分往返

入口：`python verify/n100_cubic_core_roundtrip.py`，实际退出0。证书：`verify/out/n100-cubic-core-roundtrip.json`。

本阶段在真实100盘候选上实现通用位置地图的轴点压缩。顶点旋转sigma=phi∘alpha；每个二价轴点被跳过，沿两个边组成有向细分路径。保留端点半边编号、核心alpha/sigma/phi、完整细分路径以及轴标签。

实测：原图V202/E301/F101（含外面），压缩后V198/E297/F101，每个核心顶点度3。所有细分路径按有向半边划分全部602个原始半边，反向路径与alpha配对一致。恢复算法从路径重新构造原始alpha、sigma，再构造phi，逐项与原图比较完全一致，面类型及四轴标签也完全一致。损坏细分路径负控制被拒绝。

## 枚举接口的意义与边界

对阶段35的通用位置图，若四轴均可被压缩，删除四个二价点后有V_core=2m-2，E_core=3m-3，F=m+1。这给出一种潜在枚举入口：生成带指定外面的三价球面地图，再沿外边界插入四个有序轴点。不同轴可以落在同一核心边，插入顺序和重数必须保存；不能只枚举四条不同外边。

压缩后环边、平行边均不得擅自删除。当前实现不合并这些边，也不要求核心为简单图。原始编译器仍要求恢复后的面简单、外边界简单和四轴顺序合法，生成器需要对恢复结果重新验收。

特殊低盘数/仅轴点组成的连通分支不属于本次实现适用范围；实现明确拒绝没有保留端点的轴点环。当前百盘候选及潜在m>=96域不由低盘数特例测试代替必要性证明。

这里仅核验一幅真实地图的可逆表示，不是所有三价核心的完备生成器，也没有对所有四轴插入方案去重、模型求解或新排除。半径区间、87计数族、全局最优性和极小多项式状态不变。
