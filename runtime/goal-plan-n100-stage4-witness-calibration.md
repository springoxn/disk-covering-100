# n100 阶段4首个 goal：有限见证点证书的小n校准

## 已确认的起点

已在本轮实际执行 `python verify/run_strengthened_lowerbound_n100.py --out verify/out/strengthened-lowerbound-stage4-baseline-replay.json`，退出0。原证明和原审查不修改。当前严格区间仍为 `554570693/5000000000 ≤ r_D(100) ≤ 1223433/10000000`。

## 本 goal 的边界

建立本地、精确、端到端的有限见证点下界原型，先n=8，再重用完整几何证书校准n=9、10。不承诺改善n100下界。禁止用中心网格代表任意实中心；闭盘相切和共交须纳入。

采用有限点最小包围圆与平面凸集Helly定理：点子集可被半径r闭盘覆盖，当且仅当每个至多三点子集可被覆盖。枚举所有可实现覆盖子集的极大元素。此族覆盖任意实中心的覆盖模式；无需显式分层枚举中心圆排列。有限子集的精确判定用有理平方距离、二点中点和三点外心。

先用至多32个单位盘内有理见证点、半径 `7/25` 校准；该阈值是工程校准，预期明显弱于已知小n最优值，若成功也不宣称下界研究突破。用 `3/10` 的有限见证可行覆盖作非排除对照；它不认证连续单位盘覆盖。增加相切、共线、重复点、锐角三角形（三点约束）、共圆四点对照。

## 完成判据

1. 独立证明模式完整性，明确解析部分未形式化。
2. 生成器在整数/Fraction层枚举模式；独立checker不导入生成器，以最小包围圆候选点判定子集。
3. 精确有理权重满足每模式总权重≤1、总权重>n，认证n=8、9、10不可行。
4. 负对照包括伪造权重、漏模式、提高半径、盘外见证点，实际拒绝。
5. 新输出全部位于独立路径，提供真实退出码、规模、耗时、代码/证明哈希与重放命令。
6. 报告小n与n100的强度限制；若校准只证明已被面积界涵盖的阈值，明确标记，不直接扩展到n100大规模计算。
