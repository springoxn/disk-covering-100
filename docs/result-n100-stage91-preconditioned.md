# 阶段91：固定中点预条件的双平分线组合

命令：`python verify/n100_voronoi_preconditioned.py`，实际退出0。证书：`verify/out/n100-voronoi-preconditioned.json`。

## 新组合不依赖变量行列式可除

对三所属圆心a,b,c，平移原点至顶点盒整数中点o。两条平分线写为C·x=r、D·x=s，其中x=v-o。用圆心盒中点的双倍坐标构造固定整数系数矩阵的adjugate，将这两条方程作固定线性组合，不除以变量行列式。

若某行的固定系数为(r0,r1)，新变量系数按中心分别分组为

`2[-(r0+r1)*a + r0*b + r1*c]`，

新右端为

`-(r0+r1)*|a-o|² + r0*|b-o|² + r1*|c-o|²`。

分组消去同一中心重复出现的线性依赖，避免简单相减造成的额外膨胀。固定中点矩阵奇异则跳过；非奇异也不据此声称真实变量矩阵始终非奇异。组合后某坐标系数区间避开零时可对该坐标收缩，区间商逐次用Fraction端点审计。

## 解释与范围

相较阶段90全部变量行列式区间含零而跳过Cramer除法，此法在两个分支确实激活了部分标量求界，但这些界尚未收紧现有顶点盒。不能把可除系数增加写成几何剪枝。后续仅更换除法或重复当前固定点传播不能产生新收缩，需要更强的圆心相关性或其他全局约束。
