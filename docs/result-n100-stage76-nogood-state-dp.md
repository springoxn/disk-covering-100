# 阶段76：直接累计禁配满足状态的精确闭环DP

命令：`python verify/n100_arc_nogood_state_dp.py`，实际退出0。证书：`verify/out/n100-arc-nogood-state-dp.json`。

## 新状态

此前两条禁配通过选取各自一个必须避开的标签，枚举40和9个子域。现在在闭环DP中直接使用(j,M,S)：

- j是当前弧段标签；
- M是同象限已访问标签下端的最大值，用于全序参数可实现性；
- S是已被某个不匹配标签满足的禁配位集合。

访问顶点v、选择标签j时，对每条禁配c，若c包含(v,k)且j!=k，则将c的满足位置1。满足位只作OR累计。闭环末端要求所有禁配都已满足，并且最后一个标签与起始锚标签在继承二元关系中相容。

每象限起点重置M=j；其他点要求M<=j+1，再更新M=max(M,j)。锚点取在象限切换后，末边不需要跨锚保留象限前缀值。前向记录可达状态，后向记录可闭合且满足全部禁配的状态，由此求所有标签支持，不只是找单条见证。
