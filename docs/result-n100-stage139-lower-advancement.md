## 尾部真实瓶颈

[六分支推进表](../verify/out/n100-lower-advancement-priority.json)由[汇总入口](../verify/n100_lower_advancement_priority.py)实际退出0生成。旧尾部lambda、K、mu、L不变时，总预算允许的半径阈值落在

11323679462887/10^14 <= R_threshold < 113236794628871/10^15。

这只是旧固定系数总预算的阈值，不是最优半径或该算法理论极限。R=0.11324时旧尾部总预算约-0.000160907，故就算旧局部支持仍有效也不能闭合。若mu和lambda不动，新截距必须严格小于约0.007505530351154887。

试候选L=0.007505后，条件总预算约+0.0000190926，但完整二维局部支持必须重验。首轮25万盒验证接受124491个叶、剩17个待处理栈项，返回UNDECIDED，没有遇到不可细分叶。栈项数少不意味着剩余工作少，也不证明候选支持成立。

[尾部试验入口](../verify/n100_tail_new_radius_trial.py)已发起450万盒预算扩大试验，输出目标为verify/out/n100-tail-new-radius-fulltrial-139.json。本报告写入时尚待结果，不能认定通过；后续以实际回执为准。若未决，必须保留原始失败/预算原因，不把它称为原覆盖构型反例。
