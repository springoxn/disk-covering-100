# 第3轮：高维隐藏对称与子问题转换的精确边界

本轮对用户提出的三种结构做了精确化。符号恒等式和一个倾斜五边形例子由[独立脚本](../verify/n100_cover_transfer_identities.py)实际exit0，回执见[JSON](../verify/out/n100-cover-transfer-identities.json)。

## 高维隐藏对称

若单位二维圆盘D嵌入高维线性平面P，任意高维球心c到P的正交投影π(c)满足

`|x-c|² = |x-π(c)|² + dist(c,P)²`，`x∈P`。

所以把高维球心投影到P，距离逐点不增；反向把二维构型嵌入P，距离不变。自由高维等球覆盖这个固定二维目标的最优半径与二维问题相同。高维增加的是参数化和潜在群作用，不是新的覆盖能力。

隐藏对称可以存在。脚本构造了一个有理倾角的三维正五边形：

`(cos θ, (3/5) sin θ, (4/5) sin θ)`。

它保持三维单位圆上的正五边形关系，但投影到前两个坐标后，投影范数随θ变化；例如θ=0的范数平方为1，而θ=2π/5的范数平方为`(15-2√5)/25<1`（相对1的损失是`(10+2√5)/25`）。因此三维构型的C5对称不成为二维欧氏等距对称。准晶式cut-and-project还需要选窗和投影度量，不能把高维周期性直接当成二维最优证明。

## 细化：从小覆盖构造大覆盖

若单位盘有k盘半径a覆盖，单位盘有m盘半径b覆盖，则每个半径a大盘内缩放放置m盘，得到km盘半径ab覆盖：

`r_D(km) ≤ r_D(k) r_D(m)`。

若只需要n≥km个盘，复制中心即可保持覆盖。非均匀大盘半径a_j和内部比例b_j也给出统一半径`max_j(a_j b_j)`、盘数`Σm_j`的构造上界。这个关系可以把已认证的n=12配置用于构造12倍数的上界，但不能从12的最优性反推4或100的最优性。

## 粗化：从已知大盘构造少盘上界

给定n盘半径r覆盖，分成k组G_j。若组内中心都落在半径a_j、中心z_j的圆盘，三角不等式给出k盘半径`r+max_j a_j`覆盖。对n=12可尝试四组三个中心，用每组最小包围圆求出合法n=4构造；这只是上界。要从它得到n=4最优值，必须证明所有n=4覆盖都可逆细化，当前没有这种等价定理。

## 对n=100的现实用法

1. 把100中心按接触图或几何位置分组，计算宏观包围圆，只能产生粗粒度上界或候选初值。
2. 把n=12或其他已证配置嵌套进宏观盘，只有当乘积盘数不超过100时才给出合法上界；这很难击败当前0.115446...上界，需要实际认证。
3. 若用子块分解，接口上的边界孔、共享中心和逐杆距离必须保留。独立子块最优不推出带接口的全局最优。
4. 当前87组必要族仍未完成拓扑枚举；第2轮已证明固定应力谐延拓凸性路线不可用。因此本轮不声称n=100得到新的数值界。

## 严格边界

本轮证明了投影支配、细化不等式和粗化上界转换；没有证明任何n=100全局下界、无损对称归约、最优子问题等价、连续覆盖全局排除、不可约性或真实极小多项式。
