# n100接口时间校准设计（采集前版本）

本文件在正式重复计时采集前固定设计。阶段129的全4776重认证耗时仅作诊断，不进入校准样本。接口整理与依赖核对完成后才执行本设计。

研究问题：对每项必要条件，分别预测准备/发现、证书核验、冷调用、同快照热调用和安全重放组合的成本；再判断同域合法组合的实际排除重叠及顺序收益。不能用短证书核验预测证书发现，也不能将不同几何域的排除率比较为方法强弱。

实验单位是一次进程中的一次完整工程任务；同一进程内部的重复调用仅为热路径测量，不能称为独立进程重复。记录进程、block、输入哈希、方法、规模、最大分子/分母位长及缓存状态。只作工程预测和测量区间，不声称统计显著性或总体无偏排除率。

## 分块与执行次序

先固定7个进程轮次block。在每个block内，用seed=12920261011的Python Random对象打乱可比方法/规模任务次序并保存完整schedule。每个热任务先做一次不计入测量的预热，再记录5次调用；报告block内中位数及7个block中位数的范围/中位数。原始5次不可伪装成35个独立进程样本。

冷进程数据包括解释器启动/导入，另记录函数级冷上下文耗时。文件缓存无法通过Python可靠清空，明确标为进程冷、操作系统缓存未控制；不称磁盘冷。将所有方法按固定顺序连续执行会混入温升/后台负载，采用随机次序降低这种偏差。记录Python/平台/CPU信息、开始结束时间和失败任务；不因慢而删点。

本地同一硬件为主要适用域。长全量重认证、其他繁重工作仍在运行时不采集正式计时，以免已知负载混入。绝不凭计时结果改变数学接受条件。

## 规模与成本分解

|接口层|改变的规模|准备/搜索|核验/热路径|
|---|---|---|---|
|Hall/自动匹配|圆盘n、目标k、候选边E、整数位长|边构建、匹配发现|子集亏损/完整匹配重放|
|有限容量与盒模式|目标k、圆盘n、权重稀疏度|子集/模式枚举、DP|独立MEC/能量或加权容量核对|
|LOCAL|圆盘n、标签置换|根数据与证书链加载|角点包含、置换/有理旋转|
|计数/耳域|标签数T、耳装饰分支数|357标量上下文重算|排序去重和集合筛选|
|弧帽/透镜/自由截距|径向段J、条带S|参数发现另计|保存支持J或JS重放；热计数公式|
|多目标径向轮廓|目标T、类型D、条带S|积分包络|变重数后的TD求和|
|连续盒|变量V、约束C、扫描S、位长|图编译及前提加载|每原语/整轮/全收缩双实现|
|Cramer/预条件器|所有者三元组数|组合生成|固定维区间算术、64角点诊断|
|有限循环/nogood|标签d、变量n、冲突g与长度|关系建立及连续冲突学习|状态DP与prod(clause lengths)独立子域oracle|
|完整空间树|节点N、每节点传播预算|分支选择/生成|全部叶、分裂覆盖和轨迹重放|
|地图/精确代数|边/面/变量数、稀疏单项式数|地图或SOS搜索另计|编译、稀疏系数、独立SymPy|

现有固定保存证书只能校准其实际规模，不能把一个J/S样本拟合成可靠的多参数复杂度律。对可生成的受控输入另设规模梯度；至少保留一个未参与系数拟合的规模预测，再报告实际/预测比。位长变化与几何难度可能耦合，报告这种限制。

指数方法先以k=3/5/7等小规模测试，再在预定成本预算内扩展；超限记录为预算截断，不外推伪精确秒数。多项式/指数操作模型来自代码循环与位复杂度分析，实测只估本机常数及偏差。

## 组合研究

只在相同父域或经过已验证适配的域上组合。按同一有限输入集逐个记录判定向量，直接计算A、B、A并B、A或B排除集合及增量；不乘边际排除率。共享预算仍仅允许逻辑求交，不能重复加面积。

顺序比较在同一输入集合上跑A->B、B->A，遇到已认证排除才短路；UNDECIDED不得短路为排除。分别计无共享缓存、同次快照共享上下文、安全全重放三种实现。缓存键包括输入域/半径/映射/前提文件哈希，另设改输入后缓存失效控制。

对于当前已被递归计数支配的弧帽条件，明确预测其增量排除为零；计时仍有成本，不能把历史k55排除写成当前404标签域的新增收益。对不可比MEC/盒能量和稀疏权重例，使用已认证有限见证集展示互补性，不能推广为随机全图成功率。

## 报告规则

逐方法列出模型、位长、证书/发现分离、适用规模、原始测量、block摘要、留出预测误差及失败/预算截断。宏观全n100全局搜索时间只有在地图数/树规模模型足够时才给区间；否则写未知瓶颈，不给虚构年数。

本设计由experimental-design技能提示分块、次序随机化和避免伪重复；工程模型和实际任务清单由本项目实现决定。正式执行计划若需修改，先版本化并说明修改发生于采集之前还是之后。
