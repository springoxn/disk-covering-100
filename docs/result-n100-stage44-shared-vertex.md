# n=100 阶段44：共享顶点耦合盒传播

## 新增约束

在阶段42的面心盒基础上，为核心每个组合顶点引入一个未知顶点盒，初始为缩放单位正方形[-Q,Q]^2。对每个内面边界dart d，将面心盒与其起点顶点盒连接，加入

`|c_f-v_d|² <= U²`。

这是面顶点距离约束的区间松弛版本；它没有强制边界顶点落在单位圆，只保留单位盘必要条件，也没有加入同一顶点的圆周等式。因而空盒可排除，非空盒不代表几何可行。

核心内面半边总数为 `2E-B=2*301-32=562`，每个案例有562个唯一面—顶点关联，传播每项双向更新。

## 修正版结果

修正版入口 `verify/n100_shared_vertex_boxes.py`，输出 `verify/out/n100-shared-vertex-boxes-v2.json`，实际退出0。两个案例为阶段42首个保留方案 `[0,6,12,18]` 和真实候选 `[30,6,14,22]`：

- 均无空盒排除；
- 均在1轮后达到固定点；
- 每案2248次双向收缩；
- 真实候选保留。

独立入口 `verify/n100_shared_vertex_independent.py --out verify/out/n100-shared-vertex-independent-v2.json` 实际退出0，重新计算面循环、顶点循环和562项关联；两个最终盒、固定点状态和收缩计数完全一致。

## 实现修正记录

首版传播错误地把同一面—顶点约束循环加入两次，主结果为4496次收缩；独立重放首先以字段层级错误退出，修正后又发现面关联总数应为562而不是597。首版未作为证书依据。随后重写主循环为唯一关联、另存v2证书，独立v2重放通过。旧v1文件保留为历史，不代表当前结果。

## 范围
