# n=100 阶段33：内部顶点模型与固定轴点两点 SOS

主入口：`python verify/n100_one_interior_models_independent.py --out verify/out/n100-one-interior-axis-pair-sos.json`，实际退出0。

## 内部顶点族

固定组合地图参数 `V=5,E=7,B=4`，一个内部顶点、三个内部面、面边界简单、允许平行边和二边形：

- 3,628,800 个残余面置换；
- 768 个合法有序轴标记地图；
- 16 个规范轨道；
- 独立重复端点辐条构造得到同样16个轨道。

16个轨道的每个模型都被独立重建：模型约束按有理系数逐项比对，轴边界点和内部中心原点给出精确有理可行赋值用于接口检查。

## 两点 SOS 排除

若同一面必须覆盖两个固定点 `p,q`，则对任意中心 `c` 有恒等式

`2(t-|c-p|²)+2(t-|c-q|²)+4|c-(p+q)/2|² = 4t-|p-q|²`。

因此必要条件是 `t >= |p-q|²/4`。检查器用Fraction逐项验证该恒等式，16个内部轨道的最大固定轴点对下界均为1；现行 `U²<1`，所以这16个小地图连续域全部排除。该排除只依赖固定轴点和同面约束，不依赖浮点。

真实602半边百盘候选的负控制没有这样的同面固定轴点对，最大下界为0，检查器保留它；没有产生虚假的n100排除。
