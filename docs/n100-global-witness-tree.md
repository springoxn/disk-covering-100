# 无接触图假设的全域见证树接口

本阶段实现有理盒分割完整性与见证叶检查；没有构造 n=100 完整树，也没有改善已接受区间。

## 1. 全局规范域不丢失覆盖

令目标为单位闭圆盘 D。若圆心 c=s u，s>1、|u|=1，将其投影为 u。对 x∈D，

|x−su|²−|x−u|²=(s−1)(s+1−2x·u)≥(s−1)²≥0。

因此任意覆盖可逐圆心投影进 D，半径不增。所有 n 个圆心使用带标签的 D^n，允许重合和冗余；任何 m<n 构型可复制中心补足 n。无需预先枚举有效中心数、一般位置或拓扑。

在平方半径范围 [0,T] 下，规范域是 D^n×[0,T]，包含于 [-1,1]^(2n)×[0,T]。检查器要求全域根盒恰为此立方盒，允许用 OUTSIDE_CENTER_DISK 叶排除规范域以外的部分。

## 2. 两种叶与分割完整性

WITNESS 叶给出有理点 p∈D。对圆心第 j 个坐标矩形 I_x×I_y，检查器用点到矩形的精确最短距离平方

L_j=dist(p_x,I_x)²+dist(p_y,I_y)²。

若全部 L_j>T_leaf，则每个配置在 p 都不能覆盖，整盒排除。严格大于不可换成大于等于：闭圆盘允许相切。

OUTSIDE_CENTER_DISK 叶若某圆心矩形到原点的最短距离平方严格大于1，整盒不含规范域配置。

SPLIT 节点选择某坐标的严格内点有理切分，两个闭子盒恰为 [lo,cut] 与 [cut,hi]；子盒完全由父盒继承，不接受调用者另行给出的子盒范围。遍历禁止循环、共享节点、缺子节点和未到达节点。归纳于有限树，两子盒覆盖父盒且每叶有合法排除，因此根盒排除成立。分割面重复包含是允许的，不存在遗漏。

## 3. 严格次优端点存在有限见证树

以下是解析证明，不冒称形式化内核证明或机器算出的百盘树。

固定有理 T<r_D(n)²。规范域 D^n×[0,T] 紧。任一配置不能覆盖 D，故存在点 p，使所有 |p−c_j|²−t 严格正。连续性给出该配置附近的一致正裕量。即使 p 在圆周上，也可先稍向圆内移动，再以有理内点近似，保留严格裕量；所以可以选有理见证点。

对立方根盒中规范域以外的点，至少一个圆心范数严格大于1，也有开邻域可由 OUTSIDE_CENTER_DISK 判据排除。这样所有根盒点均有某种可排除的开邻域。根盒紧，有限子覆盖存在；取网格足够细，闭网格盒的直径小于有限子覆盖的 Lebesgue 数，每个闭盒落在某个排除邻域内。点到矩形的精确距离下界随盒宽收敛到点距离，故进一步细分后对应的严格叶判据成立。有限网格可以由轴向二分树产生。

这证明对每个严格低于最优值的固定有理 T，穷尽二分并枚举有理见证的搜索存在有限成功证书。它不给任何可行的复杂度预算，也不意味着当前端点已达到。

当 T 等于最优平方半径时，最优覆盖无法被见证叶排除。因此该接口不能独自处理等号邻域；已有代数 LOCAL 叶需要通过单独验证的叶接口组合，或逐个严格次优有理端点形成另有统一证明的极限论证。尚未实现此组合。

## 4. 本阶段实际验证

运行：`python verify/n100_global_witness_tree.py`。

[脚本](../verify/n100_global_witness_tree.py)使用整数与 Fraction，显式异常检查，不依赖 Python assert。实际退出0；[运行证据](../verify/out/n100-global-witness-tree-interface.json)包含：

- n=1 全域三节点树：x≤0 用 p=(1,0)，x≥0 用 p=(−1,0)，排除 t≤99/100。
- n=100 受限盒：全部中心坐标在 [−1/2,1/2]，t≤1/5，p=(1,0) 逐心距离平方至少1/4>1/5；允许100圆心全部重合。该盒不是百盘全域。
- 圆心 [4/5,1]² 的规范域外叶，最小范数平方32/25>1。
- 13项负控制全部拒绝，含严格端点失败、漏分支、循环、共享节点、无效见证、受限盒升级全域及百盘全域假排除。

独立完整树实现/对抗审查尚未完成；本报告的解析紧性归约也未形式化。没有百盘全域排除证书，没有最优值极小多项式。
