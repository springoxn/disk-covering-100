# 阶段49：边界圆周等式首次排除一个保留轴方案

## 模型与外包

继承阶段42已经验证的100个面心坐标盒，添加198个核心顶点实坐标盒，所有坐标乘Q=2^20。整数端点表示连续实区间，不是把未知点限制到格点。

外环32条边由外面phi循环反向后取alpha配对重建。每个顶点的起点沿边界次序落在相邻固定轴间的闭象限；轴i插入在边p_i内，因此该轴后的第一个原核心顶点是边p_i+1的起点。主实现逐轴遍历间隙，独立实现逐边检查唯一循环区间，并核验每条边终点等于下一条边起点。每个案例强制32个不同边界顶点和562个内面—顶点关联，不允许空集合验收。

对每个边界顶点v施加|v|²=1及对应象限。对每个内面f的关联顶点v施加|c_f-v|<=U。省略四个新增轴细分顶点、圆周严格次序和其他模型等式，只会放宽域，因此严格空盒足以排除该方案。保留盒不提供可行覆盖。

## 圆周收缩保守性

将已知象限转为非负区间x∈[a,b],y∈[c,d]。如果a²+c²>Q²或b²+d²<Q²，则该盒不能与圆相交。否则从x²=Q²-y²得到

sqrt(max(0,Q²-d²)) <= x <= sqrt(Q²-c²)。

下界取floor sqrt、上界取ceil sqrt并与旧盒相交，仍为所有实解的外包。y同理，使用同一旧盒。恢复符号后再做面心—顶点距离收缩。有限次组合通过归纳保留每个满足必要条件的实配置。空盒只在严格不等式出现时成立。

顶点象限顺序是几何地图到边界顺序归约的解析依赖；该归约未在形式化内核证明，machine_verified_geometry=false。二进制方根、整数比较和全部传播步骤实际执行复核。
