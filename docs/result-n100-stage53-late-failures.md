# 阶段53：12个深传播晚失败的整数见证

阶段51新增的12个排除在第59、60或153轮才出现。主提取器实际退出0，独立提取器实际退出0。

12项分成四个轴间隙类，每类3项：

- (6,13,6,7)
- (13,6,7,6)
- (6,7,6,13)
- (7,6,13,6)

所有失败类型仍为面心—顶点distance，不是边界圆周盒自身为空。每案保存失败的两个整数盒、变量索引、盒间最小坐标距离平方、`ceil((UQ)^2)`和严格正余量。独立脚本重新从深传播证书计算这些量，并逐项比较主摘要；12项余量全部严格为正。

证据：
- verify/out/n100-boundary-circle-late-failures.json
- verify/out/n100-boundary-circle-late-failures-independent.json

该结果显示晚失败具有四重循环间隙模式，但失败索引有3类，尚不足以写成一个不依赖具体盒坐标的组合引理。它可作为后续空间分支的优先模式；不能把四个间隙类直接推广到其他核心。

当前固定核心结果仍为576严格排除、4200非空保留。全局核心枚举、全局最优性和极小多项式不变，machine_verified_geometry=false。
