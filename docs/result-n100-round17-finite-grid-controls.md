# 第17轮：实际候选上的有限见证密度校准

本轮不是新的toy排除叶，而是对当前932变量代数候选进行实测：四个明确的有理见证集均可用100个中点圆心在严格小于候选半径的范围内覆盖。因此这些见证集无法证明候选端点的最优性。

## 输入、构造和精确判定

[生成器](../verify/n100_finite_grid_candidate_controls.py)读取被冻结根中点与已接受预算的哈希绑定。圆心坐标分母D=10^60，平方半径根下界为t0−10^-58。对N=16,32,64,128，取全部(i/N,j/N)，i²+j²≤N²，再加入各象限有理圆周参数点

((1−s²)/(1+s²),2s/(1+s²)), s=k/N, 0≤k<N。

每个点到100个中点圆心的距离平方只用整数运算，精确取最小；所有点的最大值T_N严格小于代数候选平方半径下界。源脚本保存逐点可服务圆心标签，而非仅报告浮点最大值。

实际退出0，[主回执](../verify/out/n100-finite-grid-candidate-controls.json)记录四组点数861、3337、13109、51945和精确T_N、有理严格余量、最坏点标记以及全部分配。

## 独立复核

[独立检查器](../verify/n100_finite_grid_candidate_independent.py)使用Fraction重建点，圆周公式直接按s=k/N算而不导入生成器。它不重做最近点搜索，只逐点验证保存的圆心标签距离≤T_N，检查最大值达到T_N、T_N<t0−10^-58、全部点在D中，并绑定中点和生成器哈希。见[独立回执](../verify/out/n100-finite-grid-candidate-independent.json)。独立验证证明存在有限点覆盖，足以否定这些点集的端点排除力；不要求证明最优分配。

## 结论与限制

这是有限见证覆盖的真实可行性证据。它不说明对应更小半径覆盖连续单位盘；漏掉的孔附近可以仍然失败。也不排除不同见证集合、含代数孔的自适应集合或更密网格。

上一轮已证明纯非负单盘对偶在r>1/9无法排除100盘；本轮进一步表明，对这四组实际高密度见证，连整数不可覆盖证明也不可能在候选端点附近成立，因为存在严格更小的100盘有限点覆盖。

故不继续对这些已可覆盖的点集做昂贵整数搜索。下一阶段应回到配置耦合几何：全局有效中心/边界计数与接触地图枚举，或者为特定分支自适应生成持续孔约束。有限点网格只能做固定有理下界校准，不能替代等号端点的连续覆盖全局排除。

当前区间仍为11323/100000<r_D(100)≤1154469548855829/10^16，未证明全局最优，也未取得真实极小多项式。
