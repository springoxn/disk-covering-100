## 矩阵界和分解

J=Df(x*)，H是精确根乘子的拉格朗日Hessian。SOSC见证把J列分成439个可逆枢轴列B与54个自由列。令Z为核基，其自由行组成I；令R为仅枢轴行非零的右逆B^-1。于是任意h都可唯一写成`h=Zu+Re`，`e=Jh`，u为h的自由坐标。

根据回执的无穷范数、转置范数和根扰动界，预算核查

`||H||₂≤1`，`||Z||₂≤110`，`||R||₂≤500000`，`Z^T H Z ≥ (1/10000) I`，`||J||₂≤1000`。

最后一个J界由源约束多项式在整个根箱的各行绝对导数和重建，Frobenius范数支配谱范数。R界用`||B^-1||₂≤439||B^-1||∞`；这是粗但安全的界。核基界用`||Z||₂²≤||Z||∞||Z^T||∞`。SOSC转换为`W(Z^THZ)W^T≥(1-total)I`，所以核坐标曲率下界为`(1-total)/(||W||∞||W^T||∞)`，无需声称W本身正交。

写H0=1，Z0=110，R0=500000，μ=1/10000。Young不等式给出

`h^THh ≥ (μ/2)||u||² - K||e||²`，

`K=2H0²Z0²R0²/μ + H0R0²`。

取κ=10^21，预算验证`2κ-K≥1`。因此A=H+2κJ^TJ满足

`h^TAh ≥ (μ/2)||u||²+||e||² ≥ m||h||²`，`m=10^-12`，

因为`||h||²≤2Z0²||u||²+2R0²||e||²`且`m≤min(μ/(4Z0²),1/(2R0²))`。

## 非线性项与可行不等式

所有约束至多二次，因此有精确式`f(x*+h)=Jh+Q(h)`。距离行二次项为`||h_a-h_b||²≤2||h||²`，单位行至多`||h||²`，规范行无二次项。于是`||Q(h)||₂≤42||h||²`；42²≥4×439。这里没有忽略t，因为t在距离约束中只线性出现。

定义`Phi(x)=t(x)+Σλ_j f_j(x)+κ||f(x)||²`。根处f=0、∇Phi=0，由精确二次Taylor式得

`Phi(x*+h)-t* = 0.5 h^T Hh + κ||Jh+Q(h)||²`

`≥ (m/2 - 2κ·1000·42·||h||)||h||²`。

取半径ε=10^-40，预算验证`2κ·1000·42·ε≤m/4`。故在此邻域`Phi-t*≥(m/4)||h||²`。

另一方面，若单位与规范等式满足，406条杆满足f_j≤0，且`||h||≤ε`，则每条杆

`|f_j|≤1000ε+2ε²≤α_min/κ`。

正距离乘子α_j≥α_min使`α_j f_j+κ f_j²≤0`。因此`Phi≤t`，推出

**在固定规范和固定406杆的不等式域内，若0<||x-x*||₂≤10^-40，则 `t(x)-t*≥||x-x*||₂²/(4×10^12)>0`。**
