# 阶段110：原单位圆最紧切点的固定半径无耳条件

主程序与独立程序均退出0，完整检查17个外层(m,B)家族。

在固定半径r=355249/3125000=0.11367968，阶段109最紧层存活的17个家族中：

- (m,B)=(99,32)的归一化中心三角剖分不得有带两条边界边的耳面；
- (m,B)=(100,29)同样必须无耳；
- 其余15家族本轮未获得耳限制。

这里“无耳”不是“该家族不存在”。93个三元组、17家族的数量没有因此减少。

## 推导和认证

耳面使用三个连续边界站点，三个站点各自的赋值圆周弧落入以共同Voronoi顶点为中心、半径2r的圆盘，故三弧总角<=2asin(2r)。令其有理向上包络为gamma；本轮逐家族检查B*gamma<6pi_lo，故三弧集中组均值低于全局平均。

利用边界函数H_r的凹性，三弧组总角不超过gamma时，H和上界为

`3H_r(gamma/3)+(B-3)H_r((2pi-gamma)/(B-3))`。

加上联合中心/锚三角形面积基线`[(2m-B-2)A+B*kappa]r²`。上述两家族的总上界严格小于pi，排除耳面假设。

主程序采用上游有理级数和区间函数。独立程序使用更长反正弦级数确认gamma合法，重新构造pi、正弦和根式外包，完整重算17个家族的面积符号，并核对全部家族列表及来源哈希。全部实际触发的是面积判据；本轮没有使用剩余弧容量分支的排除结果。

## 范围限制

认证仅覆盖保存的固定半径。既有覆盖归约可能在改变半径或归一化时改变组合图，因此不能仅从固定半径证书推导全部r<=该切点的同标签无耳结论。若要接入区间搜索，需要另外完成余量与半径参数的一致上界，或证明无耳相关函数在目标范围的正确单调性。本轮未完成该项。

耳拓扑、共同图归一化和H凹性仍为继承解析依赖，独立有限算术没有将其形式化。
