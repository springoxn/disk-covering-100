# 第20轮：完整根盒上的边界最近圆心循环

本轮补齐候选32个边界孔之间的整弧Voronoi所有权；不声称已构造完整裁剪地图或枚举所有地图。

## 判据

以已接受的精确KKT根的边界孔q_h为端点。根方程保证|q_h|²=1、支撑对到孔等距；这些取等不是由区间重叠推出。本轮不重新求根。

对圆心a,b，令d=c_b−c_a，K=(|c_b|²−|c_a|²)/2。单位圆上最近a的半平面为d·q≤K；等距线与单位圆横截条件是|d|²−K²>0。

连续边界孔A,B满足cross(A,B)>0、dot(A,B)>0，所以构成角长小于π/2的逆时针短弧。支撑对交集只有一个owner。对每个其他圆心，端点非支撑距离差严格正，支撑处取等由根方程给出。若d的正方向不在A到B的正锥内（cross(A,d)<0或cross(d,B)<0），线性函数d·q在弧上的最大值在端点；即使负方向在弧内，该驻点为最小值。否则用K>0和K²>|d|²证明全圆均符合半平面。以上全部比较使用根盒有理区间。

32个孔的象限顺序单调，四象限均出现，并且每段cross/dot严格正，故边界绕行恰一次，无遗漏或多绕。
