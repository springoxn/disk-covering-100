\begin{remark}[Consequence for this document]
Every quantitative claim in Parts II--VI was checked against the artifact that exists in the parent
repository, not against the mirror. Where a number could only be taken from a stage report because
the underlying certificate is not in the mirror, the text says so or quotes the report. This is the
same discipline the programme applies to its own stages, applied to the publication layer.
\end{remark}

\section{Binding inconsistencies found by this audit}

Three binding issues were found and are recorded here rather than silently repaired.

\begin{enumerate}[leftmargin=1.6em,itemsep=3pt]
\item \textbf{The independent lattice receipt binds an earlier generation.} The independent replay
certificate {\footnotesize\texttt{verify/\allowbreak{}out/\allowbreak{}independent\_\allowbreak{}lattice97\_\allowbreak{}upperbound\_\allowbreak{}n100.json}} records
{\footnotesize\texttt{input\_\allowbreak{}sha256 = 7e732e189a0d69e30184dbd053ae2eda6ee588f0418d49553d71004e5f4ff475}} and
{\footnotesize\texttt{proof\_\allowbreak{}sha256 = a0454013448a2612475975b539d64fa722ab9e69434ca0d1d913bfba03d57d4b}}, whereas the
current main certificate file hashes to
{\footnotesize\texttt{7a98772a8fb4c608ca32ffe6489bf1f09006dd3c59a4322125beca8c1e72cd7d}} and the current proof file to
{\footnotesize\texttt{73d39456b70fdcae41ede5718a608d139661a6c7f2a626cf95b4e348be19600b}}. Its
{\footnotesize\texttt{checker\_\allowbreak{}sha256 = 9655d038a2194ebf2f849ad550ccc645f10c5f7516270d7dfe47267cb23ac878}} \emph{does}
match the current independent script. So the checker binding is current while the input and proof
bindings are stale: the independent replay was made against an earlier certificate/proof pair. This
does not invalidate the independent replay of the \emph{claim} (the $17$ checks pass on the current
inputs when re-run), but the receipt as stored is not a same-generation binding, and it must not be
presented as one.
\item \textbf{A referenced certificate path is missing from the mirror} (see the artifact-coverage subsection of Part VII).
\item \textbf{One documented constant is not in the published tree.} The tail budget uses a quantity
imported from the absorbed package; the local re-expression of the budget in
\texttt{verify/\allowbreak{}n100\_\allowbreak{}candidate\_\allowbreak{}budget\_\allowbreak{}222.py} uses
$A=129903810568/10^{11}$, and substituting it together with the frozen slope, penalty and marked
constant reproduces both stored margins exactly (see the budget re-check in the Appendix). The identity of
that constant with an outward rational enclosure of $3\sqrt3/4$ is an \emph{inference} from the
arithmetic, not a quotation from the package.
\end{enumerate}

\section{Negative-control inventory}

A certificate is accepted here only if its destruction tests are rejected. The battery in use
includes, across the routes: a scaled-up target disk (precondition only, explicitly not an uncovered
witness for the delivered claim); an explicit uncovered point for an enlarged-disk variant; a shrunk
and an enlarged covering radius; a wrong metric (the missing factor $3$ in the hexagonal inner
product); a rotated and an inflated hexagon; a truncated neighbour search; a misattributed
neighbour; two removed tangency centres; a removed interior centre; the $97$-centre configuration
submitted as a $100$-point claim; a single shell centre removed (coverage still holds --- only the
cardinality is rejected); a broken dart pairing; a broken face permutation; a support declared
inactive; an assertion-disabled run; a mismatched old radius; ten corrupted rational payloads; and
$8$ tamper tests on the local Krawczyk witness (zero inverse row, zero Cholesky transform, duplicate
pivot column, non-dyadic inverse denominator, wrong witness dimension, negated Lagrangian Hessian,
witness-source SHA mismatch, altered geometric polynomial source). Two entry points additionally
refuse to run under \texttt{python -\allowbreak{}O}.

\section{Environment}

The published runs use Windows 11 with Anaconda Python 3.13.5 (\texttt{sympy} 1.13.3,
\texttt{mpmath} 1.3.0, \texttt{gmpy2} 2.2.1, \texttt{python-\allowbreak{}flint} 0.9.0), and \texttt{tectonic} for
document building. The decision layer needs only the standard library: \texttt{fractions},
\texttt{decimal}, \texttt{math}, \texttt{json}, \texttt{hashlib}, \texttt{pathlib},
\texttt{itertools}. Symbolic work uses \texttt{sympy} for identity checking and factorization, never
as a substitute for a numerical certificate. Server-side discovery ran in a \texttt{crystalx}
environment with no environment installation; the six-candidate server search completed $916$
objective evaluations in $15.746$ s and recovered $25$ files whose SHA-256 all verified. The one
external-project replay required only a Windows compatibility layer (path separators, executable
names, LF output); the mathematical conditions, constants, intervals and counts were unchanged.
