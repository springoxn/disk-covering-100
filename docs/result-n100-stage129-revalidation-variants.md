# 阶段129：历史源失配全量重认证、变体接口与统一登记

## 本轮入口

[全量重认证程序](../verify/n100_boundary_circle_full_revalidation.py)逐项重放旧全量圆周传播的全部4776个固定核放置：当前主算法、独立算法完整结果相等，并分别与历史完整结果SHA256比较。输入集合同时核对父盒、旧结果和轴双链必要域的相同4776放置，拒绝缺项与重复。

[桥接审计入口](../verify/n100_interface_dependency_bridge.py)检查新执行收据的覆盖、输入/脚本哈希及所有结果，并将它仅用于旧证书的一条源哈希失配。它本身是轻量收据检查，不再次计算4776传播；重算由前述全量程序完成。桥接不改写旧证书，也不说明历史源变化的具体原因。

[隔离重放入口](../verify/run_n100_full_revalidation.py)提供--run-dir参数，在新目录复制输入和源快照再执行；不允许覆盖旧目录。复制源前后核对内容。该包装器参数入口已验证，整条快照包装运行本轮尚未重复执行，不把--help通过称为端到端快照重放。

## 全量重认证实际结果

[全量执行收据](../verify/out/n100-boundary-circle-full-revalidation.json)由上述全量程序实际生成，退出0：4776个主/独立/历史结果全部一致；564排除、4188不动点、24达到轮数上限。整体扫描562606071900ns约562.6秒，为单次混合负载诊断样本，不作为正式校准。

[桥接依赖审计](../verify/out/n100-interface-dependency-bridged-audit.json)实际退出0，零未桥接显式错误；缺放置、重复放置、伪造结果哈希和错误源桥接4项控制全部拒绝。原历史源哈希仍保留，改以当前双实现全部输出等价收据提供明确桥接。动态加载和解析前提的完整准入仍未完成，不把桥接后的静态审计称为全数学依赖证明。

## 剩余支持与连续变体

[变体接口](../verify/n100_proof_interface_variants.py)和[控制入口](../verify/n100_proof_interface_variant_contracts.py)实际执行退出0，[变体证书](../verify/out/n100-proof-interface-variants.json)记录：

- Cramer联合等距的147个有理外心控制；主/替代有理端点除法吻合。
- 固定中点adjugate预条件器的294个真实点控制，包含圆心不确定区间。该方法仍共享区间公式，不能称完整独立核验。
- 行列式64角点区间，验证多仿射展开；仅诊断零是否可能，不把奇异或非奇异当作几何不可行。
- 自由截距透镜支持全部513条约束重放，以及所保存矩形包络上k54的凸最优性条件。斜率非负、半径U和delta绑定。整个透镜支持另重放65536条带。
- 一个实际候选三所有者点在三种连续变体下保留；严格矛盾盒被排除，退化共线分支保留。
- 5项错误输入控制通过。

自由截距条件C<=b-a*phi求和后为sum(C)<=k*b-a*pi；它替换旧的b=a*M支持，而不是与其面积亏损相加。其最优性只针对保存的矩形包络和k54，不是精确可达几何包络的全局最优。

## 统一契约登记

[登记入口](../verify/n100_unified_proof_interface_registry.py)实际退出0，[登记表](../verify/out/n100-unified-proof-interface-registry.json)归并12组接口入口、20个家族契约模板，并定位生成时277个顶层相关源，未定位列表为空。之后增加的隔离重放包装器不在该生成时快照内，后续最终集成应重建当前快照。

入口统一列出域、半径单位、资源、解析前提和判定范围。仅登记的函数入口获准在其已核验范围内使用；任意旧main()输出、家族标签和未审查变体不能据此自动启用。所有方法默认只允许同域逻辑求交；异域需显式适配，面积预算默认不可相加。

该表仍不是所有277个源逐项语义审查完成的声明。支持脚本、反例、历史驱动与真正剪枝不同；剩余变体需要按模板确认其具体适配和依赖，而不必重复实现同一数学必要条件。
