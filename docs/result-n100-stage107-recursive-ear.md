# 阶段107：58盘递归内圆的耳三角形排除审计

主脚本先对归一化内圆半径 `t=U/(1-2U)` 的58盘首次存活分支做耳三角形测试；独立脚本第一次因比较不同精度外包后的字符串而退出1。该失败版本已保存为 `verify/n100_recursive_ear_obstruction_independent.py.bak-precision-mismatch`。改为比较安全的不等式后，独立脚本退出0。

## 结果

联合面积判据在58盘时保留内圆边界胞数

`B=24,25,26,27,28`。

若存在一个带两条边界边的耳面，则三个连续边界弧的总角可被半径`2t`圆盘控制。用`2 asin(2t)`的有理上界记为 `gamma`，再结合边界函数`H_t`的凹性，将这三个弧集中到总角`gamma`，其余`B-3`弧平均分配。主脚本用该上界和中心/锚三角形联合面积基线计算：

- `B=24`：严格面积亏损为正，耳面被排除；
- `B=25,26,27,28`：本证书仍未排除。

主证书见[耳三角形证书](../verify/out/n100-recursive-ear-obstruction.json)，独立证书见[独立耳复核](../verify/out/n100-recursive-ear-obstruction-independent.json)。

## 解析依赖

耳面拓扑条件来自归一化不可约圆盘图：带两条边界边的面使用三个连续边界站点，其三个圆周归属弧落在半径`2t`的共同圆盘中。边界函数凹性允许在固定三弧总角下使用集中组和剩余组的平均上界。联合面积基线沿用阶段105的中心/锚三角形判据。

这些几何、拓扑和凹性步骤仍是解析证明依赖；本轮算术证书没有把它们形式化为证明内核。

## 独立重算方式

独立脚本重新构造正弦级数、平方根区间、`gamma`及各B的边界函数和面积亏损。由于它使用不同位数的有理外包，不能要求与主证书字符串相等；正确的独立条件是：独立边界面积上界不小于主上界、独立三角形基线不小于主基线、独立亏损不大于主亏损，并且排除符号一致。该条件已逐B通过。

## 范围

这一步只排除58盘内圆中的B=24耳拓扑，不能排除58盘本身，因为B=25..28仍存活；也不能把内圆B直接识别为原单位圆的外部B。当前原问题在U处仍为404个三元组、57个家族，半径区间仍为

`11323/100000 < r_D(100) <= 1154469548855829/10^16`。
