# 阶段151至160：B33新度数窗口、低M闭合与严格高M残余

在R=2831/25000，恢复B33内部度数窗口5..8并关闭M<=25。B33高M尚未完整闭合；六分支全局仍只接受下界0.1132301。[当前六分支总账](../verify/out/n100-11324-six-branch-ledger-160.json)记录本阶段进展及源散列。

## 1. 用边界扇形剥离补足度4损失

原单星损失为Dd=dA-Sd-(d-1)h0，其中A=3sqrt(3)/4、h0=1/2-461134488/10^9。B33的实际旧归一化损失预算略高于D4，直接排除度4的原前提失败。但D3与所有d>=9的损失仍大于该预算，因此只需处理度4。

度4点p<=2时，少用一个标记anchor，损失至少D4+h0，已经超过预算。

p=3时，四个循环邻居全部是原边界点，三个标记循环边构成原外边界上的连续路径，剩余循环边为已存在的弦。四个完整中心三角面填满该扇形；路径中间两个原边界点的内部扇区已填满，没有连接其他内部点的额外扇区。

沿该弦剥离中心点、两个中间原边界点和四个三角面。原盘I67/B33/F165变为I66/B31/F161，剩余仍是一张简单三角化盘，所有保留下来的内部点星不变。如果它们度数都至少6，则一般/6盘等周不等式要求6F<=B²；但6*161-31²=5>0，矛盾。因此另有度3/4/5内部点。

原度4点仅与原边界点相邻，故两名内部低点不相邻，其完整星面不交；一个标记外边界边也仅有一个内侧三角面，anchor支付不重复。额外低星损失至少D5>0，所以p3总损失至少D4+D5，超过预算。两类p穷尽，度4完全排除。

[主精确证书](../verify/out/n100-B33-degree-window-151.json)实际退出0，新的窗口余量约0.01823，p3双星余量约0.09434。[独立有理复核](../verify/out/n100-B33-degree-window-independent-153.json)实际退出0，使用独立sqrt(3)/sqrt(5)有理括界和S5<6.23，枚举四种未标记循环边的位置，CAS核对剥离Euler恒等式及S5根式恒等式。平面扇形剥离、非负joint face-loss bank和一般/6盘等周依赖沿用已审查解析几何框架；不宣称定理证明器内核形式化。

## 2. B33低M完整闭合

[恢复窗口后的原行重放](../verify/out/n100-B33-after-degree-152.json)保留全部原面、顶点、位移及面积断言：低M前提全部通过，高M最终面积行仍负，分别记录。

原低M归约排除M<=24，并在M25仅留下唯一选中的深部度5、其他内部度数6..8、总高度曲率最多3。局部coherent五边星的冻结系数与实际低M表逐项核对一致，包括16个面支持；没有把别的面表收益移用到该行。

对M25基线负余量只做一次物理边抵消的coherent星形替换，所有6种高邻居循环类型均覆盖，规范化增益严格大于68/1000。保守最终面积余量为

5636333966847118183 / 250000000000000000000000 > 0.00002254。

[低M完整证书](../verify/out/n100-B33-low-complete-157.json)实际退出0、status=PASS、low_M_closed=true；它与低M前提中其他已接受分支的最小报告余量约0.00000294。选择唯一深部度5保证外侧面没有其他正势点，所有原高度点/原边界接口费用保留，边支付与局部收益不重复使用。

## 3. 高M：数值候选不等于接受

原有效K=11/25、hinge斜率3/100下，高M含至少一个度5的原行最终面积余量为

-103152691620873657833 / 250000000000000000000000。

改为K=3/5的数值候选预测正余量约0.00050898，但[新K精确回执](../verify/out/n100-B33-high-new-K-155.json)在全域规范化边界包络第一箱失败，未接受。随后数值同步K与实际hinge支持，所得最优预测余量仍约-0.00012070；[同步候选精确回执](../verify/out/n100-B33-high-synchronized-158.json)又在原局部hinge第一箱未通过。两者均仅保留为失败候选；区间下端点失败本身不等于构造了几何反例。

[高M严格残余归约](../verify/out/n100-B33-high-residual-159.json)实际退出0、status=PASS_REDUCTION。它没有接受负的一度5排除，而是重放原有效包络、原hinge、20类面、26类顶点及位移费用，证明上表四个排除。对M>=26，若仍有度5，则恰一个，M26/e0/b0；Euler迫使正高度曲率为27-26+1=2。因此含度5的残余只有两类：

- 唯一度5、两名度7、其他内部点度6；
- 唯一度5、一名度8、其他内部点度6。

度5的p允许0..4，度7允许0..6，度8允许0..7，没有借用尚未证明的p<=3。无度5的旧四种Euler条件分支与原metric支持另行保留。
