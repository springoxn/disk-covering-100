# 第23轮：保留重边身份的有向半边规范码

本轮为后续组合地图去重实现一项通用基础：对已验证的可定向连通地图，使用成对半边 involution α 和面置换φ编码，保留平行边独立身份。

[半边规范器](../verify/n100_dart_map_canonicalization.py)实际退出0，[回执](../verify/out/n100-dart-map-canonicalization.json)记录候选602个半边及完整规范码。对每个可能根半边，以α、φ固定顺序发现全部半边，重新编号，记录(α索引,φ索引,外面/轴点标记)，取所有根码字典序最小值。连通保证遍历全图；给定根后码确定两个置换与标记，因此码相同给出保α、φ和标记的同构。取所有根消除输入根/编号依赖。只识别保持定向、外面与有序四轴标记的地图同构，不把镜像自动合并。

实际候选测试同时改变顶点名字、边记录序、面记录序及所有面循环起点，规范码完全一致。二边形测试使用同端点的两条独立边，对应四个半边，身份未丢失。这是用于验证二边形表示的小组合控制，不是合法百盘候选或完整四轴覆盖模型。

前置的[序列化脚本](../verify/n100_map_canonicalization.py)及[回执](../verify/out/n100-map-canonicalization.json)只保证协调顶点/边重标号，是有限范围序列化，不是全同构规范器。新的dart方案才消除面循环起点/面序影响。通用输入仍应先由流形合法性检查器验收；规范器不是合法性判定器。

没有独立规范器实现，也没有独立规范轨道集比对；目前一个实际候选与一个二边形控制不足以验收全域枚举。下一步把任意合法dart地图编译为二次模型，并给小规模地图建立完整枚举/独立轨道校准，再评估n100计数族的实际规模。

严格区间不变11323/100000<r_D(100)≤1154469548855829/10^16。尚未完成全部地图枚举、全域排除或真实最优半径极小多项式。
