# 第16轮：任意非负单盘见证对偶的普适障碍

本轮证明一条路线限制，停止把受限盒容量toy误当作全局逼近。没有改善n100严格区间。

## 定理与完整初等证明

设μ是单位闭圆盘D内任意有限非负加权见证 measure，总权重W；有限离散点集已足够本项目使用。设每个半径r的闭圆盘服务权重均≤1。令服务函数S(c)=μ(B(c,r))。

把圆心c在半径1+r的圆盘D_(1+r)内积分。对每个见证点p∈D，所有能服务p的圆心恰为B(p,r)，完全包含在D_(1+r)内，面积为πr²。因此有限求和交换积分直接给出

∫_(D_(1+r)) S(c) dc = πr² W。

另一方面S(c)≤1，积分≤π(1+r)²，故W≤(1+r)²/r²。

若仅要求圆心位于D，结论仍成立：把任何c∉D径向投影到D，对D中所有p距离不增，服务权重不减。于是D内单盘权重≤1蕴含任意圆心单盘权重≤1，可用上述积分。

一般地，令M=max_c S(c)，则W/M≤(1+r)²/r²（W=0时无排除力）。要通过n个圆盘的独立容量上界排除覆盖，需W>nM；但n=100且r>1/9时

(1+r)²/r²<100，

因为100r²−(1+r)²=(9r−1)(11r+1)>0。故任意非负有限见证权重的这一全局单盘对偶均不能证明百盘排除。

这是一个方法障碍，不是覆盖配置构造，不是新下界。解析证据为有限和积分及投影初等证明；未进行形式化内核验证。

## 对此前路线的影响

此前有限见证校准及Hall/三点容量受限盒叶仍可用，因为它们给不同圆心不同允许域，不能自由平均圆心。受限域容量叶可能与分割、边界/接触计数组合。

淘汰的是：在当前半径附近，企图靠无限加密见证点及优化非负权重，使“任意一个半径r圆盘的服务权重≤1、总权重>100”的纯全局对偶成功。其失败有定理依据，不必继续LP试跑寻找这种证书。

不排除：非分数整数集合覆盖证书、耦合圆心布局、分支专属容量、边界长度/拓扑计数、精确接触图枚举。这些需新证据。
