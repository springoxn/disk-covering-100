# n=100 阶段28：弧长—面积联合下界

本阶段已得到并独立复核一个新的严格下界组件，但它仍不是全局最优性证明。

## 结论

在现行上端

`U = 1154469548855829/10^16`

重新按同半径全覆盖规范化后，若有 `k>=55` 个圆周服务盘，则弧长与内层面积的联合预算产生严格矛盾。因此在该解析接口的依赖下，得到

`k <= 54`。

主证书：`verify/out/n100-arc-cap-rational-support.json`。独立证书：`verify/out/n100-arc-cap-independent.json`。两者实际退出0。

## 证明计算骨架

取 `delta=1/50`，内层半径为 `s=1-2U+delta`。服务盘中心模 `d` 满足 `d>=1-U`。令 `u=d-(1-U)`。圆周服务半弧的余弦为

`cos(phi)=(1-U^2+d^2)/(2d)`。

在 `d<sqrt(1-U^2)` 分支，半弧随d增加；利用 `phi <= sin(phi)/sqrt(1-U^2)` 将弧长表示为有理平方根上界。盘在内层中的交集被深度 `delta-u` 的圆帽包含，其面积用

`sqrt(2U z^3)*(4/3-z/(5U))`

作有理上界，其中 `z=delta-u`。对 `u` 区间分成2000个有理小段，逐段验证一个线性支持

`cap(u) < a*(M-phi(u))`,

其中 `a=18/1000`，`M=U/sqrt(1-U^2)`。对每段只使用Fraction和平方根向上界；最小支持间隙为正。

圆周弧总长至少为 `2*pi`，所以 `sum phi >= pi`。若 `k>=55`，所有服务盘的帽面积总和至多为 `a*(k*M-pi)`；非服务盘至多贡献 `(100-k)*pi*U^2`。与内层圆盘面积 `pi*s^2` 比较，在 `k=55` 处得到严格正缺口；由于 `pi*U^2 > a*M`，k增加只会使缺口增大。因此所有 `k>=55` 均排除。

## 独立复核

独立检查器不导入主几何函数，重新核查：

- 2000段覆盖、端点连续和参数范围；
- 所有弧长平方上界；
- 所有圆帽平方上界；
- Machin公式的独立交错级数π区间；
- k=55的正面积余量；
- 低报帽、删除分段、伪造弧长上界三项损坏控制。

主证书中明确保留 `machine_verified_geometry=false`，因为同半径归一化、每个服务盘的单弧/弧长可加性、圆帽包含关系等仍是解析依赖。

## 对 n=100 总问题的影响

这条结果把已有服务盘范围从 `28<=k<=55` 收紧到 `28<=k<=54`，但规范化图的边界拥有者数仍满足 `B<=k`，且 `k=B` 不成立。现有 `(m,B)` 87组必要域没有因此自动排除；全局地图枚举、全域候选排除和最优半径极小多项式仍未完成。
