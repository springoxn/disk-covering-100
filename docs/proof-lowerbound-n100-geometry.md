## 1. 约定、归约与为什么「圆心在 P 内」不是前提

### 1.1 覆盖与 Voronoi 胞

设 `{B(c_i,r)}_{i=1..n}` 覆盖 `D`（闭盘、允许圆心在 `D` 外）。定义

```
V_i = { x ∈ D : |x − c_i| ≤ |x − c_j|  ∀j }        （闭胞，凸）
```

**事实 0.1（铺满）**：`⋃_i V_i = D`（覆盖性），且 `int V_i ∩ int V_j = ∅`（`i ≠ j`，中心互异）
—— 因为 `V_i ∩ V_j ⊆ {|x−c_i| = |x−c_j|}` 是直线，面积零。

**事实 0.2（P3，升级版）**：`V_i ⊆ B(c_i,r)`。证明：`x ∈ V_i ⟹ |x−c_i| = min_j |x−c_j| ≤ r`，
最后一个不等号用覆盖性：`x ∈ D ⊆ ⋃_j B(c_j,r)`，故某个 `j` 满足 `|x−c_j| ≤ r`。∎
**只用覆盖 + 定义，不需要中心在胞内、不需要一般位置。**

**归约 0.3（中心可投到 D 内，合法但不是万灵药）**：`Π` = 到凸集 `D` 的投影（非扩张：
`|Π(x) − y| ≤ |x − y|`，`y ∈ D`）。则 `B(Π(c_i), r) ⊇ B(c_i,r) ∩ D`，故把每个中心换成
`Π(c_i)` 仍是覆盖、半径不变。于是**可设 `|c_i| ≤ 1`**。
⚠️ **这一步不给出 `c_i ∈ P`**：`P` 是内接多边形，其内切半径 < 1，边界胞的圆心恰是最危险的一类。
历史链的 `area(V_i∩P) ≤ r² g(m_i,Θ_i)` 曾以 `c_i ∈ V_i ∩ P` 为前提（审计 O4）；本文 §2 的引理 A
把它整条去掉。

**归约 0.4（中心可去重）**：若 `c_i = c_j`（`i ≠ j`），丢掉一个盘：覆盖性不变、半径不变、
中心集合变小。**去重后**中心互异。

**事实 0.5（去重 + 投影后每个胞正面积）**：设 `ρ_i = min_{j≠i} |c_i − c_j| > 0`。则
`|x − c_i| < ρ_i/2 ⟹ |x − c_j| ≥ |c_i − c_j| − |x − c_i| > ρ_i/2 > |x − c_i|`，故

```
B(c_i, ρ_i/2) ∩ D  ⊆  V_i        （注意：V_i 被 D 裁剪，故只能断言"∩D"，不能断言整个小邻域）
```

再证 `V_i` **正面积**：由归约 0.3 可设 `c_i ∈ D`。取 `p ∈ B(c_i, ρ_i/2) ∩ int D`——非空，因为
`|c_i| < 1` 时 `c_i` 本身可扰动到 `int D`，`|c_i| = 1` 时取 `c_i − t c_i`（`t > 0` 小）即可；
于是 `p` 的一个小邻域含于 `V_i`，`int V_i ≠ ∅`，`area(V_i) > 0`。∎
于是记 `N = n` = 正面积胞数（去重之后），**没有「空胞」记账问题**（O8 的记账部分）。
（投影前可能出现的"空胞/退化胞"已由归约 0.3 + 0.4 消除。）

**归约 0.6（`r < 1`；`r ≥ 1` 平凡）**：要证 `r_D(100) ≥ L = 0.1109…`，故下文恒设 `r < 1`
（若半径 `≥ 1` 结论已经成立）。

### 1.2 边界弧、边界顶点、内接多边形 P

设 `∂D` 上的**所有权函数** `own(x) = ` 满足 `x ∈ V_i` 的最小 `i`（任意确定的打破平局规则）。

* **弧**：`∂D` 上的一条**极大正测度连通段**，其上按 a.e.（几乎处处）意义所有权为同一胞。
  **约定**：若某胞只在**孤立点**处达到最小距离（零测接触、tie），**不**在那里切弧——
  弧按「a.e. 意义的最大正测度段」定义，孤立零测接触被忽略。弧记为 `A_1,…,A_{B_arc}`；弧数 `B_arc`。
* **边界顶点**：**正测度**意义上的所有权变化点（即弧的端点）。孤立零测 tie 点不算边界顶点
  （除非它同时是某条弧的端点）。
* `P := conv(所有边界顶点)`（内接多边形）。

**事实 0.7（弧数 = 边界顶点数）**：由 `∂D = ⋃_i (V_i ∩ ∂D)`，弧的内部两两不交、覆盖 `∂D`
（至多漏掉有限个测度零点，且按上面的 a.e. 约定这些零点不切弧）；每个边界顶点恰是 2 条弧的
端点（无弧绕整圈时），故 `#边界顶点 = B_arc`。
**「每个边界胞一条弧」是假的**，见 §3.4 的精确反例（一条胞 2 条弧）。

**事实 0.8（`r<1` ⟹ 每条弧的角测度 ≤ 2 arcsin r < π）**：设弧 `A` 是被某胞 `i` 拥有的极大单主弧，
端点为 `z_1, z_2`。**两步**：

*Step 1（先排除"大弧"）*：`A ⊆ V_i ∩ ∂D ⊆ B(c_i,r)`（事实 0.2，**不需要投影**）。若 `A` 的角测度
`ψ ≥ π`，则 `A` 含一段测度 `π` 的子弧，其两端点对径、距离为 `2`；这两点都在 `A ⊆ B(c_i,r)` 内，
故 `2r ≥ 2`，即 `r ≥ 1`，与 `r < 1` 矛盾。**故 `ψ < π`。**
*Step 2（此时弦长公式适用）*：`ψ < π` 时角测度与弦长 `ℓ = |z_1 − z_2|` 的关系为 `ψ = 2 arcsin(ℓ/2)`；
又 `z_1, z_2 ∈ V_i ⊆ B(c_i,r)`，三角不等式给 `ℓ ≤ 2r`。于是

```
ψ = 2 arcsin(ℓ/2) ≤ 2 arcsin r < π      （r < 1）。
```

∎
（**注意**：若跳过 Step 1，直接对 `ψ > π` 的弧写 `ψ = 2 arcsin(ℓ/2)` 是**错的**——那时
`ψ = 2π − 2 arcsin(ℓ/2)`。Step 1 正是为排除该分支；它只用「`r < 1`」与「对径点距离 2」。）

**注 0.8′（勘误留痕：`4 arcsin(r/2)` 是错的）**：`∂D ∩ B(c_i,r)` 的**整段**弧在 `r < 1` 时
角测度的最大值为 `2 arcsin r`，**不是** `4 arcsin(r/2)`（后者只是 `|c_i| = 1` 时的值，反而更小）。
计算：设 `|c_i| = ρ`，`Q(ρ) = (1 + ρ² − r²)/(2ρ)`，整段弧非零需 `ρ ≥ 1 − r`，角测度为 `2 arccos Q(ρ)`；
`dQ/dρ = (ρ² + r² − 1)/(2ρ²)` 在 `ρ* = sqrt(1 − r²) ∈ [1 − r, 1]` 处取最小值
`Q(ρ*) = sqrt(1 − r²)`，故最大值 `= 2 arccos(sqrt(1 − r²)) = 2 arcsin r`；对 `ρ > 1`，`Q` 递增、
角测度递减且 `≤ 2 arccos((2 − r²)/2) = 4 arcsin(r/2) ≤ 2 arcsin r`。故该上界对任意 `|c_i|` 成立。
（初稿把 `4 arcsin(r/2)` 当作上界：它在 `r` 接近 `1` 时**推不出** `< π`，故不能作为 0.7/§4 的依据。）

**推论**：`B_arc ≥ 3`（每条弧 `< π` 而总和 `2π`）；**没有弧绕整圈**（这正是 §4 记账唯一需要的假设）。

**引理 3（复述，审计已证）**：`B_arc ≥ π / arcsin r`。证明：弧 `A` 的端点 `z_1,z_2 ∈ V_i ⊆ B(c_i,r)`，
故弦长 `|z_1 − z_2| ≤ 2r`，角测度 `= 2 arcsin(|z_1−z_2|/2) ≤ 2 arcsin r`；`B_arc` 段弧覆盖 `∂D`，
求和 `2π ≤ B_arc · 2 arcsin r`。∎

### 1.3 逃逸路线与「极限」的正确用法（预告）

本文的证明**不需要一般位置**（这是 §4 花力气证明顶点度 ≥ 3 的原因），因此
**不需要任何扰动/极限**。若有人仍想走「扰动到一般位置 + `ε → 0`」，正确形式是：
设真实覆盖半径 `r < L`，取 `ε < (L − r)/2`，把中心扰动 `ε`、半径放到 `r_ε = r + ε < L`
（覆盖性由 `B(c_i + δ_i, r+ε) ⊇ B(c_i,r)` 保证，`|δ_i| ≤ ε`），对扰动后构型用定理得矛盾，
再 `ε → 0`。**关键**：此时 `r_ε < L` 是**由 `ε` 的选择重新保证的**，而不是「假装扰动后仍 ≤ L」。
本文 §4/§6 的证法直接对任意构型成立，绕开了这一整段讨论。

## 2. 引理 A：盘内凸 k 边形的面积上界（**圆心无须在多边形内**）

> 这一条是历史链 O4/O4′ 的正面替代：它把「扇形分解 + cap 上界」两步换成一次
> 「最小包围圆 + 一个扇形 + Jensen」。

**引理 A**：设 `K ⊂ ℝ²` 凸紧，`K ⊆ B(c, r)`（`c` 任意，不必属于 `K`）。则

```
area(K) ≤ r² · f(k),      f(k) = (k/2) sin(2π/k)  (k ≥ 3),   f(0)=f(1)=f(2)=0,
```

其中 `k` = `K` 的顶点（极点）个数。`k ≤ 2` 时 `area(K) = 0`。

**证明.**

*Step 1（最小包围圆）.* 设 `B(o,R)` 是 `K` 的最小包围圆（存在唯一，`R ≤ r` 因 `K ⊆ B(c,r)`；
`area(K) > 0` 时 `R > 0`）。设接触集 `S = K ∩ ∂B(o,R)`。
因 `x ↦ |x − o|` 是凸函数、`K` 是多胞形，其最大值在**顶点**上取到，故
`S ⊆ {K 的顶点}`，**有限**；且 `S ≠ ∅`。

*Step 2（`o ∈ conv(S)`，有限版分离论证）.* 若 `S` = 全部顶点，则 `o ∈ conv(K) = K` 已经成立
（直接得结论）。故在反设 `o ∉ conv(S)` 下，**非接触顶点集非空**。取**单位**向量 `u` 与 `δ > 0`：
`⟨s − o, u⟩ ≥ δ`（`∀s ∈ S`；`conv(S)` 紧凸、`{o}` 紧凸且不交，严格分离）。非接触顶点集有限，
且每个 `|v − o| < R`，故 `δ' := min{ R − |v − o| : v 是顶点, v ∉ S }` 是**有限正数**。
取 `o' = o + εu`，`0 < ε < min(δ, 2δ, δ')`：
对 `s ∈ S`，`|s − o'|² = R² − 2ε⟨s − o, u⟩ + ε² ≤ R² − 2εδ + ε² < R²`；
对顶点 `v ∉ S`，`|v − o'| ≤ |v − o| + ε ≤ R − δ' + ε < R`（这里用了 `|u| = 1`）。
（**这里不作**"对 `K ∖ S` 每点分别扰动"这种非一致论证：`K ∖ S` 可以不闭于 `S`，
一致性来自 `S` 与其余顶点的**有限性**。）于是 `K = conv(顶点) ⊆ B(o', R')`，
其中 `R' := max_{顶点} |v − o'| < R`（凸函数在顶点取最大），与 `B(o,R)` 的最小性矛盾。
故 `o ∈ conv(S) ⊆ conv(K) = K`（`K` 凸）。∎

*Step 3（从 o 的扇形分解）.* 记 `K` 的**极点**为 `v_1,…,v_m`（逆时针，`m ≤ k`；`m ≤ 2` 时
`area(K) = 0`，结论平凡）。`o ∈ K` 有三种位置，逐一处理：

* (i) `o ∈ int K`：`K` 是星形区域，被三角形 `(o, v_j, v_{j+1})`（`j = 1..m` 循环）**恰好剖分**；
  所有 `α_j = ∠(v_j, o, v_{j+1}) ∈ (0, π)`，且 `Σ_j α_j = 2π`（绕内点一圈）。
* (ii) `o ∈ ∂K` 但在某条边 `[v_j, v_{j+1}]` 的**相对内部**：则 `o` 落在该边上，射线
  `o → v_j` 与 `o → v_{j+1}` **反向**，故 `α_j = π`；其余三角形 `(o, v_t, v_{t+1})` 仍恰好剖分 `K`
  （`K` 凸、`o ∈ K`），它们的角之和为 `π`（全在一条直线的一侧），故 `Σ_t α_t = π + π = 2π`。
* (iii) `o` 是 `K` 的极点：**排除**。若 `o` 是极点且 `area(K) > 0`，则 `K ∖ {o}` 含于 `o` 处
  张角 `< π` 的闭凸锥 `C`（极点处内角 `< π`）。由 Step 2，`o = Σ_s λ_s s`（`λ_s ≥ 0`，`Σλ_s = 1`，
  `s ∈ S ∖ {o}`；注意 `|s − o| = R > 0` 故 `s ≠ o`）。写成 `s = o + R u_s`（`u_s` 单位向量，
  且 `u_s ∈ C`，因为 `s ∈ K ⊆ C`），得 `Σ_s λ_s u_s = 0`。但张角 `< π` 的闭凸锥内不存在
  非平凡的非负组合为 `0`（其中不含反向向量对），矛盾。故该情形不发生。

于是 `area(K) = Σ_j (1/2) ρ_j ρ_{j+1} sin α_j`（`ρ_j = |v_j − o| ≤ R`，`α_j ∈ [0,π]`，`Σα_j = 2π`；
退化三角形贡献 0），从而

```
area(K) ≤ (R²/2) Σ_j sin α_j .
```

*Step 4（Jensen）.* `sin` 在 `[0,π]` 上凹，`α_j ∈ [0,π]`，均值 `2π/m ≤ 2π/3 ≤ π`，故
`Σ_j sin α_j ≤ m sin(2π/m)`。于是 `area(K) ≤ (R²/2) m sin(2π/m) = R² f(m) ≤ r² f(m)`。

*Step 5（`f` 单调）.* 令 `x = 2π/M ∈ (0, 2π/3]`，则 `M sin(2π/M) = 2π · sin x / x`，故
`M ↦ M sin(2π/M)` 随 `M` 增 ⟺ `x ↦ sin x / x` 随 `x` 减。而
`(sin x / x)' = (x cos x − sin x)/x² = −h(x)/x²`，其中 `h(x) = sin x − x cos x` 满足
`h(0) = 0`、`h'(x) = x sin x > 0`（`0 < x < π`），故 `h > 0`，即 `sin x/x` 在 `(0, π)` 上严格减。
（**不用**含 `tan` 的表达式：`x = π/2` 处无定义。）
`m ≤ k` 且 `m ≥ 3` 时 `f(m) ≤ f(k)`；`m ≤ 2` 时 `area = 0 = r² f(k)`（`f(0)=f(1)=f(2)=0`）。∎

**注 A.1（`c ∈ K` 完全不必要）**：证明只用 `K ⊆ B(c,r)` 来得到最小包围圆半径 `R ≤ r`；
扇形是从**最小包围圆圆心** `o` 出发，而 `o ∈ K` 是 Step 2 证出来的，不是假设。
（历史链从 `c_i` 出发扇形的做法要 `c_i ∈ V_i ∩ P`；引理 A 换成 `o_i` 就免掉了该前提。）

**注 A.2（`k=1,2` 退化）**：`k=1`：`K` 是点，`area = 0`；`k=2`：`K` 是线段，`area = 0`。
`f(0)=f(1)=f(2)=0` 与之相容；后文 Jensen 只在 `k ≥ 3` 上用它，`k ≤ 2` 的项按 `0` 计。

**注 A.3（等号）**：等号在 `K` = 正 `k` 边形内接于半径 `r` 的圆时取到，故引理 A 在
「盘内 k 边形面积」这一层是**最优**的——历史链的损失不来自这里。

## 3. 引理 B：cap 归属、弧换弦、`Q_i = V_i ∩ P`

> 这一条回答用户点名的风险：「把各弧换成弦得到 `Q_i`，它们是否铺成同一个 `P`？」
> 结论是**是的，而且是恒等**（不是包含关系），并且 `V_i ∩ P` 与「换自己的弧」**没有差别**：
> 不会新增来自别的胞的边。多弧胞不需特殊处理。

### 3.1 弓形 = 弧的凸包

**引理 B0**：设 `A ⊂ ∂D` 是单位圆上一段弧（角测度 `ψ ∈ (0, 2π)`），`C(A)` := 由 `A` 与其弦
围成的弓形（`D` 中被该弦截出且含 `A` 的那一侧）。则 `conv(A) = C(A)`。

**证明**：设 `A` 端点为 `z_1,z_2`，弦所在直线 `ℓ`，`H` 为 `ℓ` 界定的闭半平面且 `A ⊆ H`。
`⊆`：`A ⊆ D ∩ H` 且 `D ∩ H` 凸，故 `conv(A) ⊆ D ∩ H`。
`⊇`：`D ∩ H` 的边界是弦 `z_1z_2` 加上 `∂D ∩ H`；而 `∂D ∩ H` 恰是 `A`
（`∂D` 被 `z_1,z_2` 分成两段弧，一段在 `H` 内，`A` 就是它）。弦的端点属于 `A`，故
`D ∩ H = conv(∂(D∩H)) = conv(z_1z_2 ∪ A) ⊆ conv(A)`。
而 `D ∩ H` 正是「被弦截出且含 `A` 的那一侧弓形」。∎
（对 `ψ ≤ π` 与 `ψ > π` 都成立；后者 `H` 含原点，弓形是「大的一侧」。）

### 3.2 剖分与 cap 归属

**引理 B1（cap 含于弧所在的那个胞）**：设弧 `A` 是胞 `V_i` 与 `∂D` 的接触段（即 `A ⊆ V_i`）。
则 `C(A) = conv(A) ⊆ V_i`。

**证明**：`V_i` 凸且 `A ⊆ V_i`，故 `conv(A) ⊆ V_i`；用引理 B0。∎
**多弧**：若胞 `i` 拥有 `a_i` 条弧 `A_{i,1},…,A_{i,a_i}`，逐弧应用。∎

**引理 B2（`P` = 内向弦半平面之交）**：对每条弧 `A`，设其弦所在直线分平面为 `H_A^in`（含 `P`/原点
的那侧，闭）与 `H_A^out`（另一侧，开）；`C(A) = D ∩ H̄_A^out`（闭弓形），`int C(A) = int D ∩ H_A^out`。
则（`B_arc ≥ 3`）

```
P = ⋂_{所有弧 A} H_A^in          （凸多边形 = 各边内向半平面之交）
```

并且 `∂P` 的边 ↔ 弧 是双射，每条边就是对应弧的弦（相邻边界顶点之间的弦）。
**注意**：**不要**写成 `P = D ∖ ⋃_A int C(A)`——这是**错的**：`∂D` 上弧的内部不在
（普通意义上的）`int C(A)` 里，故右端会多出整个 `∂D`。本文一律用半平面写法。

**证明**：由引理 B0/B1 的构造，`P = conv(边界顶点)`；边界顶点在 `∂D` 上呈凸位置，相邻两点给出
一条边，而相邻边界顶点之间恰有一段弧（所有权在其间不变），故 `边 ↔ 弧` 双射；凸多边形等于其
各边内向半平面之交。∎

**引理 B2′（别的胞的弦半平面在 `V_i` 上是冗余的）**：设弧 `A` 属于胞 `j`，`i ≠ j`。则

```
V_i ⊆ H_A^in .
```

**证明**：先看内部。`int C(A) ≠ ∅`（`A` 是正测度弧）且 `int C(A) ⊆ int V_j`（引理 B1），
而 `int V_i ∩ int V_j = ∅`（事实 0.1），故 `V_i ∩ int C(A) = ∅`。又
`int C(A) = int D ∩ H_A^out`，故 `V_i ∩ int D ∩ H_A^out = ∅`，即 `V_i ∩ int D ⊆ H_A^in`（`H_A^in` 闭）。
再看可能落在 `∂D` 上的点：任取 `x ∈ V_i`。因 `area(V_i) > 0`（事实 0.5），取
`p ∈ int V_i ∩ int D`；对 `t ∈ (0,1)` 令 `x_t = (1 − t)x + t p`，则 `x_t ∈ V_i`（凸）且
`x_t ∈ int D`（在 `p ∈ int D` 与 `x ∈ D` 之间），故 `x_t ∈ V_i ∩ int D ⊆ H_A^in`；
令 `t ↓ 0`，用 `H_A^in` 闭得 `x ∈ H_A^in`。∎

**定理 B3（本节的结论）**：**定义**

```
Q_i := V_i ∩ P        （= 「把胞自己的每条弧换成弦」的胞多边形）
```

则

1. `Q_i = V_i ∩ ⋂_{A 属于胞 i} H_A^in`（**精确恒等**；`j ≠ i` 的那些因子由引理 B2′ 冗余，
   故 `V_i ∩ P` 相对 `V_i` 只被**自己的**弦割掉）；
2. `{Q_i}_{i=1..N}` 是 `P` 的剖分：`⋃_i Q_i = P`，`int Q_i` 两两不交，且
   `Σ_i area(Q_i) = area(P)`；
3. `Q_i ⊆ V_i ⊆ B(c_i,r)`（最后一步用事实 0.2）；
4. `∂Q_i` = (`V_i` 的 `m_i` 条直边，原样保留) ∪ (胞 `i` 各条弧的弦)；`Q_i` 凸，
   故 `#sides(Q_i) ≤ m_i + a_i =: e_i`，且 `Σ_i a_i = B_arc`。

**证明**：
(1) `Q_i = V_i ∩ ⋂_{所有弧} H_A^in = V_i ∩ (⋂_{j≠i} H_A^in) ∩ (⋂_{A 属于 i} H_A^in)
= V_i ∩ ⋂_{A 属于 i} H_A^in`，最后一步用引理 B2′（对每个 `j ≠ i` 的弧都有 `V_i ⊆ H_A^in`）。∎
(4) 对正面积的 `Q_i`，每条边来自原 `V_i` 的正长度直边，或来自新增的弦半平面约束。原来圆周上的非端点均在 `P` 外，因此 `Q_i` 不保留圆弧。每个 own 半平面新增至多一条直边；两个凸集的交只截短、合并或删除原直边，不会把同一原直边分裂为两条不连通边。由 B2′，别的胞的弦半平面对 `V_i` 冗余。因此 `#sides(Q_i) ≤ m_i+a_i`。若 `Q_i` 退化为点、线段或空集，面积为0，后续仿射聚合仍适用。这里不声称 `∂C(A)∩∂V_i=A`：cap-only 胞的该交还包含弦，故该等式为假。`Σa_i=B_arc` 由逐弧分配得到。∎
(2) `⋃_i Q_i = ⋃_i (V_i ∩ P) = (⋃_i V_i) ∩ P = D ∩ P = P`；`int Q_i ⊆ int V_i` 两两不交由
事实 0.1；面积等式由边界（弦、弧）为零测集。∎
(3) `Q_i ⊆ V_i` 显然，再用事实 0.2。∎
**几何读法**：`Q_i` 就是把胞 `i` 的每条弧换成对应弦得到的多边形（**至多差零测集**：
被割掉的集合是 `⋃_{own} (int C(A) ∪ (弧 A 的内部))`，面积恰为 `Σ_{own} area(C(A))`）。

**注 B4（回答「V_i ∩ P 会不会新增非本胞边」）**：不会。原因是**所有** cap 都被各自的胞
凸包住（引理 B1），所以 `V_i ∩ P` 相对 `V_i` 少掉的只是**它自己的** cap。这一点只要
`A ⊆ V_i` 与 `V_i` 凸就成立，与弧数、与一般位置、与 `r` 的大小都无关。
反过来，若某个 cap 不属于弧所在胞（即引理 B1 失效），才会出现「`V_i ∩ P` 多出别人边」的现象；
§3.4 给出该结构确实存在（多弧胞），并说明即便如此剖分仍然正确。

### 3.3 退化：`e_i = 2` 的胞，`Q_i` 可以是线段（面积 0）

**事实 B5**：若胞 `i` 是「一条直边 + 一条弧」的弓形胞（`m_i = 1, a_i = 1, e_i = 2`），则
`Q_i` 退化为该弧的弦（线段），`area(Q_i) = 0 = r² f(2)`。

**证明**：弓形胞的边界由弧 `A`（端 `z_1,z_2`）与一条直边组成；该直边的两端点必须是
`A` 的两端点（否则直边与弧围不成闭合区域），于是这条直边就是弦 `z_1z_2`，即 `V_i = C(A)`。
按定义 `Q_i = V_i ∩ P = C(A) ∩ (⋂_{所有弧} H^in)`。用 `C(A) = D ∩ H̄_A^out`（引理 B2 前）：
`C(A) ∩ H_A^in = D ∩ H̄_A^out ∩ H_A^in = D ∩ (弦直线) = ` 弦 `z_1z_2`；
再对 `j ≠ i` 用引理 B2′（`V_i = C(A) ⊆ H_{A_j}^in`）得弦 `⊆ ⋂_{j≠i} H^in`。
故 `Q_i =` 弦 `z_1z_2`（线段），`area = 0`。∎

**注 B6（聚合时不要求所有 `Q_i` 有正面积）**：`Q_i` 可能退化为线段（B5）、可能只有 1–2 条边；
这些项面积恰为 0，而 `f(0)=f(1)=f(2)=0`，故用**名义边数** `e_i = m_i + a_i` 记账是安全的
（`#sides(Q_i) ≤ e_i` 且 `f` 在整数上单调，见 §6 步骤 (3)）。

### 3.4 精确反例：一条胞多弧、`b_cell ≠ B_arc`、cap-only 胞

取 `n = 3`，`c_1 = (0,0)`，`c_2 = (a,0)`，`c_3 = (−a,0)`，`0 < a < 2`（**三个互异中心**）。
由 `|x|² ≤ |x−c_2|² ⟺ x_1 ≤ a/2` 与 `|x|² ≤ |x−c_3|² ⟺ x_1 ≥ −a/2`：

```
V_1 = D ∩ {|x_1| ≤ a/2}        V_2 = D ∩ {x_1 ≥ a/2}        V_3 = D ∩ {x_1 ≤ −a/2}
```

（三式在 `proofs/n100_geometry_check.py` 的 C4 中用 sympy 精确解出半平面。）

* `V_1`：`m_1 = 2`（两条竖直边），与 `∂D` 的接触是**两段弧**（`x_1 ∈ [−a/2,a/2] ⟺ θ ∈ [60°,120°] ∪ [240°,300°]`，取 `a=1`），故 `a_1 = 2`，`e_1 = 4`。
* `V_2, V_3`：`m = 1, a = 1`，`e = 2`，正是事实 B5 的 cap-only 胞：`Q = ` 弦，面积 0。
* `b_cell`（接触 `∂D` 的胞数）= **3**，而 `B_arc = 2 + 1 + 1 = ` **4**。**两者不等。**
* `N = 3`，`Σ e_i = 4 + 2 + 2 = 8 = 6N − 6 − B_arc`（§4 的界在此**取等**）。

**结论**：(i)「每个边界胞恰有一条弧」为假，历史链里 `b` 的含义必须钉在 `B_arc`（弧数）上；
(ii) 用 `b_cell` 会得到 `6N−6−b_cell = 9 ≥ Σe = 8`，即**安全但白丢 1 个单位的强度**；
(iii) 多弧胞与 cap-only 胞**不破坏** §3.2 的剖分与 §4 的记账（`Σa_i = B_arc` 与
`Σe_i ≤ 6N−6−B_arc` 都照常成立）。

## 4. 引理 D：带边界 Voronoi 复形的平面图记账（**`B_arc`，无一般位置**）

> 这是用户点名的第二个问题：`Σ边数 ≤ 6N − 6 − B` 能否由平面图**无须一般位置**证明？
> 答案：**能**，只要 (i) 把 `B` 读作 `B_arc`（**弧数**，不是边界胞数），(ii) 把「每个顶点度 ≥ 3」
> 作为**事实**证明出来（引理 D1），(iii) 用 `m_i ≤`（`∂V_i` 上的**图边**数）而不是等式。
> 唯一的必要假设是「没有弧绕整圈」，它在 `r < 1` 时自动成立（事实 0.8：每弧 `≤ 2 arcsin r < π`）。
> 本节末给两个**精确反例**说明假设不可去。

### 4.1 复形与定义

取**去重 + 投影后**的中心（归约 0.3/0.4），`N = n` 个正面积胞（事实 0.5）。构造平面图 `G`：

* **顶点**：`V_int`（`int D` 内的 Voronoi 顶点：该点有 ≥3 个胞以正角楔形相接）与
  `V_b`（`∂D` 上的边界顶点，`|V_b| = B_arc`，事实 0.7）；
* **边**：`E_s` 条**直线图边**（平分线片段；**在每一个图顶点处切开**，故不做任何"合并共线"的
  约定），`B_arc` 条弧边（每条弧恰是两相邻边界顶点之间的边，事实 0.7 + 事实 0.8）；
* **面**：`N` 个胞的内部 + 外脸，`F = N + 1`。

**⚠️ 图边不得跨过任何图顶点合并**：若把两条共线但被一个真顶点分开的图边并成一条，则该顶点的
度数会掉到 2、Euler 的 `V` 也会少算，`Σ(6 − deg)` 类恒等式随之出错。因此本文的图边是
**在全部图顶点处细分**的。`m_i`（胞 `i` 的**极大直边**数）与"`∂V_i` 上的图边数"是**两个不同的量**，
本文只用 `m_i ≤ ∂V_i 上的图边数` 这一不等式联系它们（§4.1 的 (4.2)）。

**Euler（不需要连通性）**：设 `G` 有 `K ≥ 1` 个连通分支。平面图的 Euler 公式为
`V − E + F = 1 + K`，故

```
(V_int + B_arc) − (E_s + B_arc) + (N + 1) = 1 + K
  ⟹  E_s = V_int + N − K  ≤  V_int + N − 1 .                                     (4.1)
```

（**不用**去论证"凸胞 ⟹ 图连通"这种命题；`K ≥ 1` 只会让下面的界更松，方向安全。
外脸唯一、被弧圈 `∂D` 与 `D` 内部隔开，故 `F = N + 1` 与 `K` 无关。）

**边–面关联（两重计数，无一般位置假设）**：每条直线图边恰以两个胞为邻（它不可能落在 `∂D` 上，
因为平分线只在孤立点触及 `∂D`），每条弧边恰以一个胞为邻（另一侧是外脸）。于是

```
Σ_i (∂V_i 上的直线图边数)  =  2 E_s ,          Σ_i a_i  =  B_arc ,
m_i  := 胞 i 的极大直边数  ≤  (∂V_i 上的直线图边数) ,
```

（一条极大直边至少含一条直线图边；被 T 型顶点切开只是让它含更多条，故是 `≤`，
方向对我们有利。）因此

```
Σ_i m_i  ≤  2 E_s  ,        e_i := m_i + a_i  ⟹  Σ_i e_i  ≤  2 E_s + B_arc .     (4.2)
```

**注 4.1′**：这里刻意**不**去建立 `Σm_i = 2E_s − X` 那样的等式，也不讨论"合并共线/T 型切分
是否降低 `Σm_i`"——(4.2) 的不等式方向统一由「顶点度 ≥ 3」提供（§4.2），退化只会让它更松（更安全）。

### 4.2 每个顶点度 ≥ 3

**引理 D1**：`G` 的每个顶点度 ≥ 3。

**证明**：
*（内点）* 设 `z ∈ int D` 是图顶点，`S = {胞 : z ∈ 闭包}`，`s = |S|`。若 `s = 2`，则两胞在 `z`
附近共用一段直线（两正角楔形合计 `2π` 只能是同一割线的两个半平面），`z` 落在一条极大边的内部，
按定义不是顶点；故 `s ≥ 3`。设 `d = min_i |z − c_i|`。
**断言：`D` 中充分靠近 `z` 的每一点都属于 `S` 中某个胞。** 对 `l ∉ S` 有 `d_l := |z − c_l| > d`
（否则 `l` 也在 `z` 处达到最小距离，即 `l ∈ S`）。取 `|x − z| < (min_{l∉S} d_l − d)/2`：
`|x − c_l| ≥ d_l − |x−z| > d + |x−z| ≥ |x − c_i|`（任一 `i ∈ S`），故 `x` 的最近胞属于 `S`。
于是 `S` 中胞在 `z` 处的楔形铺满 `2π`；每个楔形角 > 0（胞凸、正面积、`z ∈ int D` 处边界为直线段，
事实 0.5）；相邻楔形之间是一条**正长度**的平分线射线，故 `deg(z) = s ≥ 3`。
*（边界点）* 设 `z ∈ ∂D` 是边界顶点：弧端点、所有权在其两侧不同，左侧弧属胞 `i`、右侧属胞 `k`
（`i ≠ k`，否则两侧同属一条极大弧，`z` 不是顶点）。则存在 `x_n → z`（左）与 `y_n → z`（右）满足
`|x_n − c_i| ≤ |x_n − c_k|` 与 `|y_n − c_k| ≤ |y_n − c_i|`；取极限得 `|z − c_i| = |z − c_k|`，
即 `z ∈ (i,k)` 平分线。又 `φ(θ) := |u(θ) − c_k|² − |u(θ) − c_i|²`（`u(θ) ∈ ∂D`）满足 `φ(z) = 0`
且在 `z` 两侧异号，故 `φ'(z) ≠ 0`：**平分线与 `∂D` 在 `z` 处横截相交**。
于是 `z` 处有 2 条弧边（左右各一，属不同胞，故是两条不同的边）。再用与内点相同的
"最近胞铺满"论证：把 `D` 在 `z` 处的半邻域看作角 `π` 的扇形，`z` 处达到最小距离的胞集
`S ∋ i,k`（`s ≥ 2`）在该半邻域内铺满，相邻胞之间是正长度的平分线射线射入 `int D`，
故**至少 1 条**直线边（这里只需要 `≥ 1`；`s ≥ 3` 时是否恰为 2 条或更多，取决于哪几条平分线
射入 `int D`，本文不需要）。总之 `deg(z) ≥ 2 + 1 = 3`。∎

### 4.3 引理 D 与推论

**引理 D**：在 §4.1 记号下（`G` 有 `K ≥ 1` 个连通分支），`2E = Σ_v deg v ≥ 3(V_int + B_arc)`，故

```
2 E_s ≥ 3 V_int + B_arc   ⟹   V_int ≤ 2N − 2K − B_arc   ⟹   2E_s ≤ 6N − 6K − 2B_arc
                            ⟹  2E_s ≤ 6N − 6 − 2B_arc      （用 K ≥ 1），
```

再由 (4.2)：

```
Σ_i e_i  =  Σ_i m_i + B_arc  ≤  6N − 6 − B_arc .                                  (D)
```

**证明**：由引理 D1，`2(E_s + B_arc) = Σ_v deg v ≥ 3(V_int + B_arc)`，即
`2E_s ≥ 3V_int + B_arc`；代入 (4.1) 的 `E_s = V_int + N − K`：
`2V_int + 2N − 2K ≥ 3V_int + B_arc`，即 `V_int ≤ 2N − 2K − B_arc`；于是
`2E_s = 2(V_int + N − K) ≤ 2(2N − 2K − B_arc) + 2(N − K) = 6N − 6K − 2B_arc ≤ 6N − 6 − 2B_arc`；
最后 `Σ_i a_i = B_arc`、`Σ_i m_i ≤ 2E_s`（(4.2)）。**全程不需要 `G` 连通**。∎

**推论 D2（一般位置 = 等号；退化只会使 (D) 更松）**：若所有顶点度为 3、每胞单弧、无共线切分，
则 `V_int = 2N − 2 − B_arc`、`a_i = 1_{i 边界胞}`、`Σm_i = 2E_s`，(D) 取等，即历史链的
`Σ(6 − m_i) = 6 + 2b`（`b` 必须读作 `B_arc`）。度 ≥ 4 的顶点、共线中心、多弧胞只使 `V_int`
更小或 `Σm_i` 更小，故 (D) 的**方向在所有情形都安全**（不需要分类、不需要一般位置）。

### 4.4 精确反例（说明假设不可去）

**反例 D3（弧绕整圈）**：`n = 1`，`c_1 = 0`，`r = 1`：`V_1 = D`，`m_1 = 0`，1 条弧（整圆，
两端点重合）。此时 `N = 1`、`B_arc = 1`、`Σ m_i = 0`，而 `6N − 6 − 2B_arc = −2 < 0`：
(D) 的 `Σm` 形式**失败**。根因：整圆弧的两个端点是同一点，`#边界顶点 = 0 ≠ B_arc = 1`，
Euler 的 `V = V_int + B_arc` 失效。
在 `r < 1` 时由事实 0.8（每弧 `≤ 2 arcsin r < π`）该退化**不可能**出现；`r ≥ 1` 时结论 `r ≥ L` 已平凡。

**反例 D4（用 `b_cell` 代替 `B_arc` 会丢强度）**：§3.4 的三中心构型：`B_arc = 4`、`b_cell = 3`、
`Σe = 8`；用 `b_cell` 得 `6N−6−b_cell = 9`（安全但更松），用「每边界胞一条弧」的隐含假设则
把 `e_1` 从 4 记成 3，把 `f(4) = 2` 记成 `f(3) = 1.299…`，**方向错（过强）**。

## 5. 引理 C：内接多边形的面积下界（不依赖 P 的组合结构）

**引理 C**：设 `g_1,…,g_B ≥ 0`，`Σ g_k = 2π`，且每个 `g_k ≤ γ ∈ (0, π]`。则

```
A := (1/2) Σ_k sin g_k  ≥  π sin γ / γ  ≥  π (1 − γ²/6)      (γ < 1)。
```

**证明**：`s(t) = sin t / t` 在 `(0, π]` 上严格递减，故对 `0 < g_k ≤ γ` 有
`sin g_k = g_k s(g_k) ≥ g_k s(γ) = g_k sin γ / γ`（`g_k = 0` 时两边为 0）。求和：
`Σ sin g_k ≥ (sin γ/γ) Σ g_k = 2π sin γ/γ`，即 `A ≥ π sin γ/γ`。
又 `sin γ/γ = Σ_{j≥0} (−1)^j γ^{2j}/(2j+1)!` 是 `γ < 1` 上的交错级数且项递减，故
`≥ 1 − γ²/6`。∎

**应用**：取 `g_k` = 第 `k` 条弧的角测度，`γ = 2 arcsin r`（引理 3 的逐弧上界），则
`A = area(P) ≥ π(1 − γ²/6)`。（也可直接用 `π sin γ/γ`。）注意这里**没有**用到 `P` 的
顶点数、没有用到「弧怎么分给胞」，只用逐弧上界与总和。

## 6. 聚合：从覆盖到 `r_D(100) ≥ L` 的七步

设 `{B(c_i,r)}` 覆盖 `D`，`r < 1`（否则平凡）。做归约 0.3（`|c_i| ≤ 1`）、0.4（去重）。

**(1) 边界结构与 `B_arc ≥ 29`。** 由引理 3，`B_arc ≥ π/arcsin r`；若 `r ≤ L` 则
`arcsin r ≤ arcsin L`，`π/arcsin L = 28.2663 > 28`，而 `B_arc ∈ ℤ`，故
`B_arc ≥ 29`。也有 `B_arc ≥ 3`（事实 0.8），故 `P = conv(边界顶点)` 是真多边形。

**(2) `P` 的剖分与面积等式。** 由定理 B3：`area(P) = Σ_{i=1}^{N} area(Q_i)`，`N = n ≤ 100`，
每个 `Q_i ⊆ B(c_i,r)`、凸、`#sides(Q_i) ≤ e_i = m_i + a_i`。

**(3) 逐胞面积上界（引理 A）。** 对每个 `i`：若 `#sides(Q_i) = k_i ≥ 3`，
`area(Q_i) ≤ r² f(k_i) ≤ r² f(e_i)`（引理 A + `f` 在整数 `≥ 3` 上增 + `k_i ≤ e_i`）；
若 `k_i ≤ 2` 则 `area(Q_i) = 0 ≤ r² f(e_i)`（`f(0)=f(1)=f(2)=0`，注 B6）。故
`area(P) ≤ r² Σ_i f(e_i)`。

**(4) 边数记账（引理 D）。** `Σ_i e_i ≤ 6N − 6 − B_arc`。结合 `N ≤ 100`、`B_arc ≥ 29`：
`Σ_i e_i ≤ 565`。

**(5) 仿射割线记账（不做整数枚举、不需要高精度判号）。** 记

```
a := f(6) − f(5) = 0.2204349206…  > 0 ,     b := 6 f(5) − 5 f(6) = 1.2754666876…  > 0 ,
φ(e) := a e + b      （过 (5, f(5)) 与 (6, f(6)) 的割线）
```

则 `φ(5) = f(5)`、`φ(6) = f(6)`，且对**整数** `e ≥ 3` 有 `f(e) ≤ φ(e)`：
`e ≥ 6` 时由 `f` 在 `[3,∞)` 上凹（`f''(M) = −2π² sin(2π/M)/M³ < 0`）得割线斜率随区间右移不增，
故 `f(e) − f(6) ≤ a (e − 6)`；`e = 3, 4` 直接核（精确，见 C2）：

```
φ(3) − f(3) = (15/4)(2 sin 72° − √3) > 0        （sin 72° > sin 60° = √3/2）
φ(4) − f(4) = 5 sin 72° − (3/2)√3 − 2 = 0.1568… > 0
```

`e ≤ 2` 的胞面积恰为 0（注 B6），**把这些项从求和中删掉**（删的是非负项，
`Σ e_i ≤ 565` 与项数 `≤ 100` 的约束仍然成立）。于是

```
Σ_i f(e_i)  ≤  Σ_i φ(e_i)  =  a · Σ_i e_i + b · N  ≤  565 a + 100 b  =  65 f(6) + 35 f(5) ,
```

最后一个等号是**代数恒等式**：`565(f6 − f5) + 100(6f5 − 5f6) = 65 f6 + 35 f5`（C2 精确核）。
数值 `565a + 100b = 252.0923989138…`。（这一招同时替掉了"整数凹性 + 92 个 N 逐一判号"，
只剩上面两个有限不等式。）

**(6) `P` 的面积下界（引理 C）。** 逐弧测度 `≤ γ = 2 arcsin r`、总和 `2π`，故
`area(P) ≥ π(1 − γ²/6)`。

**(7) 合并与收口。** (3)(4)(5) 给 `area(P) ≤ r² (65 f(6) + 35 f(5))`；(6) 给下界。于是

```
∀ r ≤ L (< 1) 且存在 n = 100 盘半径 r 的覆盖：
        π (1 − (2 arcsin r)²/6)  ≤  r² (65 f(6) + 35 f(5)) .            (**)
```

`r ↦ 1 − (2 arcsin r)²/6` 递减、`r ↦ r²` 递增，故 (**) 左边在 `r = L` 取最小、右边取最大；
只需在 `r = L` 处否证 (**)。精确值：

```
65 f(6) + 35 f(5) = 195√3/2 + (175/8)√(10 + 2√5)  ,     L = 554570693/5000000000 ,
π (1 − (2 arcsin L)²/6)  =  3.1157211653…    >    L² · 252.0923989138…  =  3.1012271140…
```

余量 `0.0144940513`（相对 **0.467%**，发现层数值，见产品 C3）。**最后一步是有限代数/有理不等式**
（需要 `π` 与 `arcsin L` 的有理包围），由算术代理的 15 项 exact checks 闭合。若它成立，则
不存在半径 `≤ L` 的 100 盘覆盖，故

```
r_D(100) ≥ L = 554570693/5000000000 = 0.1109141386 .
```

**注 6.1（不需要 `A(P)` 的精细极值）**：历史链用的是 `areaP_min(r,B)` 的精确极值
（`tools/cell_bound.py:369-388`）与连续不动点（其根比 `L` 低 `7.6×10^{-12}`，见 `runtime/` 复现记录）。
本路线的 (6) 用的是**更粗**的下界 `π(1 − γ²/6)`：它**放弃**了约 `0.46%` 的精度，
却因此把「`B` 到底是 29 还是更大」「`P` 的顶点怎么分布」全部消掉，换来一个**严格**的
有限不等式。粗下界之所以仍然够用，是因为 (5) 的**仿射割线记账是严格的**：
连续松弛给 `100 f(5.65) = 253.2941376702…`，而 `565a + 100b = 65f(6) + 35f(5) = 252.0923989138…`，
白捡 `1.2017387564`（约 `0.48%`）的余量——这就是 (7) 里那 `0.467%` 净余量的来源。

**注 6.2（`r < 1` 与 `γ < 1` 是两回事）**：`r < 1` 只给 `γ = 2 arcsin r < π`（用于事实 0.8、
事实 0.7、引理 D1 的边界情形）；`γ < 1` 需要 `r < sin(1/2) = 0.479…`。在 §6 收口处我们只需
`r ≤ L`，此时 `γ ≤ 2 arcsin L = 0.2222856335… < 1`，引理 C 的交错级数界 `sin γ/γ ≥ 1 − γ²/6`
合法。`r ≥ 1` 时 `r ≥ L` 已平凡成立。

## 7. 退化与极限：本文不需要扰动

* **本文的证明对任意构型成立**：引理 A 不要求圆心在 `K` 内；定理 B3（含多弧、cap-only 胞）
  不要求一般位置；引理 D1/D 的「顶点度 ≥ 3」是被证明的事实（§4.2），不是假设；记账用的
  (4.2) 是**不等式** `Σe_i ≤ 2E_s + B_arc`（不区分 T 型切分/共线）。因此**不存在**
  「先扰动再声称 `r_ε ≤ L`」的问题，也不需要任何一般位置归约。
* **若仍要走扰动/极限**（例如为了绕开某个未列出的退化），正确写法是：设真实覆盖半径 `r < L`，
  取 `ε < (L − r)/2`、半径 `r_ε = r + ε < L`、中心扰动 `|δ_i| ≤ ε`
  （`B(c_i + δ_i, r_ε) ⊇ B(c_i, r)`，覆盖保持）。对（一般位置、`r_ε < L`）构型用定理得矛盾；
  再 `ε → 0`：`r_ε → r`、`γ(r_ε) → γ(r)`、两边连续，得到对 `r` 的矛盾。
  **要避免的错误**是：给定 `r ≤ L` 后扰动到 `r + ε` 却**继续沿用 `r + ε ≤ L`**——此时
  `r + ε` 可能已 `> L`。上面 `ε < (L − r)/2` 的选择正是为此。
* **`|c_i| ≤ 1` 的归约**（归约 0.3）合法，但**不**蕴含 `c_i ∈ P`；本文不再需要后者（注 A.1）。

1. **§6 步骤 (7) 的精确算术**：`π(1 − (2 arcsin L)²/6) > L²(65f(6) + 35f(5))` 的严格有理/代数

   具体数值，只依赖它成立与否。
2. **§4.2 中「最近胞在半邻域内铺满」这一步**是本节唯一需要细读的地方：它用「`d_l > d`（`l ∉ S`）
   ⟹ 距离 `z` 足够近的点，其最近胞必在 `S` 中」。本文给的是完整论证（含 `int D` 与 `∂D` 两个
   情形，以及 `s = 2` 的内点情形归约为"不是顶点"），但它是几何论证，**没有**机器证书。
3. **`r < 1` 时是否存在双弧胞**：未知，且**无关紧要**——§3、§4 的记账已按 `B_arc` 与逐弧
   `a_i` 处理多弧；本文不假设单弧。（§3.4 的反例 `r = 1` 才出现双弧胞，属平凡区间。）
4. **`proofs/n100_geometry_check.py` 不是普适证明**：C1/C3/C6/C7 是浮点发现层，C2/C4/C5 是
   精确代数/整数但只覆盖**指名的有限对象**。本文的普适断言全部来自 §2–§5 的解析证明；
   脚本只用于复核与勘误留痕（尤其 C7 复核注 0.8′ 的 `2 arcsin r` 上界）。
5. **本文不涉及**：`r_D(100)` 的精确值、极小多项式、覆盖侧（上界）、`n ≠ 100` 的任何外推。
