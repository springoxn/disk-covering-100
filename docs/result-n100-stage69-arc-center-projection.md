# 阶段69：保留弧段到圆心的反向并集收缩

入口：`python verify/n100_arc_center_projection.py`，实际退出0。证书：`verify/out/n100-arc-center-projection.json`。

## 新步骤

旧弧筛选只更新顶点盒。本轮对边界顶点v的每个保留弧段T，收缩关联圆心盒C，得到包含所有可能满足|c-v|<=U的c的盒P_T。将全部P_T并集取坐标外包后更新同一圆心盒；依次处理其各个边界顶点。不能把弧段投影盒取交集：真实顶点只需落在某个保留弧段上，并不需要同时落在所有弧段上。

该步骤保留实连续解，不要求顶点落在有理参数格点上。每个弧段本身也只是矩形外包，投影保留不代表存在同一个顶点同时满足所有关联面心。不同顶点依次作用到同一个圆心盒，仍是外包传播，不是联合可实现性判定。

## 输入和结果

输入为阶段68代表[14,21,28,3]的完整16个未决叶，以及阶段66真实候选[30,6,14,22]的256段固定点盒。每轮执行弧支持、顶点并集外包、圆心投影并集外包，再执行圆周/共享顶点/邻接传播。最多80轮。

- 16叶全部fixed；0 excluded、0 capped；
- 其中8叶进一步缩盒，8叶不变；
- 叶域总盒宽缩减1201151个缩放单位（Q=2^20）；
- 缩盒叶收敛5轮，不变叶1轮；
- 真实候选保留，盒不变，1轮固定。

原代表根未排除。总缩减跨不同叶域求和，仅为算法统计，不是单个配置的几何改善。全局固定核心仍576排除、4200保留。

## 验证范围

每次弧段到圆心收缩均使用主contract和独立clip计算，逐项完全相等；双分量并集外包、严格拒绝及相切保留控制通过。所有输出盒嵌套于对应输入盒；每个终态32边界顶点的保留弧掩码用直接整数端点与另一路分离距离计算重建，相等。

没有独立重放全部驱动逻辑。终态审计与单步算术比较不能替代完整独立轨迹复核；输入外包性和闭分支覆盖继承阶段66/68。machine_verified_geometry=false，global_optimality=false。
