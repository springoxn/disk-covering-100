# 阶段65：同象限边界次序传播

命令：`python verify/n100_boundary_order.py`，实际退出0。证书：`verify/out/n100-boundary-order.json`。

## 必要条件

在既有核心外边界CCW到单位圆周次序的解析归约下，每个象限内按外边界遍历的点满足坐标单调性。由dx/dtheta=-y、dy/dtheta=x，依次得到四象限方向：

- 第一象限：x不增、y不减；
- 第二象限：x不增、y不增；
- 第三象限：x不减、y不增；
- 第四象限：x不减、y不减。

只对同象限相邻核心顶点加约束。每案32核心边界顶点，跳过4条跨象限边，28对邻点各2坐标，共56条非严格不等式。退化点允许相等，这是一种放松；不推断严格顺序或圆弧正长。

对x_a<=x_b，用x_a上端<=x_b上端和x_b下端>=x_a下端收缩；下端大于另一上端时严格排除。替代实现用-x_b<=-x_a重算，逐案比较完整结果。外边界分别用反向面循环和逆phi遍历重建，额外验证端点连续性。

## 实验

输入为阶段63完整32案间隙类加真实候选的固定点盒。每轮次序收缩之后运行圆周、共享顶点及圆心邻接传播。33案全部fixed，0 excluded、0 capped、0额外宽度缩减；真实候选保留。

153个有理次序见证控制和一个严格拒绝控制通过。两种算术实现共享驱动和部分拓扑设置，不是完全独立端到端验证。

## 解释与限制

零缩盒只表明当前区间端点已经满足这些二元次序承包器，不意味着所有次序与圆周等式存在联合实现。没有跨象限额外耦合、没有轴细分顶点、没有对所有点的联合可实现性证明。次序必要性仍依赖解析地图到圆周归约，machine_verified_geometry=false。

本轮无新增排除，固定核心仍576排除、4200保留。该连续松弛的多种低阶承包器在测试盒上均饱和，应改变离散化/分支策略或审计松弛伪解，而不是反复重跑同盒。全局最优性、完整核心枚举与极小多项式未完成。
