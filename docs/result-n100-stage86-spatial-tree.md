# 阶段86：五层圆心实坐标覆盖树

入口：`python verify/n100_center_spatial_tree.py`。实际退出0。证书：`verify/out/n100-center-spatial-tree.json`。

## 输入及分割

只处理阶段84代表[14,21,28,3]、node27下的child1，其条件为顶点163标签<=192且顶点238标签<=23。起点是该子域的圆弧传播终态盒。

每个非排除节点先执行圆周/共享顶点距离及圆心邻接交替传播，最多160轮；再从前100个圆心的两个坐标中选择区间宽度最大的坐标，按整数中点m分为[lo,m]与[m,hi]。这些是连续实区间，m是两闭子区间的公共端点，不是整数格点枚举。相同宽度按圆心编号及坐标编号取较大者。最大深度5。

若传播达到160轮上限仍未判空，结果只能是未决的外包，继续分割也不将其视作可行。当前脚本保存每节点fixed字段，可复查状态。

## 验证和结果

每节点主与替代圆周/距离传播的完整结果相等，独立topology setup核对边/象限数据相等。全部非空输出嵌套于输入。

构树后递归重建每个子盒，核对除所选坐标端点外其他坐标全部不变、两闭子区间完整覆盖父坐标区间、父子索引一致、节点唯一且全部可达。证书保存全部节点输入及传播结果。

结果：63节点，31个分割节点，0个严格排除节点，32个未决叶。child1未排除，node27更未排除。

几何盒是有限标签域的外包，可能包含此前标签禁配已排除的组合。对这个更宽盒证明判空可安全排除相应域；保留更宽盒则不能证明任何实际覆盖存在。本轮没有逐叶重新应用完整有限关系和12条禁配，不声称叶是最强联合松弛固定点。

## 方向判断

与阶段85零增益约束测试相结合，此结果表明仅按最大圆心盒宽二分并使用当前距离传播，在五层深度不足以排除整盒。应考虑将分割与有限弧段支持/已学禁配联合，或使用更有针对性的坐标选择，而不是未经评估扩大同一树深。

本轮没有新增组合计数结论、半径界或全局核心排除。主/替代共享驱动，树结构核对和算术替代不是完全独立端到端证明。

固定核心仍576排除、4200保留；阶段84两个子域仍未决，child1现在另有32个覆盖它的未决实坐标子盒。machine_verified_geometry=false，global_optimality=false。完整核心枚举、全局最优性和极小多项式未完成。
