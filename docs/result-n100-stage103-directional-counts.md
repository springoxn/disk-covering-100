# 阶段103：偏心目标圆的方向计数接入全部保留放置

## 执行结果

`python verify/n100_directional_center_counts.py`和`python verify/n100_directional_center_counts_independent.py`均退出0。

主筛选60个偏心目标圆，覆盖全部4200个当前保留的放置标签（使用继承的早期axis盒）、32个细化空间叶以及真实候选控制。全部新增排除0。

## 必要条件

若以z为中心、半径s的目标圆盘含于单位盘，则覆盖它需要至少L(s)个覆盖圆盘。圆心满足|c-z|>=s+U的盘不进入目标开圆，因此至少L(s)个原圆心必须满足严格|c-z|<s+U。子问题闭包、缩放和通用Voronoi包络与阶段102完全相同，允许偏心平移。

沿用阶段102五个半径s=0.4,0.5,0.6,0.7,1-2U及下限16,24,34,46,56。偏心距离分别0.6,0.5,0.4,0.3,0.2。每层12个方向，取轴方向及(3/5,4/5)、(4/5,3/5)的符号组合；全部目标中心有理，|z|+s<=1经精确检验。

这些区域有重叠，所需圆心数不允许简单累加。本轮仅做各方向单独的必要计数，并未实现区域交叠的Hall联合条件。

## 主筛选的准确范围

4200个放置标签来自当前圆周存活域，但所用几何盒来自更早的4776根axis文件。已排除的576标签不再纳入本轮。这些继承盒是各放置更宽的必要包围域，适合安全预筛，不能称为全部4200放置的最新细化传播状态。

主程序用整数缩放目标中心，计算到轴对齐中心盒的最小距离平方；只有该最小值严格小于(s+U)²的圆心，才计入可能个数。少于所需数才排除。没有从球盒相交推断真实可行覆盖。

全部4200继承盒、32细化叶和候选控制均保留。零排除表明本轮宽盒预筛未获收益，不能据此断言偏心约束对更细盒无用。

## 独立复核范围

独立脚本以有理中点/半宽公式直接计算盒到目标中心距离，算法不同于主脚本的整数缩放端点公式。60个目标的包含性与需求数均核对；独立复算21个等距索引选取的放置、全部32细化叶及候选，共54案。所有生产排除也列入复核集合，但本轮排除为空。

因此不能声称4200案都已独立重放。主程序4200案完成，独立抽核21案，另33额外案完整核对。需求常数绑定阶段102的独立算术证书。解析几何归约仍为显式依赖，非形式化证明内核。
