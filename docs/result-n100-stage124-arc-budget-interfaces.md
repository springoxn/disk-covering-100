# 阶段124：固定半径弧帽、透镜及多半径预算接口

## 已执行证据

[预算接口](../verify/n100_arc_budget_interfaces.py)新增arc_cap、arc_lens、radial_profiles三个运行筛选器。[验证入口](../verify/n100_arc_budget_interface_contracts.py)实际退出0，[当前证书](../verify/out/n100-arc-budget-interface-contracts.json)记录完整支持/条带重放及10项负控制。

本批不修改已有中心盒叶或计数域接口。预算支持只在精确半径U=1154469548855829/10^16声明下接收输入，不能隐式转成r<=U的同一k计数判据。

## 类型与预算

arc_cap、arc_lens输入(m,k)，m为归约圆盘总数，k为不同圆周服务圆盘数，0<=k<=m<=100；不接收任意弧段数或B代替k。semantics_id=norm-cap-circle-serving-count/v1绑定整覆盖的范数归约与重新计数前提。

已认证的单盘支持为C<=a(M-phi)。圆周覆盖给sum(phi)>=pi，故sum(C)<=a(kM-pi)。目标盘面积不足的有理下界为

pi_low*(1-2U+delta)^2 -(m-k)*pi_high*U^2 -a*(kM-pi_low)。

严格正才排除；非正只是NOT_EXCLUDED。面积与弧长支付同一组圆盘，输出明确additive_with_other_area_bounds=false。与其他必要约束可以求交，但不能直接相加亏损。

radial_profiles的输入是已认证near/tail两个径向类型及中心类型的非负整数重数，总和100。它支持重新分配重数，但不接受任意新径向位置。每个类型的距离、弧包络、100个指定目标半径上的面积积分先由上下文重放认证。

若任一目标的总容量上界严格小于目标面积下界，或总弧长上界不足，则排除。全部容量下界足够且弧下界足够时返回NOT_EXCLUDED；包络尚不能定号则UNDECIDED。任何“capacity satisfied”都不是实际联合覆盖，角位置和重叠损耗依旧未建模。

## 独立重放

- 弧帽：调用不导入主几何函数的独立平方不等式audit，验证2000段分区、弧界、帽积分界、支持正间隙和Machin pi包络。
- 透镜：分别以两圆高度平方表达式验证全部512径向段及每段128条带，共65536条带；重算目标面积和k54原始判定。
- 多半径：用端点/轴穿越的平方高度极值验证100个目标半径，非空透镜18432条带；重新积分，未复用主生成器的roots/lens函数。
- 两个服务类型的弧下界用独立整数二分平方根及正系数arcsin部分和重建，弧上界用平方比较核对。

所有接受算术为integer/Fraction；主源文件哈希与cap->lens->profiles输入哈希链在上下文加载时核对。依旧继承范数归约、短弧公式及单调性、积分几何、面积次可加性等解析前提，不冒称完整形式化几何。

## 有限结果与意义

1. arc_cap在m100/k55排除，在k54不排除。
2. 当前选定透镜支持在m100/k54不排除，原始负间隙被忠实保留。
3. near34/tail20/central46的全部100个容量判定逐项匹配旧证书。
4. near33/tail21/central46通过全部100个目标容量测试及弧测试，输出仅为必要预算存活，不是覆盖。
5. 全100中心类型即使某些面积和宽松，也因弧容量0而排除。

这些弧帽/透镜计数界在U已被更强递归非服务计数约束m-k>=58所支配：m<=100时k<=42。因此本批接口重放不带来当前404必要三元组的新排除。保留它们的价值是明确历史判据、预算接口和独立运行成本，不能宣传为新增全局下界。

## 半径语义控制

本批有意要求radius_exact=U。把小半径覆盖放大到U时，服务圆盘数可能改变，范数归约也要求重新计数。因此即使某个半径单调转移在更高层可证，也不能自动把当前同一个k沿用。本轮将U减1/10^12的输入明确拒绝为PRECONDITION_MISSING。

其他负控制包括平方半径、错误计数语义、k>m、浮点证明数据、丢失配置id、错误重数、帽上界伪改、透镜高度低估、伪造积分下界，共10项，全部拒绝。

## 复杂度研究输入

正式计时校准尚未启动。当前可拆成：

- 弧帽冷重放O(J)有理平方比较，J=2000；之后固定(m,k)筛选只做有理公式求值。
- 透镜冷重放O(J*S)，J512/S128；参数优化搜索的多个delta、斜率候选不属于该验证成本。
- 多半径冷重放O(T*D*S)保守上界，实际空透镜少于上界；T100、D2、S512，实际18432非空条带。重数改变后的热筛选O(T*D)，无需重新积分。
- 输出保留每目标判定及绑定，I/O与重复大有理字符串序列化单独计价；不能把冷/热结果混成单一每节点常数。

## 剩余接口范围

本批覆盖零截距损失支持及固定径向轮廓。自由截距支持、优化帽参数、m/k前沿仍需登记为此支持接口的具体变体，不能称全部弧帽脚本已独立适配。整体还待同图连续收缩、有限弧学习与地图/树覆盖、嵌套依赖闭包。

正式独立时间校准和组合收益研究仍待接口整理完成后开展。当前目标保持进行中。
