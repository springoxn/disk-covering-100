# 第15轮：加权多见证容量与三点障碍

本轮从两两分离Hall叶推进到允许一个圆盘服务多个点的加权容量判据。没有得到新普适下界或最优值。

## 判据与证明

取单位盘内有限有理见证P以及非负有理权重w。对每个圆心矩形B_j，用点到矩形的距离筛出可能服务点集A_j。枚举A_j的所有子集；若一对子点距离平方>4T，或三点的最小包围圆半径平方>T，则删去该子集。剩余模式是实际可服务模式的超集，不要求证明Helly充分性，也不声称求出了矩形约束下的精确最小包围圆。

设C_j为剩余模式的最大权重。任何真实覆盖可将每个见证任选指派给一个覆盖它的圆盘；各圆盘所得点集必是允许模式，因此Σw≤ΣC_j。若ΣC_j<Σw则整盒无覆盖。

三点算式：边长平方排序u≤v≤w。若w≥u+v，最小包围圆半径平方为w/4；否则取三点叉积Δ，有R²=uvw/(4Δ²)。重合/共线包含在前一分支。所有与T的比较保留闭端点≤，严格缺额才排除。

## 实際退出0的证据

[主检查器](../verify/n100_weighted_witness_capacity.py) → [主回执](../verify/out/n100-weighted-witness-capacity.json)。

百盘受限盒：前99圆心在[−1/2,1/2]²，最后一个在[−1,1]²，t≤U²。取P={(4/5,0),(1,0),(9/10,9/50)}，权重(1,2,3)。所有点在D内；每一对都可由一个半径U圆盘覆盖，所以分离团Hall不能利用这三个点形成障碍。但三点最小包围圆半径平方为2809/202500>U²。前99圆心对所有点均不可达，最后一个圆心容量最多5，总权重6，缺额1。

五项负控制全部拒绝：增加可服务圆心、三点外接圆闭端点、负权重、盘外见证、零权重消除缺额。完整[-1,1]^200域上容量为500，总权重仅6，明确不能排除；这阻止受限盒升级全局。

[独立检查器](../verify/n100_weighted_witness_capacity_independent.py) → [独立回执](../verify/out/n100-weighted-witness-capacity-independent.json)，实际退出0。它不调用主检查器的三点侧积公式，而显式枚举单点圆、两点直径圆、三点外接圆的有理中心，逐点验证圆包含，核对全部8个子集及容量5；重合共线和钝角控制通过。独立实现仅验收保存的三点例子，未全面审计通用容量输入。
