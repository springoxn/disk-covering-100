# 隐藏高维对称与覆盖问题的细化/粗化转换

这是推进n100的路线分析，不是最优性证明。目标始终是二维单位闭圆盘D的等半径圆盘覆盖。

## 1. 将二维目标嵌入高维不会单独改变最优值

令P是R^d内的二维线性平面，D位于P，pi为正交投影。高维中心c的半径r球在P上的截面为中心pi(c)、半径sqrt(r²-dist(c,P)²)的圆盘（若dist>r则空）。因此若n个高维等半径球覆盖D，n个中心pi(c)、半径r的二维圆盘也覆盖D。反方向把任何二维覆盖嵌入P即可。故自由高维球心覆盖同一嵌入二维目标的最优半径与二维问题相同；投影的支配关系给出精确等价，不要求中心共面先验。

这允许在高维参数化候选，但不会自动提高下界。若要利用群对称G，必须明示：G是否保持P、投影是否与群作用可交换、对称构型是否能代表所有二维最优配置。若G保持P并与投影可交换，其作用在投影构型中也存在（可能退化或非忠实）；若G把P移到其他平面，则通常没有对应的二维旋转对称。增加维度可人工给任意有限点集加对称标签，不能把这种表示对称当作原距离问题的物理对称。

准晶cut-and-project说明可从周期高维对象得到低维非周期结构；涉及选窗、投影与度量，不能直接把周期性转成有限圆盘覆盖最优性。

更一般地，任意n个二维点都能提升为高维正单纯形顶点。先使二维点矩阵X的列均值为0，记G=X X^T，P=I-11^T/n。选λ≥tr(G)，则λP-G半正定：在1的正交补上G的最大特征值≤tr(G)，在1方向二者皆零。取额外坐标矩阵Y满足Y Y^T=λP-G，提升点矩阵Q=[X,Y]便有Q Q^T=λP。所有两点距离平方为2λ，是正单纯形，任意顶点置换均有对应的高维正交对称；投影前两个坐标恰为原点集。这是解析Gram矩阵构造，不是新的覆盖证明。提升点可能远离目标二维平面，截面半径因此损失；置换群通常也不保持投影平面。故仅存在隐藏对称是非常弱的条件。


## 2. 多个大圆的并：可用作共同覆盖，但须量化局部用盘数

设目标Omega=union_j D_j，n个小盘覆盖Omega，则每个D_j被与其相交的盘所覆盖。一个小盘可能服务多个D_j，不能假设每个大盘只获得n/k个小盘。若要作下界平均归约，需要另证局部盘数、重叠服务的最大次数或分离/边界证据。

若四个大盘彼此相离，覆盖总盘数可通过相交关系研究，仍须排除小盘跨多个大盘。若重叠，共享覆盖通常降低成本；平方2x2格中的中心平移对称不等于整个并集的连续旋转对称。D×D（四维积目标）与四个平面圆盘的并是不同问题。

## 3. 细化定理：大覆盖能产生更多小盘

若D由k个半径a的圆盘覆盖，而单位圆盘由m个半径b的圆盘覆盖，则把后一覆盖缩放a并放进每个大圆盘，得到km个半径ab圆盘覆盖D。因此r_D(km)<=r_D(k)r_D(m)，最优半径取到时可直接用；也可从认证上界a,b构造实际配置。使用少于n个盘的构型可复制中心补足n，故r_D(n)<=ab对n>=km也成立。

非均匀版本：若D由k个半径a_j的大圆盘覆盖，每个大圆盘内部用m_j个小盘、认证半径比例b_j，则sum m_j盘的统一半径max_j(a_j*b_j)给出覆盖。

这些是构造上界，不给下界，也不能由n=12的最优值反推出n=4的最优值。

## 4. 粗化定理：把已知覆盖分组压缩为更少圆盘

已知n个半径r、中心c_i的圆盘覆盖D。将中心分成k组G_j。若每组中心均在半径a_j、中心z_j的圆盘内，则该组所有小盘的并被中心z_j、半径r+a_j的圆盘包含，由三角不等式得到。于是k个统一半径R=r+max_j a_j的大盘覆盖D，给出r_D(k)<=R。

可把n=12配置分为四组三个中心并求各组最小包围圆，获得n=4的合法构造；未必紧致，不能声称最优。相反，想由此给n=100普适下界，必须证明任意100盘覆盖都可按统一a分成k组，才能推出r_D(100)>=r_D(k)-a。仅对当前候选分组不构成普适下界。

## 5. 对百盘的可检验推进

A. 在当前认证100中心构型上做分组与最小包围圆，找出可用宏观模块；比较与10x10或其他因子细化构型的覆盖半径。浮点仅作发现，输出中心、包围圆和组合覆盖需精确复核。

B. 按当前接触图寻找可分解子块，以接口边界固定条件代替独立单位圆盘假设。子块共享边界孔、中心与角间隔，必须保留这些接口约束；可尝试通过精确Schur补/力证书组合已认证子块。

C. 若发现高维对称参数化，先证明投影覆盖和全部距离关系，再检验对称约束能否无损代表全局最优。没有该无损归约，对称参数化只是一族候选上界。

当前未实现A/B/C的完整新证书，未取得r_D(100)的极小多项式。
