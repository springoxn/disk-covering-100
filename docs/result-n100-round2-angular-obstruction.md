# n=100 第2轮：固定应力角能量路线的精确否证

当前数值区间仍为 `11323/100000 < r_D(100) ≤ 1154469548855829/10^16`。本轮未得到更优覆盖、普适更紧下界或真实极小多项式。

本轮解决的是下一执行路线的选择。此前粗逐对Loewner矩阵不定，还不能说明真实能量非凸。现在从同一932变量根箱与正应力Schur补出发，证实真实谐延拓角能量在候选根处存在负方向，并构造允许角域内的显式降能锚点，因此当前固定应力的全域凸能量证明不可行。

## 精确对象与证据

设固定正应力为w，32个单位圆锚点为q，自由节点按最小Dirichlet能量谐延拓。约化能量为

`E(q)=Σ_{i<j} c_ij |q_i-q_j|²`，`c_ij`由原246节点正权图的Schur补给出。

在角变量中，Hessian二次型为

`v^T H_ang v = 2 Σ_{i<j} c_ij (q_i·q_j)(v_i-v_j)²`。

独立区间证书是决定性负号证据。浮点显示见证二次型约-2.16358×10^-5、有限步能量差约-1.08173×10^-11，仅用于说明尺度；不是判定依据。

有理旋转用 `u_i=s v_i/2`，`cos_i=(1-u_i²)/(1+u_i²)`，`sin_i=2u_i/(1+u_i²)`，有恒等式`cos_i²+sin_i²=1`。由根锚点精确单位约束可知旋转后仍在单位圆。每个相邻叉积仍正，点积大于`1-2t_root`，且连续路径不越过短弧边界，故保留单圈顺序与角隙总和2π。有限步证书有正裕量，不将较大的步长推断为仍可行。

## 对覆盖任务的含义

该反例发生在谐延拓应力能量松弛。角点加谐延拓的内部节点不保证逐条杆长≤r，因此它不是更小半径的可行覆盖，也不反驳原932变量KKT根的54维约束切空间SOSC。真实覆盖可行域须保留逐杆距离约束和孔拓扑。

固定应力的E在允许角域已经有值低于根值，故任何试图仅通过收紧这一个能量的Loewner界、角隙耦合或残差精度来证明`E≥E(root)`的路线都不可能成功。接下来改用逐杆力证书/分支树与定量局部隔离，并继续处理87族其他拓扑。尚无完成这些全局排除的证据。
