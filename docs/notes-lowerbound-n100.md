# n = 100 的下界：Stage 3 第一步结论（λ 律的天花板）

产物：`_recon/lambda_ceiling.py`、`_recon/n100_gap.py`。运行：
`python _recon/lambda_ceiling.py`、`python _recon/n100_gap.py [--search]`。

> **强度等级**：本文件给出**两条否证**（λ 形状的下界律、面积-周长实现）与**一条诊断**
> （缺口主要不在下界侧，而在构型侧）。没有任何新的下界定理；n = 100 的全局最优性
> 仍然未解决。

---

## 1. λ 律的天花板：目标 λ 是做不到的

goal §D.2 的纲领是证明形如

```
n r² >= δ (1 + λ r),      δ = 2π/(3√3) = 1.2091996                        (λ律)
```

的不等式，并且它需要有 λ ≈ 0.86 才能在 n = 100 上把下界钉到 0.1151 附近。
**但这个 λ 是被已知最优值卡死的**：λ 律若对某个 n 成立，取该 n 的**最优**构型即得

```
λ <= λ_n := (n r_n² / δ − 1) / r_n .
```

（因为最优构型的 r 最小，对不等式最不利。）用**已证明最优**的 n 值算 λ_n：

| n | r_n | λ_n | 来源 |
|---|---|---|---|
| 7 | 0.5 | 0.8945 | 精确 1/2 |
| 8 | 0.445041867913 | 0.6974 | G. Fejes Tóth（中心 + 正七边形） |
| **9** | **0.414213562373** | **0.6688** | **G. Fejes Tóth（中心 + 正八边形）** |
| 10 | 0.394930843635 | 0.7340 | G. Fejes Tóth |
| 11 | 0.379983853120 | 0.8250 | 本仓库 `docs/RESULT-n11.md` |
| 12 | 0.361102963745 | 0.8143 | 本仓库 `docs/RESULT.md` |
| 19 | 1/√13 = 0.277350098113 | 0.7524 | 已发表最优值 |
| 25 | 0.239146311738 | 0.7628 | 本仓库 `9r⁴−18r²+1` |

**λ\* = 0.6688，由 n = 9 的已证明最优值卡住**。于是：

| λ | n = 100 的下界 | 相对最好已知构型 0.122343271 |
|---|---|---|
| λ\* = 0.6688 | 0.114081200 | **−6.75%** |
| λ(n=25) = 0.7628 | 0.114671976 | −6.27% |
| goal 目标 0.83 | 0.115096232 | −5.92% |
| goal 目标 1.01（5% 门槛所需） | 0.116239489 | −4.99% |

- **5% 门槛需要 λ ≥ 1.0079；λ\* = 0.6688 只有它的 66.4%。**
- 即使把 λ 律只声称在 n ≥ 19 或 n ≥ 25 上成立（"最宽松"读法），λ 仍被 0.7524 / 0.7628
  卡住，给出的下界只有 0.11461 / 0.11467 → 仍差 6.3%。
- **范围限制（重要的诚实条件）**：若只声称在 n ≥ N₀ 上成立，则 N₀ > 25 时已知最优值
  不再构成限制（n ≥ 26 只有 n = 26 一个已证明最优值，本仓库没有它的数值）。
  也就是说"λ 律对 n ≥ 27 成立、λ = 1.01"逻辑上未被否证——但 n ≤ 26 的实测 λ 是
  0.67–0.89，要它在 n = 27 处跳到 1.01 需要额外理由，而这正是**未被证明**的东西。

**结论**：作为**全局**纲领的 λ 律（goal §D.2 想要的形状）是**假的**；作为**大 n 渐近**
纲领它未被否证，但已知数据不支持，且它本身就是要证的东西。这一形状不能再当作
n = 100 下界的引擎。

## 2. 面积-周长实现：比纯边数计数更弱

"Fejes Tóth / Oler 型"最自然的实现是每个胞的

```
A(V) <= (r/2) p(V)        （V 凸、含于半径 r 的圆盘）
```

在 n = 25 精确构型上逐胞实测（`_recon/lambda_ceiling.py` B 段）：

| 量 | 值 |
|---|---|
| 扇形式上界 `r²g(m_i,Θ_i) + cap_i` 超过周长界的胞 | **0 / 25** |
| `Σ fan` | 3.3337 |
| `(r/2)·Σ p_i` | 4.0931 |
| 恒等式 `Σ p_i = 2L_s + 2π` 给出的实际 `L_s` | 13.9740 |
| 唯一可证的普适上界 `L_s <= 2 r E_s` | 26.7844（**松 1.92 倍**） |

- **逐胞层面周长界从不 binding**（扇形式界总是更紧，比值 `cos(π/m)`），所以面积-周长
  不等式在胞层面**不增加任何东西**。
- 聚合层面它更糟：`π <= (r/2)(2L_s+2π)`、`L_s <= 2rE_s` 给出 **r ≥ 0.154042**，
  比经典覆盖密度界 0.219927 还差。
- 即使假想"已知真实 `L_s` = 13.974"（oracle），该路线也只给 **0.183551**，
  仍远弱于我们已有的 0.223544。

**结论**：面积-周长型实现**排除**。根因是唯一的普适 `L_s` 上界（每条平分线边是半径 r
圆盘的弦）太松，而覆盖性假设给不出更好的东西。

### 2b. 引擎标定（关键）：在文献成功之处也只恢复 14–21% 的缺口

文献里**唯一有先例**的全局最优性证明是 G. Fejes Tóth 的 n = 8, 9, 10（Dirichlet 胞 +
面积估计 + **radical-axis 反射**）。在我们的代码里实现的是它的前两半（"胞 + Euler + cap"）。
拿它在**已知答案**的 n 上标定（`_recon/engine_calibration.py`）：

| n | b | 真实 r | 引擎界（严谨） | 亏损 | 经典密度界 | 亏损 | **引擎恢复的缺口** |
|---|---|---|---|---|---|---|---|
| 8 | 7 | 0.4450418679 | 0.3968781796 | −10.82% | 0.3887800754 | −12.64% | **14%** |
| 9 | 8 | 0.4142135624 | 0.3757348845 | −9.29% | 0.3665453703 | −11.51% | **19%** |
| 10 | 9 | 0.3949308436 | 0.3568597440 | −9.64% | 0.3477354707 | −11.95% | **19%** |
| 25 | 16 | 0.2391463117 | 0.2239041720 | −6.37% | 0.2199272222 | −8.04% | **21%** |

（"条件界"= 已知真实边界胞数 b；无条件的版本 n = 8/9/10 分别是 0.406991 / 0.378397 /
0.360326，亏损 −8.6…−8.8%，同样只恢复 ~15%。）

**这张表是本次最重要的否定证据**：在文献**成功**的那三个 n 上，我们这套引擎只把
经典密度界的缺口填掉 **1/5**。也就是说 Fejes Tóth 在那三处成功**不是**靠"胞 + 面积"
这半部分——那一半的功率本来就不够——而必须靠**边界反射构造**（以及"中心 + 正多边形"
这一极窄族的刚性）。我们没实现反射那一块，而它恰恰是全部的功率所在。
推论：把 n = 25 / n = 100 的希望寄托在"胞不等式 + 更好的聚合"上是没有前景的。

## 3. 诊断：缺口主要不在下界侧，而在构型侧

把已证明最优值用两种等价方式记账（`_recon/n100_gap.py`）：

```
eps(n) = r_n √n / √δ − 1              相对超出覆盖密度界的比例
c(n)   = eps(n) √n                    （eps ~ c/√n 的拟合常数）
w(n)   = n − π/((3√3/2) r_n²)          "不干正事"的盘数
```

| n | r_n | eps | c | w / n |
|---|---|---|---|---|
| 7 | 0.5 | +20.30% | 0.5371 | 2.16 / 7 = 30.9% |
| 8 | 0.445042 | +14.47% | 0.4093 | 1.89 / 8 = 23.7% |
| 9 | 0.414214 | +13.01% | 0.3901 | 1.95 / 9 = 21.7% |
| 10 | 0.394931 | +13.57% | 0.4292 | 2.25 / 10 = 22.5% |
| 11 | 0.379984 | +14.61% | 0.4845 | 2.63 / 11 = 23.9% |
| 12 | 0.361103 | +13.76% | 0.4765 | 2.73 / 12 = 22.7% |
| 19 | 0.277350 | +9.94% | 0.4333 | 3.28 / 19 = 17.3% |
| 25 | 0.239146 | +8.74% | 0.4369 | 3.86 / 25 = 15.4% |
| **100（我们的构型）** | **0.122343** | **+11.26%** | **1.1258** | **19.21 / 100 = 19.2%** |

**已证明最优值的 c 落在 [0.390, 0.537]（均值 0.450）；我们的 n = 100 构型是 c = 1.126
——按这个带看是离群 2.5 倍。** 按该带外推（**⚠️ 这张表随后被撤回，理由见下框**）：

| c | 预测 r(100) | 相对我们的构型 |
|---|---|---|
| 0.3901 | 0.114253748 | −6.61% |
| 0.4496（均值） | 0.114907800 | −6.08% |
| 0.5371 | 0.115869974 | −5.29% |

即**构型侧还有约 5–6% 的半径（10–12% 的面积）空间**。这与"构型里 100 个盘有 15 个
落在单位圆外"的直觉一致（`hex_init` 取距原点最近的 100 个格点，15 个在圆外），
也与 n=100 落后于 n=7…25 的 c 趋势一致。

> **⚠️ 撤回（同日，同一次核查内）**：把 c 带当成 n = 100 的标尺是**苹果比橘子**——
> 已证明最优的 n ≤ 25 构型是**环状/高对称**的，而我们的 n = 100 构型是**格点状**的，
> 两者不是同一族。两条硬事实：
>
> 1. **格点族在小 n 根本覆盖不了圆盘**（`_recon/hex_family.py`）：n = 25 时格点补丁的
>    半径是 0.4615（真值 0.2391，差 93%），因为它需要约 80 个格点才够覆盖。所以
>    "格点 vs 最优"在小 n 的比值没有意义。
> 2. **格点族自己的 c(n) 还在下降**：n = 40 → 2.13，50 → 1.92，70 → 1.35，**100 → 1.14**，
>    140 → 1.12，200 → 0.82。我们的 n = 100 值**与它自己这一族一致**，不是离群点；
>    它相对于小 n 环状最优值"离群"，只是族不同。
>
> 另外（外部核查）：**n > 25 没有任何公开参考值** —— Friedman 的
> *Circles Covering Circles* 表止于 n = 25（其约定下 r(25) = √6+√3 = 4.1815…，
> 与我们的精确值 1/(√6+√3) = (√6−√3)/3 ✓ 一致），MathWorld 只给渐近密度。
> 所以 0.12234 这个数**没有外部标尺**，既不能说是好的也不能说是差的。
> §3 的"构型侧还有 5–6% 空间"**撤回**，改为：**是否有空间，目前无证据**。

### 一个构型侧的负结果（这个是真的）

`_recon/n100_anneal.py` 与 `n100_gap.py --search` 一共四类搜索，**全部无法改进 0.1223432713**：

| 搜索 | 规模 | 结果 |
|---|---|---|
| 自由点最深洞松弛（早先） | 12 个种子 | 0.1223432713（不变） |
| 边缘点 (ρ,θ) 坐标下降 | 39 个边缘点 × 4 尺度 | 第 0 轮后无改进 |
| 退火最深洞移动（跳出局部解） | 3 起点 × ~72k 次评估 | 0.1223432713 / 0.1231779180 |
| 结构化混合（格点内部 + k 点边界环） | 2730 组参数 | 最好 0.1225472432（更差） |

220k+ 次评估、四类不同机制，都回到同一个构型。所以在**已知的搜索手段**下，
n = 100 的构型侧没有可见的改进空间；"还有 5% 可拿"这一说法目前**无证据支持**。

## 4. 目标算术：5% 判据在两侧的敏感度

判据 `(U − L)/U <= 5%`（U = 上交构型半径，L = 已证下界）等价于 `U <= L/0.95`：

| 下界 L | 来源 | 过关所需的构型 U | 相当于构型要改进 |
|---|---|---|---|
| 0.110914 | **我们已证**的逐胞+Euler+cap 链 | **0.116752** | 4.58% |
| 0.114081 | λ 律在 λ\* 处（**未证明**，且是 λ 形状的理论上限） | 0.120085 | 1.85% |
| 0.115096 | λ 律 λ=0.83（**假的**） | 0.121154 | 0.98% |

**可执行的读法**：用**已经拿到**的下界 0.110914，只需把 n = 100 的上交构型做到
**r ≤ 0.11675**（≈4.6% 改进），5% 判据就过了。但 §3 的四类搜索（220k+ 次评估）**找不到**
这样的构型，而"有 4.6% 空间"这个预期又来自**已被撤回的 c 带** —— 所以这条路的可行性
**目前没有证据**。

## 5. 重定范围：§G 的最后一条应当执行

按 §1–§4，两侧都**没有已证明可行**的路：

- **下界侧**：λ 形状的全局版被否证（理论上限 0.114081），面积-周长实现更弱（逐胞
  0/25 binding、聚合上界 0.1540）；已证的是 0.110914。
- **构型侧**：四类搜索（220k+ 评估）找不到任何改进；"还有 4.6% 空间"的依据（c 带）
  已撤回；n > 25 无公开参考值，连"我们的构型好不好"都没有外部标尺。

所以 goal §G 的最后一条（"若 6 周内 Stage 2 仍无在 n = 25 上闭合的迹象 ⇒ 本目标降级为
n = 100 的覆盖证书 + 对称类最优"）**应当执行**。注意：Stage 2 在 n = 25 上其实**是闭合的**
（还出了精确证书），缺的是 **n = 100 的下界引擎**。降级后的交付：

1. n = 100 的**覆盖证书**（已有，三种独立方法，r = 0.1223432713）；
2. 一条**已证**的普适下界 **0.110914**（逐胞 + 带边界 Euler + cap；恒等式那一层在 n = 25 上
   有 `verify/out/euler_clipped_n25.json` 的精确证书）；
3. 写清楚并如实标注的**开放命题**：
   > **A（数值）**：存在 100 盘覆盖，其半径 r ≤ 0.11675（= 已证下界 / 0.95，即 5% 判据的
   > 等价形式）。四类搜索未找到；**目前无证据它成立**。
   > **B（分析）**：对一切 100 盘覆盖 r ≥ 0.1141（λ 形状的理论上限，**未证明**）；
   > 已证的是 0.1109。
4. 诚实声明：**n = 100 的全局最优性未解决**，且没有任何外部标尺能说明 0.12234 离最优多远。

**工具重定向建议（本文件价值最高的一条）**：本项目的机具（`rings_cover.py` 的精确环族
目标函数、`verify/euler_clipped_n25.py` 式的精确证书链、`rings_profile_search.py` 的有序
profile beam search）**已经在 n = 7, 8, 9, 10, 19, 25 上精确命中已知最优值**，而 benchmark
题面覆盖到 **n = 29**、其中 **n = 26 与 n = 27 有已发布参考指纹**。把这套机具用在那些 n 上，
性价比高于继续攻 n = 100 的 5% 代理指标：答案存在、可对照，且搜索空间可能仍在环族内
（26 = 1 + 5·5 ✓ D5；27 = 1 + 2·13 ✓ D13；28 = 4·7 ✓ D7 无中心）。

## 6. 诚实边界

- §1 的否证只针对 **λ 形状**（"δ + 线性边界项"），不针对"任何可能的下界方法"；
  且它有范围条件：若只声称在 n ≥ N₀ 成立而 N₀ > 25，已知最优值不再构成限制
  （n ≥ 26 只有 n = 26 一个已证明最优值，本仓库没有它的数值）。
- §3 的 c 带**已撤回**：小 n 最优值是环状族、n = 100 最好构型是格点族，两者不可比；
  格点族在小 n 甚至覆盖不了圆盘。"构型还有 2–6% 空间"**不是结论**。
- §4 的 0.114081 是"λ 形状的理论上限"，**不是已证下界**；我们真正已证的是 0.110914。
- §2 的否证是硬的：逐胞 0/25 binding、聚合上界 0.1540、oracle 0.1836，都算得出来。
- n = 100 的 r 真值未知，本项目 0.1223432713 是自建最好构型；**没有任何外部标尺**。
