# 阶段116：边界耳尖模式的完备必要松弛计数

主程序和独立程序均退出0。以阶段114的各家族允许耳数为输入，统计边界环上的非相邻二进制耳尖词，按旋转去重（未按反射再去重）。

m99各B的旋转模式数：B32:1，B33:17，B34:1080，B35:1188，B36:1313，B37:2。例：m100/B32有12734个旋转模式。这些均为必要边界词松弛计数，不能解释为可行几何地图数。

## 精确计数

长度B、恰e个非相邻耳尖的带标签循环词数为

`W(B,e)=B/(B-e)*binom(B-e,e)`。

允许耳数列表逐家族来自前置证书，不假设它一定是完整整数区间。旋转s的不变词是长度d=gcd(B,s)块重复B/d次；只有总耳数e可被B/d整除时才可能。Burnside平均固定词数给旋转轨道数。

长度1、2的周期块采用相同的循环不相邻约定：长度1只允许零词，长度2允许零词和两个单耳词。这些小周期在大边界的重复词计算中必需，不能省略。

## 独立复核

独立程序不使用主组合数公式求循环词数，而用首位/末位/已用耳数的转移DP，并闭合首末邻接。旋转轨道数通过最小周期原始词递归分解重建，独立于主Burnside平均实现。

实际17家族的全部标签词数、旋转固定计数及轨道数逐项一致。另外完整枚举长度1..14的所有二进制词并筛选非相邻性，共2204合法词，直接规范化全部旋转，与DP及最小周期计数逐耳数一致。

## 与完整地图枚举的区别

此结果完整覆盖“耳尖非相邻+允许总耳数”的边界词松弛，并不构造每个代表词的内部剖分。某些词可能没有符合要求的内部三角图或几何覆盖。此前不交耳组限制还能进一步剔除某些总耳数合规的词；本轮没有逐词应用这些更细限制。

因此不能把轨道数当成完整归一化地图数，也不能把词存活当成连续覆盖可行。要完成目标，仍需对每个相关边界模式构造完备内部地图前端、证明所有必要退化分支被包含，再联立连续不可行证书。
