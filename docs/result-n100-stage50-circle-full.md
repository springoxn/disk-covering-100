# 阶段50：全部固定核心方案的圆周传播验收协议

## 范围

输入为阶段42的4776条保留记录，并与阶段39完整方案集合逐项比较。仅扫描这个固定核心，不枚举其他核心，也不改变87组全局必要计数族。

每案例引入32个核心边界顶点的单位圆等式与象限，再传播562个面心—顶点关联的距离<=U约束。面心初盒来自阶段42，原始顶点盒为实区间[-Q,Q]^2，Q=2^20。所有判定使用整数与精确平方根取整，未知点不受整数格点限制。

四轴细分产生的新顶点、边界严格次序、共圆等式的其他耦合均未补齐。省略约束是放松，严格空盒仍可作为必要域排除；任何非空结果都不提供覆盖构造。

## 可复现入口

```
python verify/n100_boundary_circle_full.py
python verify/n100_boundary_circle_full.py --independent
python verify/n100_boundary_circle_rational_controls.py
```

默认输出分别为verify/out/n100-boundary-circle-full.json、verify/out/n100-boundary-circle-full-independent.json、verify/out/n100-boundary-circle-rational-controls.json。输出拒绝覆盖；复跑需为扫描命令传--out新路径（独立模式默认核对主默认证书）。有理控制脚本需要保留原输出或在独立副本执行。

本文件先记录验收协议，完整实际计数以运行结束后的结果附记与证书为准，不将运行中的进度当作最终结论。

## 实际完成结果

主扫描与独立重放均实际退出0，证书为verify/out/n100-boundary-circle-full.json和verify/out/n100-boundary-circle-full-independent.json。4776个方案中严格空盒排除564；非空固定点4188；40轮上限仍收缩24；非空保留总数4212；真实候选[30,6,14,22]保留。24个capped案例不作可行或不可行判断，4212个非空域也不构成覆盖配置。

独立脚本用逆外面遍历、逐边象限判定、整数二分平方根和独立距离承包器，逐项重建主记录摘要、失败状态、轮数、失败变量、失败盒及最终状态；排除集合和全部摘要一致。摘要绑定的完整结果可由输入和脚本确定性重建。
- 输入4776方案集合必须与阶段39完全一致，无重复或遗漏；
- 每案例核查32边界顶点、562关联；
- 空盒为excluded；40轮上限非空为capped；无变化非空为fixed；后二者全部保留；
- 真实候选[30,6,14,22]必须保留；
- 每条记录保存完整传播结果（含所有最终盒和计数）的规范JSON SHA256；
- 距离失败额外保存失败两盒及变量索引，圆周失败保存失败约束身份；
- 独立算法不调用主传播器，使用逆外面遍历、逐边象限判断、整数二分方根与阶段42独立距离收缩器；
- 独立完整重放后比较每条结果摘要、排除状态、轮数和失败盒，而非只核对计数；
- 摘要不是盒本身。全部最终盒可通过绑定的入口和输入确定性重建；摘要确保独立重建结果逐项相等。

## 精确有理点控制

有理参数化(x,y)=Q((1-t²)/(1+t²),2t/(1+t²))，t=k/40，k=0..40，在四象限给164个有理单位圆点。每点构造4种整数端点外包，共656例；两种圆周承包器均保留精确点。错误象限、严格内侧盒、严格外侧盒三项拒绝控制通过，证书实际退出0。这是有限控制，保守性解析论证仍见阶段49报告。

## capped深化结果

对阶段50的24个capped方案执行160轮同一整数传播，主/独立重放均在同一脚本中逐项比较并实际退出0，证书为verify/out/n100-boundary-circle-capped160.json。结果为12项严格空盒排除、12项达到固定点、0项仍capped。此前阶段50的4212非空保留因此在这24项中进一步减少12，若仅对本固定核心的该必要松弛计数，当前严格排除总数为576，固定点保留总数为4200；真实候选不在这24项capped集合内，已由阶段50保持保留。
