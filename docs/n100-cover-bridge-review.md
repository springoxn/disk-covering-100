## 2. 根数据（区间，独立重算）

根箱为有理中点 ±`10^-58`（Krawczyk 已验收，属 DEPENDENCY）。

- 全部 492 个点坐标 `|x| ≤ 0.9987 ≤ 2`；`t* ∈ 0.013327999392353651`。
- **406 条杆在根箱内的区间舍入到 0**（`max |rod| ≤ 1.66×10^-58`，即舍入宽度量级）：源系统把 406 条杆全部作为**等式**，
  故在精确根处 `F(p*,C*) = 0` **精确成立**。这是"一个支撑覆盖则该孔全体支撑等距覆盖"的必要前提，`INTERVAL`。
- 114 个内孔 `1−|p*|² ≥ 0.175455`；32 个边界孔 `|p*|² = 1`（区间含 1，宽度 ~10^-59）。
- 每个支撑分支的 2×2 Jacobian 区间行列式不为零，`min |det| = 0.126665`，
  `max_h ||J_h^{-1}||∞ = 6.0798`。故 `K = 10^6` 是**安全但极松**的界（实测松约 1.6×10^5 倍），不是紧常数。
- 14194 个非支撑 (中心,孔) 对：`min (下界 d² − 上界 t) = 0.018771 > 64(η+ε) = 6.4×10^-44`。

`docs/n100-cover-bridge-increment-bounds.md` 的做法改用**增量区间**（各自的根值区间与扰动值区间作差取偏差），得到
`4η+8ρ`，与解析式 `16ε+4η` 一致。同时记录：即使采用更松的全宽约定，收缩结论 `K·pert ≤ 1/2` 依然成立，
故收缩步骤不依赖约定选择。**解析公式 `16ε+4η` 有效，不需要改动。**

## 4. Banach 的定位（必须写成定理，不是假设）

这一段在本轮材料里此前只以"收缩映射预算"的形式出现，应显式写成定理：

> 固定中心 `C ∈ C* + [−ε, ε]^{200}`。取 `J* = D_pF(p*,C*)`、`T(p) = p − J*^{-1}F(p,C)`。
> `B̄∞(p*,η)` 在 `∞`-范数下是完备度量空间。若 `‖DT‖∞ ≤ K(16ε+4η) ≤ 1/2` 且 `‖T(p*)−p*‖∞ ≤ 64Kε ≤ η/2`，
> 则 `T` 把 `B̄∞(p*,η)` 映入自身且为 `1/2`-压缩，**由 Banach 不动点定理**存在唯一 `p_h(C) ∈ B̄∞(p*,η)`
> 使 `F(p_h(C),C) = 0`。

要点：存在性/唯一性是定理的**结论**，不是输入；脚本只检查那两个标量预算。内孔另有 `1−|p*|² > 0.175` 的严格余量，
故 `p_h(C)` 仍在开单位盘内（`32η+2η²` 的门槛远小于该余量，阈值本身保守）；边界孔由第二方程保证 `|p_h(C)| = 1`。

## 5. 覆盖推理与"不需要库存完备性"

链：固定规范 + 中心在 ε 盒 + 真实覆盖半径 `t ≤ t*` ⟹

1. 每个持久孔点 `p_h(C)` 在闭单位盘内（内孔靠余量，边界孔靠单位方程），故被某中心覆盖，`|c_i − p_h(C)|² ≤ t`；
2. 非支撑中心满足 `|c_i − p_h(C)|² > t* ≥ t`（间隙 0.0188 减去扰动传递 1.6×10^-44），排除；
3. 覆盖中心必属支撑集；又由构造 `F(p_h(C),C) = 0` 得支撑集内各中心等距，故**全部**支撑杆满足 `f_j ≤ 0`；
4. 32 条单位等式成立；固定规范等式成立。于是提升后的 493 向量落入固定杆域；
5. 支撑距离平方与 `t*` 偏差 `≤ 64(η+ε)`，故 `t ≥ t* − 64(η+ε)`；
6. 该向量与精确根距离 `≤ 1.472×10^-42 < 10^-40`，由已验收固定杆局部定理得 `t − t* ≥ ‖h‖²/(4×10^12) > 0`（除非 `h = 0`）。

结论：`t ≤ t*` 只能等于 `t*` 且 `C = C*`，即该 ε 盒内无改进覆盖、根在盒内唯一最优点。

**对"不需要库存完备性"的审查意见：成立。** 406 条杆是从根读出的固定 (中心,孔) 关联集；被告覆盖的孔点由
Banach 分支从中心**生成**，不枚举被告自身的 Voronoi 胞/孔。被告若有额外接触，只会**增加**约束，不会把 `t` 压到
域最小值之下。因此该桥确实只需"持久支撑孔 + 覆盖假设"，无须被告侧的完备清单。这是本轮最有价值的部分。
