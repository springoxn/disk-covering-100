# 阶段80：连续标签区间冲突推广及零额外收益

命令：`python verify/n100_arc_range_nogood.py`，实际退出0。证书：`verify/out/n100-arc-range-nogood.json`。

## 推广方法

取node27当前8条禁配中的第一条四顶点冲突。将每个单标签j推广为连续标签区间[lo,hi]，对其对应完整圆弧区间作坐标外包，再限制继承父盒并执行几何传播。每次只有主、替代实现完整结果一致且严格判空，才接受扩大。

同象限每个坐标随参数单调，连续弧段联合的坐标外包可由首末闭弧段外包取坐标最值构造。采用闭弧外包，未将顶点固定到参数格点。每个区间保持包含初始标签；按低端、高端顺序试探端点及二分值，不声称所得冲突最大或全局最优。

## 精确收益检查

将禁配满足位改为“某个顶点标签落在其禁配区间之外”，对原有限模型重跑支持DP和整数赋值计数。三组可穷举小模型覆盖区间多文字、单元完整域禁配及混合单点/区间禁配，支持和计数均与穷举一致。

结果：支持标签1859→1859，完整标签赋值数

`4233354339792243657657309094862499`

前后完全相等，保留比例精确为1。对每个顶点检查新支持为旧支持子集；所有返回见证满足推广后的区间禁配。

因此本轮证实了更大的条件几何冲突，但它没有排除原有限允许模型中的额外组合。不能仅按区间宽度变大宣称剪枝增强。完整组合计数提供了这一零收益判断，单点支持相等本身不足以得出该结论。

## 范围和下一步

这次结果与阶段79的微小削减率一起表明，继续沿当前最小标签见证逐点或逐区间扩大，尚不能有效压缩node27。后续应改变分支/见证选择或加强几何相关约束，而不是只累计同类角点冲突。
