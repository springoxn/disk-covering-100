## 最近点不等式

对每个顶点选择一个所属圆心a，对全部非所属圆心b施加

`|v-a|² <= |v-b|²`。

其线性形式为`2v·(b-a)+|a|²-|b|² <= 0`。系数与常数分别作整数区间外包；残差区间下端严格大于0时判空。系数区间不跨零时，使用另一个坐标贡献的下端得到必要的单坐标半空间限制；商端点向外取整，保留盒内非整数实坐标。

商区间实现分别使用整数交叉除法与Fraction端点，两种实现逐次相同。运行前代码已将端点方向统一为上界向上、下界向下外包；未将整数格点限制误用于连续实盒。43个有理点保留控制、严格拒绝和重合圆心控制通过。

每案19238条不等式，输入为两个分支及真实候选[30,6,14,22]的阶段69父盒。三案均一轮固定、无收缩、无排除，真实候选保留。

只用一个所属圆心的最近点条件是Voronoi模型必要条件，其他所属圆心相等仍是模型依赖。没有机器证明所有覆盖都必能落入当前固定Voronoi核心；不能把这些条件当作全局核心枚举的替代。
