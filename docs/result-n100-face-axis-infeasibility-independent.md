# 双轴面全域排除的独立负一证书

[独立检查器](../verify/n100_face_axis_infeasibility_independent.py)实际退出0，[回执](../verify/out/n100-face-axis-infeasibility-independent.json)保存六个模型的负一组合乘子、上界约束、正余量和错误证书控制。

上一轮下界为t−L=(gP+gQ)/2+两个平方，其中L=|P−Q|²/4。加入h=T−t≥0，δ=L−T>0，则

 -1 = (gP/2+gQ/2+两个平方+h)/δ。

每个约束乘子和平方乘子为正，右侧任何可行赋值下非负，而左侧为−1。因此排除整个闭可行域，包括所有退化赋值。无需求局部极小点。

独立实现不导入主SOS实现。它读取原编译模型，核对实际轴等式与精确代入，检查距离约束索引、支撑变量、乘子符号、平方索引和上界绑定。代入轴坐标后剩余仅三个自由变量(cx,cy,t)，每变量次数≤2。对{-1,0,1}^3的27个完整有理节点检验负一恒等式，通过逐变量插值定理得到全多项式身份。六模型共162个节点。这是带次数界的完备恒等式判定，非随机数值测试；插值定理仍为解析依赖，未形式化内核。

负乘子、错误平方偏移、错误原约束引用、错误下界四项篡改均拒绝。依赖文件与主脚本哈希均绑定。

范围：六个V4,E5,m2,B4模型在当前T下的全域排除已经有独立验证；一般双轴同面规则有精确恒等式支持。仍未实现一般大模型SOS搜索，未完整枚举/排除百盘剩余地图，未处理候选图邻域外连续域。当前候选没有触发双轴同面。
