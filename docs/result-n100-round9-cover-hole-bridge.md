# n=100 第9轮：固定规范中心邻域的覆盖—杆域桥

[桥接脚本](../verify/n100_cover_hole_bridge.py)实际exit0，回执见[桥接证书](../verify/out/n100-cover-hole-bridge.json)。[独立审查](../verify/out/n100-cover-bridge-review.json)父会话最终重跑exit0，34项检查及6项破坏控制通过。它重新读取932变量源和根箱，使用中心坐标半宽`ε=10^-54`、孔坐标延拓半径`η=10^-45`、保守支撑Jacobian逆界`K=10^6`，检查：

- 114个内孔的三中心等距方程和32个边界孔的两中心等距+单位圆方程，共146个支撑分支；
- 146个支撑Jacobian区间的行列式可逆；
- 全部14,194个非支撑中心—孔距离都有严格正于`t*`的间隙；
- 内孔仍严格在单位圆内，边界孔仍在单位圆边界；
- 隐函数收缩映射的自映射预算`64Kε≤η/2`和导数扰动`K(16ε+4η)≤1/2`；
- 提升后的493变量距离上界严格小于第6—8轮固定杆局部球`10^-40`。

根处`F(p*,C*)=0`由已认证精确根的406条杆等式推出，不由有理中点残差为零推出。每条等距差方程是两条活跃杆等式之差；边界第二方程直接是单位约束。[增量界与收缩映射定理说明](n100-cover-bridge-increment-bounds.md)给出自映射和唯一分支存在性的解析证明，[独立审查稿](n100-cover-bridge-review.md)核查了该逻辑及距离扰动转移。

## 必要约束的逻辑

在固定规范、中心坐标位于上述根邻域且真实覆盖半径满足`t≤t*`时，每个持久支撑孔仍在目标闭圆盘内，因此必须被至少一个中心覆盖。所有非支撑中心与该孔的距离平方已严格大于`t*≥t`，所以覆盖该孔的中心只能来自其支撑集合。于是每个支撑中心—孔距离都满足`f_j≤0`，并且32个边界孔满足单位圆等式。146个孔共给出原406条活跃杆中的全部距离不等式。

不需要声称附近所有局部极大点的完整库存：只要这些已认证的146个支撑见证孔持续存在，覆盖本身就强制出406条必要杆不等式。对应支撑孔坐标由等距/单位圆方程的局部隐函数分支给出；脚本的区间Jacobian、收缩常数与距离间隙是该桥的算术输入。

支撑距离平方与`t*`的偏差至多`64(η+ε)`，故必要时`t≥t*−64(η+ε)`。由此得到提升后的493变量点在固定杆域局部球内，再应用第6—8轮增广拉格朗日排除。

## 结论范围

这形成了一个**固定规范、根中心中心邻域**的覆盖必要约束桥：其中不存在半径`t<t*`的覆盖；等号点也只能落在已认证根的局部约束域。它不是全局覆盖叶：没有处理中心离开该邻域的分支、其他接触图、规范切片之外的旋转副本、退化和87族全域排除。脚本回执明确`global_topology_exclusion=false`。

因此本轮没有把候选根升级为`r_D(100)`，也没有声称取得真实极小多项式。
