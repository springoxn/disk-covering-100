# 当前上界下至少28个不同边界服务盘

[主检查器](../verify/n100_boundary_serving_count.py)与[独立检查器](../verify/n100_boundary_serving_count_independent.py)均实际退出0。证据分别见[主回执](../verify/out/n100-boundary-serving-count.json)和[独立回执](../verify/out/n100-boundary-serving-count-independent.json)。此结果是枚举必要条件，不是新的最优值或新的普适半径下界。

## 不限对称性的解析论证

取0<r≤U=1154469548855829/10^16<1。圆心范数为ρ的圆盘若ρ=0不能服务单位圆周。ρ>0时，沿圆心方向测角，圆周在盘内当且仅当cos θ≥K=(1+ρ²−r²)/(2ρ)。若K>1交为空；若K≤1，由ρ²+(1−r²)≥2ρ√(1−r²)，得K≥√(1−r²)>0。因此一个圆盘服务的全部圆周弧长至多2 arccos√(1−r²)=2 asin r；包含相切时的零长度弧，也允许中心在D外。

若k个不同圆盘服务并覆盖圆周，弧长有限次可加上界给出2π≤2k asin r。积分表示asin r=∫_0^r(1−s²)^(-1/2)ds≤r/√(1−r²)，故k U/√(1−U²)≥π是必要条件。

用Machin恒等式π=16 atan(1/5)−4 atan(1/239)与交错级数，π>16(1/5−1/(3·5³))−4/239>157/50。两个Machin项的分支可由tan(4 atan(1/5))=120/119及差角公式得到tan(4 atan(1/5)−atan(1/239))=1；角在(0,π/2)固定为π/4。界限使用严格交错余项，无浮点π常数。

有理判定证明(157/50)²(1−U²)−27²U²>0，即27 U/√(1−U²)<157/50<π。这与覆盖必要条件矛盾，故k≥28。同一粗界不排除k=28；没有据此证明28盘可以覆盖圆周或整个D。

## 地图前置过滤

若一个合法覆盖模型可行，圆周每条边的整弧被对应内面圆盘覆盖（同象限短弧引理）。收集所有外边邻接的不同内面，得到覆盖圆周的盘集，因此不同边界面数必须≥28。一个面可以服务多条弧；重复圆心只会减少不同盘数，不削弱该必要条件。

候选经主边列表计数与独立面循环关联重算，确有32个不同边界面、36条圆周边。四轴点细分增加边数，不增加边界服务盘数。六个小模型只有两个不同边界面，因此均被这项结构条件排除；这只是对此前已排除模型的另一校准。

独立实现将所有平方比较清分母为整数：157²(b²−a²)−50²k²a²，a=1154469548855829,b=10^16。它未导入主Fraction实现，重建边所有者集合，拒绝用同一粗界声称至少29或30个盘。解析弧长、Machin分支与交错余项不是形式化内核结果，证明已明确列出。
