# n=100 阶段39：真实核心四轴方案的内盘链距离排除

本轮把内部图结构接到上一轮的5280个轴点插入记录，避免只依赖外环弧预算。

## 盘链必要界

每个内面对应一个半径不超过U的覆盖盘。若两个面共享组合边，则它们都覆盖该边端点，故两圆心距离不超过2U。若轴点p属于首盘、轴点q属于尾盘，连接二者的内面对偶路径包含k个盘，则三角不等式给

`|p-q| <= U + (k-1)*2U + U = 2kU`。

所以 `|p-q|² > 4k²U²` 时该轴方案不可行。路径不得经过外面，外面不是覆盖盘。用于k盘链的每条邻接边都保存了实际半边身份，检查器核验邻接两侧的面。

对于相邻轴点，平方距离为2；对径轴点平方距离为4。现行U给 `(12U)²<2`，所以只有6盘的相邻轴链必不可能。
