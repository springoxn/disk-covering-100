## 推导

阶段108的各层已收紧m-k，但外层(m,B)仍使用U处的联合面积前沿。本轮在各层保存上端点rho重新检查每个旧存活家族。

若sin(pi/B)>rho，圆周弧容量排除；否则令x=sin(pi/B)，A=3sqrt(3)/4、kappa=461134488/10^9，必要条件为

`[((2m-2)/B-1)A+kappa]rho² + x sqrt(rho²-x²) - x cos(pi/B) >= 0`。

对每个家族用有理三角函数和平方根区间算出整个残量的上界。若上界严格小于0则排除该家族及其所有k标签。对存活家族，本轮区间下界严格正；不存在未定区间被自动接受。

该必要条件对rho单调放宽，故在保存上端点被排除的家族在更小半径同样被排除。这里是在当前半径归一化后的整数标签上用较大半径的必要松弛，不把某个U处几何代表或其原所有者集合移到较小半径。

## 独立复核

独立程序不导入主生成器或上游判定函数。它复用已有独立算术辅助函数，重新构造Machin pi区间、正余弦级数、平方根外包，重算204家族的分类，重新从旧层域过滤所有三元组，逐项比较保留/删除集合及家族数。

还核对四层新域包含关系和候选整数标签(100,32,32)的保留。标签保留不证明任何候选能在较小半径覆盖。

## 适用边界

本轮是三个条件半径层的实际有限计数域增强。U处域未缩减，全局半径下界未提高，固定核心几何盒未重跑。几何依赖仍是共同图归一化、单弧归约、联合三角形面积、边界凹性；未在本轮独立形式化。
