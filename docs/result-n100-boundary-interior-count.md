# 内外耦合计数与候选根盒圆周服务分类

[主检查器](../verify/n100_boundary_interior_count.py)及[独立整数检查器](../verify/n100_boundary_interior_count_independent.py)实际退出0，见[主回执](../verify/out/n100-boundary-interior-count.json)、[独立回执](../verify/out/n100-boundary-interior-count-independent.json)。

半径r≤U<1/2的盘若碰到单位圆周，圆心范数≥1−r，故任何盘内点范数≥1−2r。于是圆周服务盘完全不能进入开内盘|p|<1−2r。其余q个盘必须覆盖该开内盘，面积次可加给出qπr²≥π(1−2r)²。因此q≥ceil((1/r−2)²)。该比值随0<r<1/2单调递减，当前U处严格在44与45之间，故q≥45；相切属于边界服务盘，不影响开内盘论证。

结合至少28个不同圆周服务盘，任意最多100盘的覆盖在当前区间必须有28≤k≤55个圆周服务盘，至少45个非服务盘。仅此论证给出总数至少73，远不足以排除100，不形成新半径界。一个抽象模型的边界面数不超过真实服务盘数，故边界面≤55是必要条件，但不能据此声称恰有45个非边界地图面不服务圆周。

候选全根盒以判别式4|c|²−(1+|c|²−t)²严格分类；正分支已检查。全部100个中心无未定：32个服务圆周、68个不服务。32标签恰等于既有边界面集。这是根盒几何事实，不仅依靠地图标号。独立实现全部清分母，只用整数，重算内盘容量和100个服务判别式。

这组必要条件的强度弱于此前部分全局下界计数限制；新增的是独立几何解释、可执行筛选与候选实际服务分类，不宣称加强已接受87个计数族或完成地图枚举。
