# 第12轮验收总账与未闭合的全局域

本轮完成一个具体LOCAL盒排除器与证明链哈希总账；持续目标未完成。

[LOCAL叶检查器](../verify/n100_local_leaf.py)实际exit0，[示例叶](../verify/out/n100-local-leaf-example.json)给出200个中心坐标区间及平方半径区间。中心盒半宽10^-38，平方半径上界取有理中点t0−2×10^-58，因此严格低于精确根t*。逐坐标距离根的保守界≤10^-37，满足已独立验收的无规范局部排除定理。四项负控制：过大中心盒、半径不低于根、漏坐标、损坏哈希，全部拒绝。[运行证据](../verify/out/n100-local-leaf-check.json)。

该叶中的t范围从0到t0−2×10^-58。局部定理无需预设t在t*附近：若这么小的t仍能覆盖，持久孔本身会强制t≥t*−64(eta+epsilon)，从而提升回固定杆局部球并得到矛盾。因此接受该叶不偷加“覆盖半径已经靠近根”先验。

[总账检查器](../verify/n100_local_chain_ledger.py)实际exit0，[总账](../verify/out/n100-local-chain-ledger.json)核查49条依赖及脚本哈希，并单独确认独立审查回执绑定当前主预算和脚本。它拒绝仅凭这个LOCAL叶升级全局端点的尝试。

## 已取得的内容

- 固定上游932变量孤立KKT根、连续覆盖及54维SOSC已有此前实际重放证据。
- 当前固定应力谐延拓角能量非凸，已用负方向及有限有理旋转降能证书否证该全域凸性路线；未构造更优覆盖。
- 正应力的一阶对偶、增广拉格朗日定量局部杆域排除、146个持久孔覆盖对应和旋转规范消除已组合，独立精确预算支持无规范中心坐标半径10^-37。
- 本轮把其中一个中心盒变成可执行的LOCAL排除叶，未声称存在完整全局证明树。

## 八项缺失证据

1. 完整接触拓扑枚举及独立规范轨道集一致性；87组(m,B)是必要参数族，不是已枚举图集。
2. m=96..99等少于100有效中心的所有覆盖分支排除。
3. 当前候选图以外全部图的完整连续域证书。
4. 当前候选图在已排除局部邻域之外的域排除，或更优覆盖的发现与精确化。
5. 所有退化、孔碰合、中心重合、并行/非泛型分支的完备处理。
6. 无对称性限制的普适下界与候选精确端点闭合等号。
7. 由已证明最优端点导出的本原不可约极小多项式全部系数及不可约性证书。
8. 最优半径的有理根隔离和唯一根证明，绑定前述等号与多项式。

这些缺口不是哈希或算术失败；它们是尚未构造的数学/枚举证据。持续目标保持active，不标complete，也不将自动轮数上限当成数学阻塞。第12/12轮仅结束当前自动续跑额度，不代表原目标达成。

当前区间不变：`11323/100000 < r_D(100) ≤ 1154469548855829/10^16`。没有取得r_D(100)本身的极小多项式。

下一具体研究单元应转入完备图枚举前端与连续域排除，而非继续只优化局部邻域常数。已证明的局部叶可作为该前端遇到候选图根附近时的一个排除接口；必须为其余域出具独立证据。
