## 已取得证据：输入

执行 `python verify/audit_inputs_n100.py` 退出0，产物 [输入清单](../verify/out/input_inventory_n100.json) 的 `sources[0].exact_input_valid=true` 与 `sources[1].exact_input_valid=true` 确认两份历史文件各含100个互异、可解释为精确有理数的二维中心。其中85个中心在单位闭盘内、15个在盘外；[正式题面](goal-n100.md#L25) 允许盘外中心。

[自由点结果](../runtime/freecover_n100.json) 与 [退火结果](../runtime/n100_anneal.json) 的规范化十进制有理中心列表具有相同SHA256：`329581ebb0cb2f93ab0217194691ce4d4d0bb9b0b4770636d65dd3a7a678e8ac`。因此两份文件保存了相同的精确定义输入，不能作为两个独立构型。

[输入审计工具](../verify/audit_inputs_n100.py) 使用JSON的 `parse_float=str` 保留十进制文本，以 `Fraction` 判定输入和盘内中心数；显示半径仍是历史字符串。清单的 `mathematical_coverage_verified=false` 明确本步骤不认证覆盖。

[极坐标数据](../runtime/n100_polar_probe.json) 是105条参数记录，[环探针](../runtime/n100_ring_probe.json) 是16条参数记录；[profile结果](../runtime/profile_search_n100.json) 的best没有P坐标数组，历史radius为 `0.12556157657685146`。这些有限搜索摘要不构成最优性证明。

[生成工具](../tools/freecover.py#L47) 用格距扫描及最近点截断；同范数并列时重新截断可能得到不同中心集合。本阶段优先保留JSON中的实际有序坐标，不以重新生成“最近100点”替代源输入。格距89/420与Q(√3)恢复仅为发现方向，除非另有转换证明，不把十进制坐标与代数格点宣称为相等。

## 下界义务与真实未决范围

[下界审计](audit-lowerbound-n100.md) 及下界证书的`chain_items`列出20项证据等级。面积法解析论证为 `area(D)≤Σarea(B(c_i,r))=100πr²`，消去正π得 `100r²≥1`，故r≥1/10；机器核对有理恒等式和正性，不以机器记录代替测度论证。

历史0.1109141386降级为`not_certified`。未闭合范围包括边界退化、胞数与弧数不一致、扇形分解中心归属及cap上界、盤外中心、重合/共线/冗余盘及边界等号；n25实例Euler证书不能外推。义务清单是一份人工审计及可追溯记录，程序校验其算术和一致性，不宣称自动证明全部解析引理。历史原文保留，涉及“加强下界已证”的旧句子由本审计与当前状态明确取代。

全局最优性、局部最优性、对称族内最优性、最优半径的极小多项式仍未证明。当前区间的相对缺口为28/153，约18.3%；不满足5%代理指标。面积下界对应的5%上界阈值为2/19，不能用渐近密度数值推断有限n=100下达到该阈值不可能。
