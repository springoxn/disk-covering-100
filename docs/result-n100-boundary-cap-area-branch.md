# 面积帽强化的分支排除：k=55，r≤23/200

[主检查器](../verify/n100_boundary_cap_area_branch.py)和修正后的[独立复核器](../verify/n100_boundary_cap_area_independent.py)均实际退出0。见[主回执](../verify/out/n100-boundary-cap-area-branch.json)、[独立回执](../verify/out/n100-boundary-cap-area-independent.json)。

一个服务单位圆周的半径r盘，其圆心到原点距离d≥1−r。沿该圆心径向取横坐标x，内盘半径s=1−2r+δ，内盘点满足x≤s，故落在服务盘内的截面从左端x=d−r起最多宽δ。令z=x−(d−r)，盘截面高度≤2√(2rz)，因此该盘进入内盘的面积≤∫_0^δ2√(2rz)dz=(4/3)√(2rδ³)。d更大只使帽更小，δ<2r保证计算范围有效。

对m盘、其中k个服务圆周，内盘必须被覆盖，所以必要条件

 π(1−2r+δ)² ≤ (m−k)πr² + k(4/3)√(2rδ³)。

取r0=23/200,δ=1/125,m=100,k=55，左右差有严格正有理下界。π区间来自Machin恒等式和交错级数，平方根通过整数isqrt上取整到分母10^20，全部判定精确。主回执还保存m96..100,k53..55的各项计算，不把未排除项冒充通过。

r≤r0时排除也成立：固定目标内盘s0=1−2r0+δ，对更小r，服务盘距原点≥1−r，盘进入目标内盘的深度≤δ−2(r0−r)≤δ，非服务盘面积与帽高度上界也不增加；若深度负则无交。因此r0处的上界证书适用于全部r≤r0，不仅端点。

此前δ=0内盘面积条件在r0处不排除45个非服务盘，故该面积帽论证在此分支确有强化。但此前更强整体下界的计数族可能已经不含k55，不宣称全局下界提高。

当前候选上端U=1154469548855829/10^16使用同参数未得到正余量，是明确不通过控制。无法声称k55在整个当前最优区间排除，更无法排除k≤54全部分支。
