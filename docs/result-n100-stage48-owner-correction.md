# 阶段48：撤回空边界环带验收，重验真实边界与自同构

## 必须撤回的历史结论

阶段45、46的主/独立脚本把outer标签直接用于内面循环。outer标签仅属于外面一侧的dart，每个内面全部dart都标inner，所以待检边界拥有面集合为空。阶段46终端已经输出boundary faces []，当时没有拦截，是审计遗漏。相关旧证书虽然exit0，实际上没有检查任何边界面；它们不能作为环带筛选已验收证据。此前“独立重算”复制同一筛选逻辑，没有消除此错误。

正确方法：先识别外环半边d，再用alpha[d]定位内面；随后把原核心面编号转换成排除外面后的面心盒索引。不能仅找到正确面编号却忘记索引偏移。

## 修正后的实际运行

以下命令均实际退出0：

```
python verify/n100_boundary_owner_correction.py
python verify/n100_boundary_owner_correction_independent.py
```

主证书verify/out/n100-boundary-owner-correction.json；独立证书verify/out/n100-boundary-owner-correction-independent.json。

修正版确认32个不同边界拥有面，在阶段42的4776方案上实际执行152832次环带比较。原点和单位圆点算术控制通过。比较用整数直接交叉相乘：若盒最大平方范数乘UD²小于(UD-UN)²Q²，则该拥有面不可能服务圆周。没有平方根或阈值向下截断。

独立版本经无向边两侧面关联重建拥有者，不使用原错误标签谓词；通过四角平方范数最大值计算盒最大范数，重建全部检查次数与最小余量。

实际新增排除0、4776保留、真实候选保留。这次是真正检查了环带判据，但仍不证明盒与圆环联合约束有精确可行点，只证明该判据没有发现整个盒都落在内圆的情形。

## 对称性结果

穷尽核心594个半边作为固定根的目标像，并沿alpha/phi传播映射；每个成功映射都重新检查双射、全部半边标签和置换交换。独立算法改用alpha/sigma的DFS，同样穷尽594个根像，得到相同的唯一恒等映射。

保持方向且保持外面的核心自同构群是平凡群。故4776个保留轴方案无法用这种自同构去重。反射、整体轴标签旋转及坐标旋转的额外等价没有在这里处理，不宣称完全无对称约减。

先前verify/n100_axis_automorphism_orbits.py读取阶段38的5280项，其结果为1自同构、5280轨道；它不是阶段39的4776项商化证书。正式结论以本阶段双算法证书为准。
