## 代码导出的独立复杂度模型

令n为圆盘数、k为见证目标数、E为候选服务边数，C(B)表示与实际中间有理位长有关的基础算术成本。输入最大分子/分母位长有记录，但中间表达式可能增长，不能把输入B当全程上界。

- 自动Hall：目标/两两分离O(k²)、构边O(nk)有理工作；增广路径实现最坏O(kE)组合工作，密图n=k时O(k³)。发现亏损后只核验给定子集可以更便宜；本批测量完整适配器而非纯证书叶。
- 小池容量：当前代码枚举2^k模式并检查最多O(k³)对/三元条件，再为n个圆盘筛可达模式；朴素上界O(2^k k³+n2^k+nk)，另加独立重放。
- 盒模式：每圆盘均值/方差O(k2^k)，坏子集和最大模式朴素双比较可到O(4^k)；并集DP和支配比较也可能到O(n4^k)。其实际反链往往小，不据此取消指数最坏情形。
- 带权容量：预处理O(k³)，每圆盘可达子集枚举2^a、a<=k，配对/三元禁集比较；宽松上界O(k³+n2^k k³)。零权重减少有效目标可望节省，但须证明预处理不改变缺额，不能直接删有几何作用的点。
- 计数/耳：已核验保存切面后，T个标签筛选近似O(T)加排序/去重；357个标量精确超越/区间核验属于准备成本。半径断点数、精度和级数项数另计。
- 弧/透镜/轮廓：J径向段、S条带、T目标、D固定类型，核验积分包络按实际JS及TD布局计数；热固定计数支持O(1)，轮廓约O(TD)。参数优化和支持发现另计。
- 连续：S扫描、C约束，固定维原语约O(S*C*C(B))；传播轮次与枝树节点数依赖数据。若每节点C相近，完整树重放约O(N*S*C*C(B))，但寻找足够小树不是线性成本结论。
- Cramer/预条件：每个三站点常数维有理区间算术；所有者数d时需最多choose(d,3)组；角点诊断固定64个角。奇异范围跳过，不能推断无解。
- 有限循环/nogood：跟踪实际可达状态数R及转移数，状态DP不保证多项式；独立nogood分支oracle最坏含各条子句长度之积。标记数、域宽和冲突数必须独立记录。
- 地图/精确代数：单地图编译按顶点/边/面和输出多项式项数核算；a项平方朴素a²乘积，稀疏多项式相乘按项数乘积合并；有理位长重要。枚举全部地图/发现SOS不包含在证书核验模型中。

这些是操作模型，不是已经实测拟合的全部增长律。首批只有Hall做规模梯度；其余固定证书只提供实际规模常数，下一批扩展指数池、位长、传播和组合工作负载。

## Hall留出规模检查

构造相同单位盘目标线段、全可达圆心盒，目标/圆盘数同为4、8、16、32、64。所有点对严格分离，输出均NOT_EXCLUDED。训练规模为4/8/16/32；64保留作检查。

以32规模的block范围锚定二次几何到三次增广工作，并仅在上端乘输入位长比平方的工程惩罚，预测64规模约28.8356至84.7543ms。实际中位数28.9142ms在内；相对纯二次中位锚预测之比0.92887。此区间很宽，只是保守工程预测，不是数学墙钟上界、置信区间或任意Hall池的通用规律。

证书另给出每项相同输入1000次串行热调用预测；那只是重复工作负载的线性累计，不含新进程、I/O、上下文冷建或几何难度变化。不得拿来预测完整n100搜索时长。
