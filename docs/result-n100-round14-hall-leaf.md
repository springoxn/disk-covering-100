# 第14轮：分离见证 Hall 叶与普适下界范围审查

## 实际进展

[Hall叶检查器](../verify/n100_separated_witness_hall.py)实际退出0，[精确回执](../verify/out/n100-separated-witness-hall.json)包含一个百盘宽盒：前99个圆心各坐标在[−1/2,1/2]，第100个在[−1,1]²，t≤U²，U=1154469548855829/10^16。见证点为(−1,0)、(1,0)。

对前99个圆心，每个点到圆心矩形的平方距离至少1/4>U²；每点可服务集合均为{99}。两个点距离平方为4>4U²，不能由同一个闭圆盘覆盖。任何覆盖都需把两点指派到两个不同圆心，但可能圆心并集只有1个，Hall缺额1，整盒排除。

这比单点叶严格更强：每点单独都有可服务圆心，所以逐点全不可达判据不能排除此盒。证明只用三角不等式与注入指派，无对称性/一般位置/接触图假设，重合圆心仍被包含。

五项负控制全部拒绝：新增第二个可服务圆心、闭端点允许同盘、盘外见证、重复见证、聚类盒内距离裕量失效。

[混合树v2](../verify/n100_hybrid_hall_tree.py)实际退出0，[树回执](../verify/out/n100-hybrid-hall-tree.json)验证两片继承子盒均可由Hall叶排除，且之前身份/旋转重标号LOCAL例子兼容。漏Hall子叶、重复见证、受限根升级全域三项控制被拒绝。旧脚本和历史回执未改写。

独立的通用Hall/混合树实现尚未完成。回执中的独立例子几何界为直接有理不等式交叉检查，不冒称通用独立实现。

## 既有11323/100000下界范围

读取[原始重放回执](../verify/out/external-disk100-bounds-67ebf1c.json)与[审计生成器](../runtime/audit-external-disk100-lower/build_audit_json.py)，确认既有端点下界包含n99面积排除，n99至所有m≤99的推论使用面积上界对有效中心数的严格单调性；已有CAS审计做过此恒等式。

该证据针对固定半径11323/100000，并依赖全配置同半径规范化后建立的新图、单弧及Jensen几何归约。退化通过解析归约/闭域极限处理，未形式化。不能把此端点的m<100排除迁移到候选U；U附近仍有m=96..99必要计数分支存活。本轮仅核读范围，未重跑约389秒的完整上游证书，不声称新鲜完整重放。

## 全局边界与下一步

本轮两份新检查均是受限百盘域排除，不是完整全域树，也没有新的普适下界。当前区间不变，真实极小多项式未取得。

下一步应设计多见证服务容量界：分離团Hall仍受见证间距限制，可利用每个圆心矩形内允许同时服务的见证子集，以精确最小包围圆或非负对偶权重证明整个盒容量不足。这将连接早期有限见证校准，但必须面向当前半径重新构造并核验，不能复用较大半径的toy结果为百盘结论。
