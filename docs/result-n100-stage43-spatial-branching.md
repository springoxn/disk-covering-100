# n=100 阶段43：完整有限空间分支树

## 范围

本阶段把阶段42的固定点坐标盒接入空间二分，实际处理两个保留轴方案：[0,6,12,18]及真实候选[30,6,14,22]。所有变量和约束仍限于单位盘、四轴图距离上界、相邻内面圆心距离<=2U；尚无共享顶点变量。

## 覆盖语义

每个节点先对输入盒作至多16轮保守传播。空盒为排除叶；到深度6而非空为未决叶。其他节点选择轴0拥有面及其邻面的一个坐标区间[lo,hi]，以整数mid=(lo+hi)//2拆成闭区间[lo,mid]和[mid,hi]，其余坐标不变。

两子域并集恰为父域，共享中点允许。传播后的盒包含该节点全部可行点，因此只需覆盖传播后父盒即可。一个根域仅在整棵树没有未决叶时才报告排除；任何未决叶保留根域，绝不把局部裁剪等同于全域排除。

节点记录传播前父子重建信息、传播后的全部100圆心盒、迭代轮数、收缩次数和（若出现）失败约束。树不省略子节点，不使用搜索启发式结论代替证据。
