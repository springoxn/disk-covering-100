# 阶段1验收后的 n100 小规模试验建议（未执行）

本建议依 [阶段1计划](../runtime/goal-plan-n100-stage1.md)，不构成已启动搜索或服务器重算。先验收输入、连续覆盖、普适下界、统一复现与独立检查，再决定进入哪一个阶段；一次只推进一个阶段。

## 阶段2：结构搜索试跑

只在本地启动可控预算的发现试跑。第一轮上限为两类初值、各3个确定种子；总覆盖目标函数求值不超过6000次，或本地累计30分钟，先到者停止。六角内部加自由边界层、多环初值解除对称限制；不因对称性排除自由构型。每次记录实际计时、完整100中心、随机种子、深洞、邻接图、停止原因与代码哈希。

至少先用一个小实例检查目标函数不吞异常；Delaunay只发现，边界最大值需完整处理。每个入选候选交给阶段1的严格覆盖验证器，使用相同有理半径或向安全方向的有理半径比较。任何候选无完整连续认证时不能报告上界改善。

停止条件：达到预算；出现目标函数/输入异常；全部入选结果重复同一接触图且无认证上界改善。停止后不追加同类随机重启，报告证据和可选的新结构变化。若有结构不同的可认证候选，即使无改善，也可作为候选池产物；不据此声称局部或全局最优。

## 阶段4：有限见证点下界试跑

先在小n校准，不立即处理100盘。建议n=8、9、10各选一个严格低于已证最优值的有理阈值，每例先选不超过32个精确有理见证点；点须用精确平方范数断言落在单位盘内。模式枚举必须包括闭盘的二维、一维和零维模式，或给出包含全部真实模式的安全过近似，不能仅以中心网格替代。

首轮只做一个n的几何完整性与证书端到端试跑，预算：本地30分钟、最多100000个模式/枚举事件，先到者停止。到阈值时保存完整输入、已处理事件及未处理账本，不把中断枚举称完整。

有理对偶下界或SAT证明需独立检查，求解器状态码不算证书。对偶下界未超过盘数或组合模式可行时，结论为方法尚弱，不推出连续覆盖存在。只有小n几何模式完整性与组合不可行性两层都获证后，才拟定n100自适应见证点预算。

## 顺序选择

若阶段1仍存在输入或上界证书问题，暂停后续试验并补证。若仅历史加强下界未闭合、但保底基线已验收，优先选择能独立验证的阶段4小n校准；若已有可信连续覆盖评估器且结构诊断清晰，可先做阶段2试跑。两者均需在新阶段明确资源预算和验收，不自动启动服务器任务。

这里的预算是下一阶段试跑上限建议，并非达到结果的承诺。实际计算规模和费用必须在试跑后记录；服务器数据重算须另有明确授权。
