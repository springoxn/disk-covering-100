# 阶段88：反向参数上界DP独立核对有限支持

入口：`python verify/n100_arc_reverse_support_audit.py`，实际退出0。证书：`verify/out/n100-arc-reverse-support-audit.json`。

## 为什么增加这一检查

阶段83—87的有限支持均使用同一正向参数下界状态DP，几何主/替代算术或集合删标重放并不能独立验证这个DP。本轮另写反向圆周遍历及显式集合/图递推，不调用正向state_dp、make_marks或其闭环求解过程。

## 独立状态与递推

反转顶点顺序，并旋转到象限切换后作锚。标签j对应参数闭区间[j,j+1]（整体比例256省略）。逆向参数必须不增，维护此前上端的最小值U，当前标签必须满足U>=j；转移到标签k时，同象限更新U=min(U,k+1)，跨象限重置U=k+1。这与正向算法维护下端最大值M、检查M<=j+1的状态不同。

把继承二元关系展开为显式有序对集合。禁配满足位单独根据区间之外的标签计算。每个锚前向构造可达状态及显式状态图，末端检查闭环边及全部12条禁配已满足，再沿图反向提取可完成路径的状态。最后合并全部锚的支持。闭弧端点相等保留，不强加严格次序。

## 验证结果

12组四顶点小模型，每组穷举81个标签赋值，包含0至4条混合区间禁配、二元关系和象限分组，反向DP的全部支持位集合与独立穷举一致。

真实域选取阶段84 child1父域，以及阶段87支持最少和最多的两个空间叶。全部支持逐顶点逐位比较一致：

| 案例 | 支持标签 | 反向单层最多状态 | 与正向证书相同 |
|---|---:|---:|---|
| child1父域 | 1588 | 4928 | 是 |
| 空间树node30 | 1079 | 2884 | 是 |
| 空间树node39 | 1297 | 3388 | 是 |

本轮未核对剩余30个空间叶，不能写成32叶全量独立DP复核。证书保存三个域全部支持、逆序顶点序、锚见证及输入绑定。

## 独立范围

这是独立的有限关系求支持实现，使用相同继承二元表、几何mask、12条禁配和topology setup。因此它加强了闭环/次序/禁配求解的实现可信度，但没有独立证明关系表是全部覆盖的必要条件，也没有独立复核所有连续几何承包器或全局地图枚举。
