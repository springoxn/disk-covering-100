# n=100 阶段25：面积帽筛选与自动容量剪枝

本阶段目标是把边界下界与 Hall 排除变成可应用的接口。**没有提高普适半径下界，没有排除87组必要计数族，没有证明全局最优性或取得最优半径极小多项式。**

## 1. 现行下界来源

现行区间仍采用固定外部提交67ebf1c的历史本地重放：
`11323/100000 < r_D(100) <= 1154469548855829/10^16`。
事实源：`verify/out/external-disk100-bounds-67ebf1c.json`，历史实际退出码0，六个分支PASS。本阶段核读其来源、解析证明和独立审查，不声称重新执行约389秒的完整重放。

其下界不是简单长弦公式：包括全覆盖同半径norm-cap归约、同图有效中心/边界数分类、核心曲率、星形面积/周长、铰链亏损及capped-pair尾部。`docs/audit-external-disk100-lower.md`明确区分精确算术复核与未形式化的几何依赖；浮点仅用于支持点发现，不参与接受的不等式判定。

## 2. 面积帽前沿

入口：`python verify/n100_cap_frontier_screen.py`。本阶段实际退出0，证书为`verify/out/n100-cap-frontier-screen.json`。

在固定上端U，对服务圆周的盘有圆心模至少1-U。令内目标半径s=1-2U+delta，每个服务盘在内目标中的面积不超过 `(4/3)*sqrt(2U*delta^3)`。面积次可加性给出必要条件

`pi*s^2 <= (m-k)*pi*U^2 + k*(4/3)*sqrt(2U*delta^3)`。

取delta=41/5000，整数sqrt向上舍入和Machin有理pi包围给出严格正缺口，排除m<=100、k>=56。每增加一个服务盘的缺口增量为正，故无需枚举k=56..100。低半径构型可先扩大到U再分类，得到同端点的必要条件。

把87个(m,B)族暂以k=B代入，在分母10000的delta网格上均无正缺口。这不是连续参数全域否证；也没有因此接受k=B的几何桥接。此结果提示现有简单面积帽不足以缩小87族，下一步必须增加弧长/互斥/三点覆盖资源约束。

## 3. 自动 Hall 提取

入口：`python verify/n100_hall_automatic_search.py`。实际退出0，证书`verify/out/n100-hall-automatic-search.json`。

给定两两距离严格大于2U的有理见证池，通过有理点到中心盒距离建立二部图。增广路失败时，交替可达顶点给出Hall缺额子集；输出用既有Hall叶检查器重验，并以独立clamp距离实现复核。

8个固定圆周有理点在可用外围中心数为1、3、7的受限百盘盒中产生排除；8个可用外围中心与全中心域控制不被排除。重复点、盘外点和破坏后的见证被拒绝。搜索对给定分离池完备，不对所有可能几何见证完备。

## 4. 非分离三点容量剪枝

入口：`python verify/n100_nonseparated_capacity_cut.py`。实际退出0，证书`verify/out/n100-nonseparated-capacity-cut.json`。

对至多12点的小池，枚举全部点子集。两点用直径判据；三点若非锐角则取最长边直径，否则比较

`a*b*c <= 4*cross^2*t`，

其中a,b,c为三条边的长度平方，t为半径平方。平面Helly将所有三点可覆盖性连接到整个子集可覆盖性。中心盒先筛掉不能到达的点，每盘容量取其可达集合中几何可行子集的最大基数。当容量总和小于见证数时，覆盖不可能。

校准见证为(13/20,0)、(17/20,0)、(3/4,19/100)。在U处每一对都可由一盘覆盖，但三点整体不可由一盘覆盖。99个中心限定在[-1/2,1/2]^2、一个中心位于全盒时，总容量为2，产生缺额1。原先要求两两分离的Hall方法不能使用该三点组。独立实现采用Gram行列式重算全部子集和容量；虚假三点可行性、低报容量两项损坏被拒绝。两个可用外围中心、全中心域以及闭半径端点控制均符合预期。

解析Helly/MEC依赖尚未形式化。容量上界忽略多个点的共同可行圆心是否落在盒内，因而可偏松，但不会因该放松误排除。

## 5. 混合树接入与真实候选控制

入口：`python verify/n100_hybrid_capacity_tree.py`。实际退出0，证书`verify/out/n100-hybrid-capacity-tree.json`。

v3支持WITNESS_CAPACITY叶，保留旧v2叶接口。每个叶严格使用SPLIT继承的中心盒，主/独立容量检查必须通过。两片继承子盒均排除；局部升级全局、遗漏子节点、额外可用中心三项控制均拒绝。

真实候选的有理中点来自`runtime/external-disk100-strict-local-replay/source/rational_midpoint.json`。半宽1/1000、1/100、1/10的三个中心盒，在U处均没有被本三点池误排除。此控制不重新认证候选根或覆盖。

## 6. 下一阶段与复现纪律

下一步将自动Hall和非分离容量叶应用于有明确来源的几何分支，而非继续构造校准玩具盒。需要实现分支生成、见证发现和计数/地图/连续中心域之间的合法范围桥接；完整地图枚举、退化与候选邻域外排除仍未完成。

以上入口默认拒绝覆盖既有输出。重新执行时应先保留现有证书，以新路径或新运行目录重放，不能删除历史证据。每份证书绑定脚本SHA256；算术接受只用整数/Fraction。`machine_verified_geometry=false`保留。
