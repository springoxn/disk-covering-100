# 阶段125：同图连续盒收缩接口

[运行接口](../verify/n100_continuous_proof_interfaces.py)与[测试入口](../verify/n100_continuous_proof_interface_contracts.py)已写入。测试实际退出0，[当前证书](../verify/out/n100-continuous-proof-interface-contracts.json)记录31个真实有理点保留、闭边界控制、8项负控制和一个实际固定核候选重放。

## 类型与证明范围

坐标使用整数端点包围的闭实区间，统一缩放Q=2^20。它们不是整数格点变量；内部可以包含任意实数/有理数。context必须绑定map_id、frame_id、parent_box_id、radius_domain_id及缩放语义。

五种原语：distance_le、circle_eq、bisector_eq、nearest_le、norm_range。每个原语处理声明的数学关系，保留其中所有真实解。任意用户方程不会自动成为覆盖的必要条件；结果covering_exclusion_authorized_without_bridge始终false，实际覆盖排除还需同图几何桥接。

compile_fixed_core读取已绑定固定核和父中心盒，按已存在的地图/边界象限/所有者关系生成原语。其几何必要性继承旧归约，明确限制一个固定核；不声明完整地图枚举。

## 运行与独立范围

每一步同时运行主/替代算法并比较输出：距离使用单独clip实现；等距使用新写的Fraction端点除法重建；范数使用角点最大值和钳位最小值；圆周使用替代平方根上取整公式；最近点使用Fraction除法替代分支。后两者共享公式和部分代码，不称为完整独立几何验证。

每步验证新盒包含于旧盒。空盒才返回EXCLUDED；无变化的不动点返回NOT_EXCLUDED；轮数上限前仍有收缩返回UNDECIDED。后两者都不是可行性结论。

输出保留完整proof_input、失败原语、传播轨迹和上下文。组合时重新运行并比对完整记录，只允许同图、同父输入盒、同坐标帧和半径域。不同必要收缩可求盒交；交为空才排除。没有累计任何面积或弧长亏损。

## 实测验证边界

- 距离平方25的3-4-5闭相切保留，24严格排除。
- 六个有理单位圆点、25个有理等距点保留，共31个。这直接检查真实非整数点不会被整数端点舍入丢失。
- 最近点和范数范围各有严格排除控制。
- 一轮收缩上限返回UNDECIDED，独立必要收缩求交保持x=0分支。
- 错误地图、缩放、半径域缺失、浮点坐标、变量越界、零轮数预算、异坐标帧拼接、伪造排除标签，共8项拒绝。
- 实际候选放置[30,6,14,22]从固定核编译20,924条条件，包括全部非所有者最近点关系；一轮主/替代传播均通过，候选未排除。只重放该候选一例，不是4200个遗留放置的全面新重放。

## 方法族关系与剩余变体

本批提供距离/圆周/等距/最近点/范数的共同原语，旧的圆心交替、单点前瞻、有限次传播及空间分支可以复用这些原语和同父域契约。它不声称逐个历史驱动已移植。

联合Cramer、固定预条件器、行列式角点界属于同一必要等距/最近点系统上的更强收缩或代数重写，还需各自变换证书；它们不能仅凭本批五原语已实现而标成已重放。若分母区间跨0，应保留为未决或换预条件器，不能将不能除法当作不可行。

## 后续成本研究输入

若有V个二维盒、C条条件、S次传播，一般驱动上界O(S*C)次固定规模有理/整数区间运算，加每步更新和可能的证书记录成本。最近点条件构建约O(V*n)，同一顶点所有者两两等距可能O(sum deg(v)^2)。实际含大量不变约束的稠密扫描，不等于事件队列优化复杂度。

本接口每步双实现，组合又重新运行整条轨迹；生成、算术独立核对、结果重放的成本后续分开校准。父盒/图编译和哈希I/O也必须单列。这里未给绝对时间预测。
