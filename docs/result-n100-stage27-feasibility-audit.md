# n=100 阶段27：未决盒可行性审计

本阶段没有提高下界或改变最优性结论，但确定了阶段26剩余盒的正确处理方式。

## 实证结果

入口：`python verify/n100_stage27_feasibility_audit.py`，实际退出0；证书：`verify/out/n100-stage27-feasibility-audit.json`。

输入是阶段26的32个候选来源中心盒、真实候选KKT有理中点和多规模扩展孔池。对每个8/16/24/32孔池，16个未排除盒都具有显式的盒内中心配置，能够覆盖该有限见证池；独立检查器重新计算所有盒内坐标、分配和半径余量。没有把有限见证覆盖误称为单位圆盘连续覆盖。

同时重新调用固定提交67ebf1c的严格上界检查器：

- 整数/有理精确覆盖重放退出0；
- 重新确认100个中心覆盖整个闭单位圆盘；
- 严格上界仍为 `1154469548855829/10^16`；
- 32个父盒中有8个实际包含这份已认证连续覆盖配置，索引为 `[3,7,11,15,19,23,27,31]`。

因此，试图用更多相同来源的孔见证排除全部32个父盒在逻辑上是不可能的；至少这8个盒包含真正的可行覆盖配置。阶段26的16/16统计只能理解为“见证池未排除/已排除”，不能理解为候选配置的可行性分类。

## 方法意义

这一步排除了一个错误方向：继续增加同一类候选孔见证，并不能解决全局问题。剩余可行分支必须保留，研究重点应转向：

1. 以完整覆盖配置的临界点结构为输入，构造低于现行上界的全局下界；
2. 在不同组合地图或不同活跃接触图上寻找新的候选，而不是排除当前上界配置的盒；
3. 只对确实不包含可行覆盖的中心域使用容量剪枝。

## 范围

本阶段没有排除新的 `(m,B)` 计数族，没有证明全局最优性，没有取得极小多项式。见证点仍是有理中点，中心盒只是有限来源域，`machine_verified_geometry=false` 的边界保持不变。
