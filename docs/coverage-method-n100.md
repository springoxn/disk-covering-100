# n=100 连续覆盖证书的充分性与重放

规范输入为 [历史100中心](../runtime/freecover_n100.json) 的 `/best/P`，每个JSON十进制字面量按精确有理数解释；其有序规范副本见 [精确中心](../runtime/candidates-n100/centers_n100.json)。不存在重新取最近100格点的步骤，也不把十进制坐标等同于理想代数格点。

本证书要证明的是这100个半径 `R=153/1250` 的闭圆盘覆盖整个单位闭圆盘。它不证明历史发现半径为精确覆盖半径，不证明局部或全局最优。

## 盒分割的充分性

根盒为 `[-1,1]²`，包含单位闭圆盘D。每个节点四分成四个闭盒，路径数字0、1、2、3分别以最低位选择x上半、最高位选择y上半。深度d的节点有S=2^d，其坐标区间为 `[-1+2ix/S,-1+2(ix+1)/S]`，y同理。

外域叶：逐轴计算盒内平方坐标的最小值，若最小平方范数严格大于1，则该闭盒与D不相交。严格大于保留了单位圆上的等号点。

覆盖叶：盒中心m到盒内任一点的距离不超过两个半边长之和 `h=2/S`。若对某个实际中心c，有 `R-h≥0` 且 `|m-c|²≤(R-h)²`，则由三角不等式整个闭盒位于该中心的半径R闭盘中。中心及m均为有理数，乘公共分母后两侧比较只用整数。中心可以在D外。

完整性：路径无重复、前缀互不包含，保证叶盒内部互不重叠。有限叶的整数Kraft恒等式 `Σ4^(dmax-d)=4^dmax` 保证总面积等于根盒面积4。若有限闭盒并集遗漏根盒中的一点，其闭性使遗漏部分在根盒内含一个非空相对开邻域；根盒内这种邻域具有正面积，矛盾。因此叶覆盖整个根盒。

对任何x∈D，完整性保证它在某叶内；外域叶与D不相交，所以x必在至少一个覆盖叶内，再由该叶的判据落在对应闭圆盘内。因此认证的是整个连续闭圆盘，包含边界，不是采样网格。重合、共圆、共线、相切以及单中心边界极值不需要Voronoi分类，均由同一完整域论证涵盖。

深度上限处若仍有未决盒，记录未决并判失败，不能删去这些盒来宣称通过。

## 独立重放

[生成与账本检查器](../verify/coverage_n100.py) 重算每个叶的整数充分判据与完整性；[独立检查器](../verify/independent_coverage_n100.py) 不导入生成器，改用整个盒的最大角点平方距离。平方距离在矩形上的最大值为每轴端点平方距离最大值之和，因此全部角点检查足以认证整个盒。

独立检查器共享历史输入、叶账本、路径数字约定，不共享生成器的几何helper。两者都从源字节SHA256与规范中心SHA256核对输入；独立检查还核对生成器代码SHA256。数学正确性不依赖证书自报的 `all_passed` 标志。

负对照包括删除叶、半径修改、错误中心、输入或代码哈希篡改。生成器对某些篡改重新计算负载哈希后仍须由数学检查拒绝；独立检查器不依赖该负载哈希拒绝漏叶或错误半径。

统一复现命令为 `python verify/run_n100.py`。实际叶数、运行结果及退出码以 [汇总证书](../verify/out/baseline_n100.json) 为准；单个覆盖账本见 [覆盖证书](../verify/out/coverage_n100.json)，独立复核见 [独立证书](../verify/out/independent_coverage_n100.json)。
