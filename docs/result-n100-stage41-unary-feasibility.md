# n=100 阶段41：全部逐面四轴松弛的有理可行证书

## 结论

阶段39保留的4776个轴插入方案，每个方案100个内面，共477600个面—方案组合，其下述逐面松弛全部有精确有理可行点：

`|c_f|²<=1`，以及四条 `|c_f-a_i|² <= (2*d_i+1)² U²`。

其中a_i是固定四轴，d_i是在排除外面后的内面对偶图上，从f到a_i所属面的最短距离。全部组合只有4365种不同距离向量；每种均找到分母64的点，没有未决项。

这不是完整覆盖模型的可行性证书。不同面圆心之间的距离、共同顶点、圆周顶点坐标和覆盖约束都被省略。当前只证明这些逐面集合的笛卡尔积非空，不证明其点可扩展为共同几何配置。

## 执行证据

- `python verify/n100_axis_unary_feasibility.py`：实际退出0；证书verify/out/n100-axis-unary-feasibility.json。
- `python verify/n100_axis_unary_independent.py`：实际退出0；证书verify/out/n100-axis-unary-independent.json。

主算法通过BFS收集距离向量，在有理格点上搜索。对固定整数分母Q及x，四条盘约束都转为y的整数区间，使用向下取整整数平方根求交，同时施加单位盘约束。找不到格点只记未决，绝不作排除；实际全部在Q=64找到。

独立检查器不导入搜索函数，使用独立面循环与Floyd距离重新计算4365向量及477600出现次数。逐点直接整数交叉相乘检查五条平方距离约束，再比对全部向量和次数。缺失向量、盘外点、错误次数、错误半径四项负控制均拒绝。证书中的最小轴约束整数余量严格为正。

所有接受比较均用整数。图距离到几何距离的三角不等式归约仍为解析依赖，machine_verified_geometry=false。

## 对后续路线的实际约束

阶段40只证明所选固定权重没有排除；本轮更强：对于这里明确列出的五个逐面盘约束，已经直接给出可行点，因此任何合法的分离权重都不可能证明这些交集为空。继续只调整这些约束的方差权重，无法新增排除。

若要进一步收缩，必须增加未包含的约束，例如相邻面圆心必须相距不超过2U、共享顶点必须同时被相邻盘覆盖，或使用更紧轴距离推导。加入耦合约束后的可行性不由本轮保证，也未在本轮判定。
