# 第24轮：小规模地图完整枚举轨道校准

[枚举校准脚本](../verify/n100_small_map_enumeration_calibration.py)实际退出0，[回执](../verify/out/n100-small-map-enumeration-calibration.json)记录全部结果。

参数固定V=4,E=5,m=2,B=4，四个边界顶点依次为四轴标记。α固定为五条边的配对d↔d xor1。通过边重标号可令四边外面循环固定为(1,7,5,3)，其余六半边的φ图像遍历全部6!=720种排列。过滤要求三个面循环、四个顶点循环、无环边、全部面顶点简单且至少二边形、四轴顶点不同；连通性由编码遍历检查。由置换地图的Euler关系V−E+F=2，候选为定向球面地图。四边外面删去后是组合圆盘。边数、面数都很小，不推广此穷举成本至百盘。

实际接受12个标记置换，去重为6个保持定向和有序轴标记的轨道。

独立构造路线：从四边形的任意两个不同顶点插入唯一内弦，总共C(4,2)=6条；显式构造其两个内面φ循环及顶点标记，不通过主筛选器。两路线的全部规范轨道集合完全相同。其中4条相邻顶点弦产生二边形，2条对角弦产生两个三角形。删除一个轨道的负控制导致集合不等。

小规模独立性范围：地图生成路径分别是全部置换过滤和几何多边形弦构造；规范比对共享一个独立于上一轮面步进代码的顶点旋转规范器。因此没有两套完全独立同构判定实现，也没有跨规范器证明本轮轨道与上一轮602半边规范码一致。只能称该参数族的完整枚举校准。

需要继续：对更广V,E,m,B和四轴选择开发合法性审查、规范轨道比对和任意地图的二次模型编译。n100所需全部计数族仍未枚举，候选邻域外域仍未排除，退化完备性归约仍有解析依赖。

严格区间保持11323/100000<r_D(100)≤1154469548855829/10^16。真实最优半径和其本原不可约极小多项式未取得。
