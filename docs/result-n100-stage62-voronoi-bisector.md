# 阶段62：Voronoi等距顶点收缩实验

命令：`python verify/n100_voronoi_bisector_vertex.py`。实际退出0。证书：`verify/out/n100-voronoi-bisector-vertex.json`。

## 新加入的必要条件

核心解释为裁剪Voronoi地图时，同一顶点v的两个incident内面心a、b满足

`|v-a|²-|v-b|² = 2v·(b-a)+|a|²-|b|² = 0`。

全部变量同乘Q，因此等式保持整数齐次形式。对每个顶点的每对incident面建立等式，每案530条（这是顶点—面心对关联数，区别于265个去重后的圆心邻接对）。这不是阶段60审计过的距离<=2U约束重复。

以区间算术外包系数和常数项，首先检查残差区间是否包含0，再对系数区间不含0的顶点坐标做区间除法和向外取整收缩。系数含0时跳过除法而保留父盒。当前只收缩顶点坐标，不反向收缩圆心。

## 测试和结果

输入为阶段61完整32案的交替传播固定点盒，以及阶段60真实候选[30,6,14,22]的固定点盒。33案均fixed、0 excluded、0 capped、0额外盒宽缩减。没有新增严格排除，原固定核心仍576排除、4200保留。

25个有理点控制检查等距点不会丢失；另检查一个严格不等距盒被拒绝、重合圆心时盒保持。每次实际发生的区间除法用Fraction端点商独立比较整数floor/ceil。这些是承包器算术控制，不等价于独立重放整个传播。未完成独立端到端验证。

## 限制和下一步

等距条件的必要性依赖将核心实现解释为Voronoi地图的解析归约；它对任意覆盖地图未必成立，不能无条件推广。自然区间外包将重复出现的圆心变量视为独立，当前圆心盒较宽，试验无收缩；33案结果不能推出其他方案上也无用。
