## 平移联立求解

对至少三个所属圆心的Voronoi顶点v，选择所属圆心a,b,c。取顶点盒整数中点o并设置x=v-o，则两条方程为

`2(b-a)·x = |b-o|²-|a-o|²`

`2(c-a)·x = |c-o|²-|a-o|²`。

以整数区间计算系数、右端、行列式和Cramer分子。仅行列式区间不含零时作除法，商端点向外取整。整数交叉除法与Fraction端点计算逐次一致。包含零则安全跳过，绝不把除法失败当作不可行。

147个有理外心保留控制（包含半整数点）、共线跳过控制和严格拒绝控制通过。具体控制的三圆心等距性另以Fraction恒等式断言。

在阶段84两个子分支和阶段69真实候选父盒上，每案166组，均一轮固定、无收缩、无排除，与距离基线相同。每案普通行列式区间可除数为0；因此这一无收益结果主要来自全部跳过联立除法，不是证明联立约束已被充分利用。

## 精确盒行列式极值

另写角点枚举器诊断跳过原因。用未乘系数2的行列式

`det(b-a,c-a)`

逐组枚举六个独立中心坐标各取上下端，共64角点，计算最小最大值及相应角点。逐角点核对直接与展开多项式表达相等，精确角点范围包含于普通区间范围。

分析依赖：该行列式对六个标量坐标中的每一个分别仿射，所以独立坐标盒上的极值由角点取得；又因盒连通、行列式连续，若精确最小最大值夹住零，盒内确有行列式为零的点。这是关于独立盒的陈述，相关点可能违反其他共享顶点或距离约束。

| 输入 | 三元组 | 普通区间避开零 | 精确盒区间避开零 | 精确范围严格变窄 |
|---|---:|---:|---:|---:|
| child0 | 166 | 0 | 0 | 166 |
| child1 | 166 | 0 | 1 | 166 |
| 真实候选父盒 | 166 | 0 | 0 | 166 |

498组中497组即使精确求独立盒行列式范围仍夹零。这定位了当前矩形盒松弛的一个实际问题：多数相关圆心的联合几何信息不足以排除共线退化，仅替换除法端点算法无法使它们可除。

child1唯一避零的角点区间尚未回灌联立承包器。本轮仅证明该组可用更精确分母，未声称产生收缩。
