# 第9轮桥接的解析预算说明

固定中心C*与支撑孔p*取精确根值，不是有理中点。中心单坐标扰动≤ε，孔单坐标扰动≤η。内孔F的两行为等距差方程，边界孔第二行为|p|²−1。令J*=D_pF(p*,C*)。

坐标绝对值≤2，且ε,η<1。每条等距行F的中心扰动常数可直接展开：两中心差变化乘p*贡献≤16ε，两个中心范数平方变化贡献≤16ε+4ε²，总计≤32ε+4ε²≤64ε；边界第二行在p*固定时为0。

导数变化应对同一根的增量直接计算：等距行每个导数分量为2(Δc_b−Δc_a)，绝对值≤4ε，行和≤8ε；边界单位圆行分量为2Δp_k，行和≤4η。因此||D_pF(p,C)−J*||∞≤16ε+4η安全。

使用扩大盒Jacobian的全宽会重复计入独立根区间，不等价于上述增量比较；独立检查曾因此exit1。应检验增量公式的直接区间界，不能将全宽结果冒称必要收缩常数。

由已认证逆界||J*^-1||∞≤K=10^6，对闭完整度量球B∞(p*,η)，T(p)=p−J*^-1F(p,C)满足||DT||∞≤K(16ε+4η)≤1/2，并满足||T(p*)−p*||∞≤64Kε≤η/2。因此T是球内自映射收缩，有唯一固定点，给出支撑孔分支。内孔到单位圆有严格余量，边界孔第二方程使其仍在目标边界。

非支撑平方距离在根处间隙>64(η+ε)；扰动后平方距离变化≤64(η+ε)，故仍>t*。支撑集合中所有中心与持久孔等距，覆盖该孔只可能由该集合完成，因而全部支撑杆均满足≤t。这里不需要附近局部极大点库存完备性，只有支撑孔存在性与距离间隙必要。

该推导只处理固定规范、中心邻域半宽ε=10^-54。其他图、旋转规范定量覆盖、退化和全局最优性未完成。
