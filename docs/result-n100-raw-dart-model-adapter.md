# 原始半边置换到闭覆盖模型：端到端适配

[适配器](../verify/n100_raw_dart_model_adapter.py)实际执行退出0，[回执](../verify/out/n100-raw-dart-model-adapter.json)保存候选解码地图、720置换的接受列表、拒绝原因统计及哈希绑定。

输入为偶数个半边，固定α(d)=d xor1，面置换φ、指定外面半边及四个轴点起始半边。顶点按φ∘α的轨道重建，边保留每个配对的独立身份，内面按φ循环导出，外面循环反向给出圆盘正边界。检查置换合法性、无环边/桥、简单面、连通性、球面Euler关系，再由通用编译器核验轴次序、地图预算与关联，生成闭二次覆盖模型。

实际候选602半边经解码，规范码往返完全一致，输出仍为605变量、44等式、986不等式。解码会重新编号圆心与地图顶点，故这里比较规范地图及模型大小，不声称与原候选模型多项式按原编号逐项一致。

小规模不是只跑六个代表：全部720面置换均经过原筛选器及新解码/编译路径，接受列表完全相同，12个标记置换形成6轨道，全部合法实例均编译为13变量、12等式、34不等式。非置换、重复轴、错误轴次序三项控制全部拒绝。

独立性边界：适配器与原筛选器生成和检查路径不同，但使用现有通用编译器和规范器，仍无完全独立端到端实现。720枚举只涵盖V4,E5,m2,B4参数族。不能由候选往返推出百盘全部图枚举或退化完备全域排除。

当前接口链已可由原始合法dart地图产生完整闭约束。接下来关键问题是枚举规模和连续域求解；继续重复候选可行性检查不会产生新下界。真实全局最优性及其本原不可约极小多项式仍未取得，严格区间保持11323/100000<r_D(100)≤1154469548855829/10^16。
