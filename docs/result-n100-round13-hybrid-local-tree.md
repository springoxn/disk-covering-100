# n=100 第13轮：全域树与 LOCAL 叶的精确接入

本轮完成了把既有局部证书接入全域分割树的接口，但没有声称全域树已经构造。

## 已验证

[混合检查器](../verify/n100_hybrid_local_tree.py)实际退出0，[回执](../verify/out/n100-hybrid-local-tree-interface.json)记录：

- 从 `rational_midpoint.json` 出发，对100个圆心的根盒逐坐标计算单位盘范数余量；100/100严格在单位盘内，最小余量为有理正数（大于 `1/50`）。
- LOCAL 叶必须绑定当前 widened budget、独立审查回执、根中点和本地链总账；独立回执的 parent receipt 与预算哈希逐项核对。
- 49条局部证明链哈希被再次检查。
- 身份旋转/标号和有理四分之一转动加逆序标号两个例子通过。
- 全局升级、非正交旋转、重复标号、错误绑定、过宽中心盒、半径穿过根端点六项控制全部拒绝。

混合树严格继承父盒，分割节点只接受有理内部切分；因此它不会因调用方传入不一致子盒而产生假叶。LOCAL 叶只证明已绑定的候选根附近盒；它不能排除其他图或根邻域外配置。

## 数学边界

投影归约保证所有圆心可限制在单位盘内，允许重合和冗余盘，所以这一步没有加入对称性或一般位置假设。它只消除了域外圆心，尚未枚举所有接触拓扑或有效中心数。

当前仍缺少完整的 `D^100 × [0,T]` 有理分割树。已有见证树接口只证明严格次优固定端点存在有限树，不能直接处理最优等号。故本轮没有产生新的普适下界，也没有把候选半径升级为真实最优值。

当前严格区间保持
`11323/100000 < r_D(100) <= 1154469548855829/10^16`。

真实 `r_D(100)` 的极小多项式、不可约性和有理根隔离仍未取得。
