# 阶段135：补充圆心分布接口及旧规则的条件契约

[分布接口](../verify/n100_center_distribution_interfaces.py)新增环带圆心范数计数、平移目标盘计数以及显式锚点圆盘交的方差必要条件。[核验入口](../verify/n100_center_distribution_contracts.py)实际执行退出0，证据见[契约与计时证书](../verify/out/n100-center-distribution-interface-contracts.json)。

## 三条必要规则

环带a<=|x|<=b在单位盘内。半径不超过U的圆盘若能碰到环带，其圆心范数必在[max(0,a-U),b+U]。能碰到的圆盘数M必须满足M*U²>=b²-a²。实现用声明的闭范数区间计算可能数，闭端点接触保留。它不推导各圆心的范数区间，输入必须由上游圆心盒或精确位置认证。

平移目标盘B(q,s)满足|q|+s<=1。可能碰到它的圆心到q的距离不超过s+U；用矩形到q的精确最短距离保守计数。M*U²>=s²是必要条件。原方向脚本使用更强的递归最低覆盖数；新接口只有独立面积最低数，不能宣称与该旧脚本等强，更不能删除强前沿的独立前提。相切圆盘即使贡献面积为零也计作可能，从而宁松勿错。

对声明的圆盘约束|x-p_i|²<=t_i和非负有理权重w_i，W=sum(w_i)>0、均值mu=sum(w_i*p_i)/W，有恒等式sum(w_i|x-p_i|²)=sum(w_i|p_i-mu|²)+W|x-mu|²。方差严格大于sum(w_i*t_i)则无解；等号保留。图路径给出的t_i需另外绑定正确所有者和路径，接口只证明显式圆盘交为空，不能跳过几何提升。

## 核验和成本

环带与平移目标分别经独立区间分离/夹点公式复算。7项控制包括足够面积数只保留不称覆盖、闭相切保留、目标盘越界、浮点半径、零半径、反向圆心盒及锚点等号保留。三锚点方差身份经SymPy精确展开为零。7个不同进程各执行两任务、预热一次后测5次，共70次热调用精确结果对照通过。

n=100固定输入的环带热中位数0.5704ms、平移目标2.4996ms；相同输入1000次串行预测分别0.5704秒、2.4996秒。这些补充计时是固定次序的工程测量，未另做随机化/预注册设计，不作为因果比较。判定仍只用Fraction，墙钟浮点仅用于遥测。

操作复杂度为环带O(n)有理比较、平移目标O(n)有理距离、多锚点O(k)有理工作，另计JSON规范化/哈希和有理中间位长。本批未按位长拟合这些新内核，不能将先前小池位长规律直接套用。
