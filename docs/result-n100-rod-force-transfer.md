# n=100 有界单元：角方向 v 的杆力转移（rod-force transfer）

**范围**：本文只记录一个**有界局部单元**。不声称 r_D(100) 的全局最优性/全局界，**不是** H0 或任何 Gram 提升步骤的负性证明，也不构造任何新的覆盖。

## 问题

取上一轮固定有理角方向 `v`（32 维，来自[角能量负见证](../verify/out/n100-angular-energy-negative-witness.json)），在 32 个边界孔锚点（杆图节点 `214..245`，即 493 个基坐标中的 `428..491`）上放 Dirichlet 锚点速度

```
dz_i = (-q_{i,y}·v_i , +q_{i,x}·v_i)        i = 0..31
```

按已证明的杆权 `alpha_j`（乘子变量 `493 + j`）**谐延拓**到 214 个自由节点（节点 `0..213` = 100 圆心 + 114 内部孔）。问：406 条 active 杆约束

```
f_j(z) = |c_a - p_b|² - t          杆 j，圆心节点 a，孔节点 b
```

的一阶变化 `l'_e = d/ds |z_a - z_b|² = 2 (z_a - z_b)·(dz_a - dz_b)` 是否**同时**出现严格正值与严格负值。

**结论（有界）**：是。406 条中 **196 条严格正、210 条严格负、0 条未定**。

半径为 `r = sqrt(t)`；改进覆盖的一阶杆域可行性判据是**不等式**

```
l'_e <= t' < 0        对每一条 active 杆
```

（只有在新半径下仍保持 active 的 KKT 行才需要取等号，其余行允许有松弛）。既然两个符号都出现，`+v` 与 `-v` 都**不满足**该判据：**这一个**谐延拓不是可行的一阶改进方向，也不在 406 条杆约束的 ker B 中。

**这不排除**：(i) 同样的锚点数据 `v` 下的其他自由节点速度场（非谐延拓）；(ii) 非线性/有限步分支；(iii) 其他方向。

## 精确误差预算

谐延拓方程 `L_FF dz_F + L_FA dz_A = 0`，即 `dz_F = -(Xi/SCALE) dz_A`，其中 `Chat = D·L_FF`、`Bmp[f,a] = (D·L_FA)[a,f] = -A_j` 都是精确整数矩阵（`D = 10^60`，`A_j` = 乘子变量 `493+j` 的分子）。

- 精确整数残差 `Et = SCALE·Bmp − Chat·Xi`：`max|Et| = 1.2132362009487652×10^58`（59 位十进制、193 bit），`‖Et‖₂ ≤ 1.0069860467874751×10^60`（61 位十进制）。
- 候选舍入误差（`M ≈ 2.647016774241472×10^8`，取自 `result.json` 的 `invariants.lambda_min_LFF_lower_bound`，`lambda_min(L_FF) ≥ 1/M`）：`e_round = M·‖Et‖₂/(D·SCALE) ≈ 7.833226803353173×10^-31`。
- 根箱 `±1e-58` 的杆权扰动：`delta_L = 2·246·maxdeg·rho`，`e_weights = M_eff·delta_L·(1+‖X_mid‖₂) ≈ 5.187128162916683×10^-46`（`M_eff = M/(1−M·delta_L)`）。
- 锚点速度的根箱误差：锚点 `i` 的两个分量各带 `|v_i|·rho`，故每个锚点 2-范数 `≤ sqrt(2)·|v_i|·rho`；保守取因子 2，即 `‖delta_A‖₂ ≤ 2·rho·‖v‖₂`；单分量最大误差 `3.07727405098×10^-59`（`|v|_max = 153863702549/(5×10^11)`）。
- 自由节点速度误差 2-范数 `epsF ≈ 7.833226803352266×10^-31`。
- 每条杆区间半宽 = `2·Σ_d [ |Δz_d|·e_Dd_d + |Δd_d|·2rho + 2rho·e_Dd_d ]`，实际范围 `1.82×10^-31 … 5.12×10^-31`。

最强的两个违例（裕量约 28 个数量级）：

| 符号 | 约束 j | 乘子变量 493+j | 圆心节点 | 孔节点 | 一阶变化 `l'_e` | 区间半宽 |
|---|---|---|---|---|---|---|
| 严格正 | 343（边界对 k=0,l=1） | 836 | 77 | 214（锚点） | `+7.173722259640727×10^-3` | `2.5572146349113173×10^-31` |
| 严格负 | 378（边界对 k=12,l=0） | 871 | 57 | 226（锚点） | `-4.893856249827113×10^-3` | `1.821329741733002×10^-31` |

杆映射一致性自检：406 条杆的中点平方长度全部等于 `t_root = 0.013327999392353651…`，最大偏差 `6.310477659343186×10^-61`（远在 `±1e-58` 根箱之内）；这确认所用 `(a,b,j)` 映射恰是 406 条 active 距离行（114 内部三角形 ×3 + 32 边界对 ×2），乘子变量为 `493+j`。

## 边界与下一步

- 它**不**涉及 H0 / Gram 提升步骤的符号；不得引用为本文件或任何 H0 负性证明。也不给出任何 r_D(100) 的界。
